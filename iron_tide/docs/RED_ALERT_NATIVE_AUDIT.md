## 已确认

- 0xa885c0: GetRedAlertButton 字符串进入 HUD 调用；绑定结果储存于 HUD+0x124。
- 0x8711a0..0x8711d7：可用性检查；挑战管理器+0x18 非零、储备字段+8 >=10000、威胁状态+0x14 ==3、激活标记+0x1c ==0。
- 0x87b7b0..0x87b84b：激活重复上述门槛，置激活标记，调用 0x8a0860 派发事件，再调用 0x5027d0 消耗储备并保存返回值到+0x20。
- 0x5027d0：消耗 min(当前储备, 配置+0x1c)，当前储备减去消耗，置dirty。不能仅凭10000可用门槛断言消耗固定10000。
- 0x481c8b：某配置构造默认+0x1c=50000；尚未确认它就是上述挑战储备配置，不将其等同实际消耗或奖励。
- 0x87b500..0x87b5d9：对象造价计算调用0x6fb2d0，其结果乘模板+0x14(3.0)，累加威胁并夹至模板+0xc上限；该路径由0x87f4c0损失通知包装函数调用，排除原因8/0x19（原因枚举未解码）。
- 0x87b5e0..0x87b6b9：对象造价乘模板+0x10(0.75)，累加并夹至上限；造价0x6fb2d0在参数0时返回模板+0x2fc的16位造价字段，不能简单称实际支付资金。
- 0x8858b0..0x885975：按模拟时钟间隔衰减，依据当前档选择模板+0x18/+0x1c/+0x20，饱和减法不低于0；随后与模板+4/+8比较更新黄/橙/红状态并调用0x87b6c0。精确帧边界是严格大于调度阈值，UI无需复制此一帧差异。
- StaticStream.big编译资源 RedAlertTemplate:BaseRedAlert 的字节与XML一致：黄->橙20000、橙->红49000、上限50000；击杀系数0.75、损失系数3；三档衰减50/150/50。
- 0x87b822..0x87b842：带属性修饰器的对象遍历回调0x871a20；该回调0x871a60..0x871a72循环调用升级例程0x780ad0，直到资格检查0x7133c0为false。支持“将符合资格的现有对象升级至不能继续升级”，具体最高等级及新生产单位继承待核对。
- 0x5112f3..0x511331：挑战结果路径在标记+0x10为true时将时间选为5999秒(99:59)，该标记与激活事件的完整连接尚未追完。
