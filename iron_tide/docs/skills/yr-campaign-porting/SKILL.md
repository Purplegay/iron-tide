# 尤复战役移植 · 快速入口

以苏军 07《首脑游戏》的整关迁移方法为范例，不复制该关数值、触发器或近似。先跑通一条**可追到零售 ID 的真实战场链**，再按共用适配器批量扩展。追求少返工，不降低验收标准。

## 1. 开工只读当前需要的资料

1. 找到含 `project.godot` 的 Iron Tide 项目，读根及适用目录 `AGENTS.md`、项目 `docs/memory/YR_CAMPAIGN_PORTING.md` 和 `docs/memory/YR_CAMPAIGN_MEMORY_INDEX.md`。按地图 ID 只读该关最新交接和本轮相关专题，核对当前工作树、菜单、装配入口和测试。不要从安装目录找项目文件。
2. 先定**地图 ID、范围、交付阶段**。区分盟军 `ALL01UMD`、盟军 `ALL07SMD`、苏军首关 `yr_time_shift`。用户只要某一阶段就不扩范围；已有 ID 先查是否已接入，不重复计数。确认 Steam/零售来源、MIX、SHA-256、剧场、可玩边界及可复跑提取入口；无本地证据则依项目交接重取，不能编造或从范例抄参数。
3. 按任务选参考：

| 本轮任务 | 先看 |
|---|---|
| 新开一关、继续补任务或 AI | [执行流程与双表模板](references/workflow.md) 的「接入」；照最新交接找同类导出器和正式适配器 |
| AI 有启用记录但未出兵，或对象动作找不到目标 | [执行流程与双表模板](references/workflow.md) 的「AI 规则已启用」和「依赖绑定对象的动作」 |
| 跨场景恢复原对象并执行延迟动作 | [无头取证](references/headless-evidence.md) 的「跨场景对象和延迟动作」 |
| 迁移地图、桥坡、预置对象或换时代 | [完整检查表](references/full-checklist.md) 的地图、覆层、预置建筑与换场；另读项目 `YR_SLOPE_PORTING.md`、`BRIDGE_PORTING.md`、`TERRAIN_PORT_GATE.md` |
| 分支卡住、存档、结算或 CG | [执行流程与双表模板](references/workflow.md) 的「验收」；再查[完整检查表](references/full-checklist.md) 对应门槛 |
| 批跑逐 ID AI，或复测超时项 | [无头取证](references/headless-evidence.md)，先辨路点、择敌和设施，不盲目倍速复跑 |

上述参考路径相对技能根；从仓库直接读取时相对 `docs/skills/yr-campaign-porting/`。整关验收必查完整检查表；资源、桥坡、语音等专项动到哪一项就读哪一节。

## 2. 一个批次怎么做

1. **建两张独立账。** 任务 `Triggers/Events/Actions/Tags/CellTags` 追到房、对象、计时、启停、难度和后继；地图 AI `AITriggerTypes/AITriggerTypesEnable/IgnoreGlobalAITriggers` 追到 AI ID、房号、条件、权重、前置、资金与 `TeamTypes/TaskForces/ScriptTypes`。全局继承、脚本增援、预置招募和工厂生产分列；有条件 ID 的按条件 ID 计，不把共享编组去重来缩分母。没有独立条件表时，另报本图脚本小队与其稳定 ID，不冒充条件条目。
2. **先接一个贯穿样本，再成组补同语义项。** 零售数据 → 正式出击战场的驱动表 → 条件查询 → 动作适配 → 玩家能看见的结果。已有关卡代码可复用机制，不绕开表硬编码任务流程；通用遭遇战 AI 不替代本图 AI。只导出、不消费的条目不算接入；原图不可达或关闭不擅自打开，未知动作单列。
3. **做正反两例再扩大批跑。** 有门槛的查差一、不下单与刚满足；执行结果按用途验，工厂队查扣费与出厂，驻防看实际到岗和接敌，运输验卸载，工程师验到门转属。默认隐藏无头、隔离存档，批跑关闭测试用自动存档与定时检查点；不改玩家存档。移动及交火固定步长，不靠大步长跳过逻辑。
4. **写结论，不把证据混用。** 两表各报原图总数、本轮新增、累计正式接入、本轮逐条实测、未接或不适用，并列完整 ID 和结果。区分数据核对、流程验证、行为完成、自然通关和发行；未验就是未验。按项目规范写 `docs/memory/` 交接并更新索引，包含原图依据、实际入口、玩家结果、复跑命令与证据、近似及未验。

## 3. 不得因提速跳过

- 在正式菜单、Battle/HUD、真实生产和存档入口取证；覆盖胜利、普通及专属失败、结算与返回。关键断点成对 `seed/cold`，检查未执行动作不漏、已执行动作不重发。只看退出码或只 `load()` 不算通过。
- 开场交控单独验收：从正式菜单出击，在正常帧循环分别走简报自然结束与主动跳过，记录每段影片、续音、交控和第一条命令的墙钟时间。手动步进、倍速或强行回调只能作专项证据。锁控期间必须有可见的画面、字幕或明确进度与跳过路径；查完播/落地门槛后是否又叠加原图计时，避免无提示长等。见[无头取证](references/headless-evidence.md)。
- 地图桥坡、覆层、碰撞和建筑不能凭画面或格表互相替代；按项目专题逐格、逐桥验。新增/重烘单位建筑同批验高光和玩家中文。新增或换源 CG 同批登记原片节选，分别验战场播放和收藏回看。
- 开窗口或截图先取得同意。用户跳过自然通关或有头实景时，按要求停止并记录未验，不宣称零售整关等价或已发行。阶段证据和完整签发标准见 [完整检查表](references/full-checklist.md)。
