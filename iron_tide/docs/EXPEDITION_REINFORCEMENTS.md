# 军团超时空增援（2026-11-19 修订）

每局重新排队，幸存者不再开场部署。军团包括营地购买/奖励的普通人员、特装小队和健康英雄；本局工厂自产单位、地图初始单位和任务单位不加入跨局军团，也不影响损失比例。

基础时间为 cost × 0.3 秒，英雄与普通单位完全相同，训练等级不额外增加等待时间。所有同价格同批抵达，不逐个累计。军衔、经验、生命比例保存在队列中，英雄授予原生最低军衔后不被队列默认0级降级。

## 跨局减时

按兵种/英雄身份/特装 token 分别记录减时秒数。

下一局减时 = min(基础时间 × 上限, 原减时 + 本局实际推进的该批倒计时 × 0.5) × 军团人数存活比例。

推进时间不超过本局该批 due，不把到场后漫长战斗时间继续算作减时。普通上限50%；传说藏品“超时空稳定锚”（200补给、抽取相对权重0.15）将上限提高到80%。伤亡惩罚在封顶后计算，保证满减时状态损失也会回补等待。未抵达队列视为健在，未出战预备军团不计本次伤亡分母。

例：基础300秒，上局完整等完且无损，下局150秒；同样条件下损失50%，下局225秒。特殊遗物允许累积至最多240秒减时，至少等待60秒。

每局时钟从0开始。仅同一场战斗的checkpoint恢复队列和时钟；不会在新局沿用上一局已完成队列。胜利和撤退均执行军团结算。自产单位无军团来源标记，结算不会收入军团。
