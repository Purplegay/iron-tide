## 一、开工时取得的原版资料

- [ ] **按原图剧场取建筑美术。** 读取地图 `[Map] Theater`，在该剧场的 MIX 中找主体、底座、建造、运转、受损和阴影帧，缺项再查通用包。洛杉矶是 `NEWURBAN`，反应炉取 `genermd.mix/YGPOWR*.shp`；雪地取 `snowmd.mix/YAPOWR*.shp`。两个剧场的帧数和阴影起始位置也可能不同。换图时连同动画状态表、预加载和高清页一起切换。0.32 已为第二关 9 种尤里建筑登记 6 个剧场、每个剧场 39 张素材。重新生成入口为在 `iron_tide` 下运行 `node tools/yuri_building_theaters.mjs "<尤复安装目录>"`。

  0.32 的 `--building-animation-audit --theater-picture` 从战役入口进入第二关，检查完好、受损、工作和建造状态，并在同一进程中将图集切到雪地再切回新都市，89 项断言通过。[新都市生物反应炉实景](../../docs/fixes/v0.32/hollywood-reactor-newurban.png)

- [ ] **移植体素单位时补齐各状态的高光。** 按原版 VXL 法线与 VPL 查表烘焙车体、独立炮塔及换装、部署、后坐状态。用一张当前单位总览交给使用者检查观感。[光照公式、重烘入口及 0.32 总览](../../docs/MODEL_RENDERING.md#032-原版体素单位的金属高光)

- [ ] **确认任务身份。** 记下游戏版本、阵营、关序、任务文件名、来源 MIX、战役入口、简报与字符串键。洛杉矶使用 `mapsmd03.mix` 中的 `ALL02UMD.MAP`。先核对地图名、首个镜头、玩家房号和首要目标，防止接到同地点的另一张图。
- [ ] **列出本关引用的资源。** 从地图取预置对象、任务队和触发动作，再查该版本的规则、美术、语音事件表、字符串表、影片和素材包。YR 使用 `rulesmd.ini`、`artmd.ini`。逐项记录基础值、地图覆盖值、游戏内实例值，包括本关专用造价、供电、容量、占领和驻军限制。
- [ ] **盘点地图和房号。** 记录可玩边界、坐标变换、路点、地块标签、建筑朝向、桥梁及桥头小屋、矿区和采矿设施。记录各 House 的身份、盟敌关系、初始资金、基地、守军和控制权。用两个相距较远的路点核对世界坐标，再验证相机、单位和雷达标记落在同一处。

## 二、按事件接入玩法

- [ ] **逐个移植单位图标和生产时间。** 从本关出场、可生产和附属单位列名，包含占领敌厂后的产品、随车成员和部署形态。按零售版 `Image → artmd.ini Cameo → SHP` 与 `CAMEO.PAL` 核对图标。按 `rulesmd.ini` 与任务图覆盖核对 `Cost`、全局 `BuildSpeed`、单位 `BuildTimeMultiplier`。在真实兵营或工厂检查卡片刷新后的图标、价格和秒数，切换倍速，核对队列半程扣款与到时出厂。对地图预置或自动补员的单位，检查选中栏图标和实际使用的补员、部署计时，注明其生产入口是否开放。

- [ ] **追到动作真正执行的位置。** 从 `Tags`、`CellTags` 和对象绑定追到 `Triggers`、`Events`、`Actions`。记录初始启用状态、谁能触发、难度、一次或重复、规则帧、局部标志，以及启用或关闭的后继触发器。区分被攻击、摧毁、占领、渗透和进入范围，逐条确认触发后果。
- [ ] **还原开场与任务目标。** 按原序记录镜头路点、临时揭雾、暂停、交还控制、初始选择、援军进场及首次命令。核对主目标、可选招募、失败条件、组合标志和结算延迟。洛杉矶拆完四厂后还要清剿指定敌方房号，结尾有居民欢呼。
- [ ] **沿引用还原 AI。** 从建队动作和 `AITriggerTypes` 追到 `TeamTypes`、`TaskForces`、`ScriptTypes` 和实际路点。记下编制、房号、难度、是凭空增援还是基地生产、巡逻或攻击命令、补员和重组。实测遇敌交火、清场后继续原路线。洛杉矶片场巡逻可从两辆 `LTNK` 和路点 31、30 入手。
- [ ] **验证关键对象的交互。** 用玩家实际指令测试工程师占领、驻军与撤出、运输与车内开火、解除心控、断桥抢修、采矿卸货、居民排队与获救、掉箱与拾取。按本关实际对象选项。地图摆出的建筑也要测，尤其是通用生产目录里没有的城市设施。
- [ ] **核对单位和建筑表现。** 为本关特殊对象记录原版编号、武器与精英武器、弹头、装填、部署状态、炮塔朝向、开火点和音效。检查建造、驻留、受损、满载、死亡等状态使用的动画、色盘和房色。用一个自然发生的状态转换核对画面和规则，例如尤里反应炉进人后同时看炉体和电网。

## 三、逐句核对玩家能看到和听到的内容

- [ ] **从两个方向查漏。** 从每个原图播放动作追到音频文件、发言人、中文台词和显示位置。再从所有本关专用录音反查触发器，另列通用 EVA 通报。存在素材但触发归属待查的，保留 ID 和疑问。洛杉矶 `xa2ev03` 就属于这一类。
- [ ] **对白和行动提示各留一栏。** 按原声或可靠字幕翻译人物实际说的话，同时保留玩家需要的目标、入队或操作提示。发现克林特时，伊娃谈西部片、托人要签名；“克林特已入队”是另一条事件。新单位登场逐项核对介绍、到达通报、镜头、雷达圈、页签和生产图标。
- [ ] **按实际播放方式验字幕。** 全屏简报、雷达短片、实地通讯分别检查。按影片进度核对首末句、换句、跳过与恢复。连续触发两处发现时，核对发言人、语音顺序、排队、断行、驻留时间。用正常窗口看字幕是否被 HUD 遮住，听一遍是否与当前说话人一致。
- [ ] **核对引导与视野。** 将原版箭头动画、建筑闪烁、雷达报点、图标闪烁的目标和持续规则帧写入事件表。切换雷达供电、揭雾和目标存亡，确认公开任务标记与普通单位情报各按原条件显示。

## 四、从玩家入口验收并交接

- [ ] 从战役指挥室选择任务，走一次胜利和一次失败。检查三种难度各自启用的守军或触发链，以及发现顺序变化、提前拆厂、目标易主等会改变结果的分支。
- [ ] 在一次性事件前后、阶段切换和援军途中存档，冷启动恢复。核对单位归属、乘员、目标、队列与计时，确认增援、台词和奖励各发放约定的次数。
- [ ] 把原图定义、运行时对象、玩家实测分别留下证据。区分目录可查、实例生成、行为已验。记录命令、难度、结果、画面或日志位置、替代实现和待查项。用隔离玩家数据运行回归。
