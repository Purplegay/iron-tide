## 区段拆分

trace2/3 在每个单位上记录进入/退出边界，嵌套调用从父区段扣除，按画面帧与引擎事件对齐，剔除两端不完整帧。两个档有效帧数 212/211，最慢 5% 各 11 帧，全部对齐。数字是带探针的墙钟均值。动作/维修包含分支判定，普通战斗剩余时间包含未再拆分的被调函数。
