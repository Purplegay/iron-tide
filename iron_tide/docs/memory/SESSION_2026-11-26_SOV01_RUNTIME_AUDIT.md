# 苏军第一关运行一致性复核

本次检查的是 Iron Tide 现有第一关 `yr_time_shift`。从苏军战役菜单的出击按钮进入，核对已接入的任务、地图、建筑与演出。表中的覆盖是对本项目行为的证据，不能当作原引擎逐项一致的结论。

## 实际修改

- `time_shift_events.gd::power_contest` 将盟军与尤里共享敌对战斗房号时的电厂归属留到进门时登记，跳过已归属尤里的电厂。对玩家电厂下达普通工程师交互时不预先写入标记。
- `allied_abilities.gd` 在指定尤里工程师完成交互后登记电厂归属，玩家夺回时清除标记。任务指定的工程师目标不受普通目标可见性检查阻断，仍须目标存活、可占领并走到入口。诊断复现中，工程师距入口为零但敌方迷雾仍返回不可见。
- `time_shift.gd::sync_crossing_visual` 和 `battle_snapshot.gd::restore` 依据已存的旋涡时间重建暂停画面。跨过一半时切换区域和战场对象。读档后用已保存的阶段防止重新生成对象，继续后才播下一条简报。
- `hud.gd` 的两个延迟布局入口在节点离场时直接返回，防止切换存档场景时访问已经脱离场景树的视口。
