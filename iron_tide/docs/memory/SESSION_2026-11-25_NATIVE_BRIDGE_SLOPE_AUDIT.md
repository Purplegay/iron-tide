## 战场复现与处理

在好莱坞 u=150 桥的 v=118 处分离桥面，再让灰熊从相邻车道驶向断口。原先 record_move 只检查目标是否还在同一座桥，走一格可掉层，走两格可越过断口。现在移动落定前检查经过的每一桥段，从完好桥面驶向缺口时保留原位置和层级。桥下街道继续走原来的地面规则。

用隔离 APPDATA 从真实战役场景运行 tests/hollywood_campaign.tscn -- --bridge-tech。新增检查修前两项失败，修后全场 59 项通过，错误日志为空。覆盖六座桥的断面和维修绑定，以及样本灰熊上下桥、侧向护栏、桥下通行、断口阻挡和修复后的行驶。日志在 %TEMP%/iron-yr-bridge-slope-audit/ 下的 before.log 和 after.log。
