# 迷雾外开火的位置提示

通用 fog.reveal_attack 已经按受击方暴露开火地点 3 秒。修前在玩家快速存档副本定向测试，敌方 DISK 从未知格向 SHK 开火，飞碟本体立即可见，actor_visible_to 返回真，但迷雾过滤后的光束不可见，小地图开火点提示数为零。重建用的 _live_masks 在合并时会清空。

在通用开火揭示入口对攻击玩家或友军且原先处于迷雾的来源发出 firing_origin，战术地图绘制橙色闪环。飞碟红色主武器及紫色汲取武器传入开火双方地面坐标作为光束迷雾判断坐标，继续使用美术中心绘制。

用同版本发行运行时、快速存档副本、测试用隐藏开火点及定向射击验证。激光打 SHK 和汲取电力建筑均得到开火前隐藏、开火后攻击者 visible 和 actor_visible_to 为真、光束过滤后 visible 为真、开火点提示 1 条。结果在 .validation/quick-disc-20261125/fire-reveal-laser.json 与 fire-reveal-drain.json。检查了运行时状态，未逐像素比对截图，未逐个验证特殊技能。这次验证范围是开火暴露和表现。

补验使用发行运行时和快速存档副本，在隔离战场分步推进迷雾计时。飞碟两次汲取电厂间隔 2 秒，原地只收到 1 次 firing_origin。第二次开火后将飞碟移入另一处迷雾，推进 2.8 秒时原地仍可见、撤离处飞碟隐藏，累计 3.1 秒时原地回雾。退出码 0。结果见 .validation/quick-disc-20261125/fire-expiry.json。
