# 远征开局基地留出通道

原版地图的远征开局在 battle.gd 把电厂、兵营、矿场的目标位置各向外推 100 世界单位，搜索失败后重试旧锚点。runtime.gd 的追加设施优先搜索半径 300 至 900 的圈，把与己方既有建筑地基包围盒的间隔设为至少 100。找不到时按原有半径 200 至 2300 的搜索顺序兜底。恢复关内快照沿用已存位置。

Godot 4.7.2 无头隔离验证从生产脚本提取 structure_site，并使用项目 Placement 几何函数。开阔地选中 (212,212)，与夹具中既有建筑地基间距 112；唯一合法点在内圈时返回 (-200,0)；完全封闭时返回 INF。测试使用模拟地图合法性，未运行整场远征或在截图地图实测矿车通行，未打包。
