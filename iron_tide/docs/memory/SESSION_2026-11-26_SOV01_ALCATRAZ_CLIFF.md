# 苏军第一关恶魔岛岸崖

从截图的任务文字定位《时空转移》。本次以心灵控制器旁海岸作验收样本，截图本身没有提供格坐标。SOV01UMD.MAP 的 (123,38–39) 为 NEWURBAN 的 WClifx18 上下两块，类别 15，分别为 4、0 级。(128,37–40) 是连续四块 DRSLPE05，连接海滩与 4 级公路。

`tools/bake_native_slopes.py` 将恶魔岛沿岸 WClifx 等崖片及邻格纳入原版等距合成后重采样，重烘 `assets/maps/yr/yr_sov01_terrain.png`。崖面四角的平滑取样为平面底图近似。`scripts/units/unit.gd::_domain_ok` 在本关逐步移动时读取与寻路共享的实时地形标志，区分地面、海面、不可通行崖面和当前时代边界。

隔离 APPDATA 运行 `tests/time_shift.tscn -- --alcatraz-cliff`，从苏军菜单出击，测试夹具切到最终时空的通行边界并在目标处放置单位。运输艇从水面向不可通行的崖脚连续给速度五次，停在水侧。犀牛从海滩下达移动指令，最终进入 (128,36) 的 4 级平地。16 项通过，退出 0，stderr 空。实际窗口截图在 [恶魔岛海岸](evidence/SOV01_ALCATRAZ_CLIFF.png)，前后底图、烘焙与实机日志在 `%TEMP%/s01-alcatraz-cliff/`。

验证覆盖这处直崖、相邻坡道及正常物理步，未覆盖冲击位移、滑移推挤、逐段全岛行军、旧存档或完整任务通关。坡道仍使用二维地形贴图，车辆本体没有增加随格高起伏的投影或俯仰。本次为工程版，未重新导出发行包。
