# 远征信物校时器

稀有经营藏品，进入通用藏品池，共五级，每级使信物开场等待和发动后的冷却时间缩短 10%。commander_keepsakes.gd 先把槽位原始等待限制在 300 秒内，再按遗物等级折算。满级开场上限 150 秒，普通再次发动 300 秒，联合运费 120 秒。营地显示与战场采用同一计算。检查点保存剩余时间，恢复时沿用进度。藏品卡与持有列表从配置读取最高等级。

Godot 4.7.2 无头 expedition_keepsake_regression.tscn 使用独立用户目录，满级模式 IRON_TIDE_TEST_MAX_TIMER=1 通过 414 项，无遗物模式通过 415 项。覆盖逐级封顶、13 槽位开场与按钮状态、中途读档及新关重置、独立再发动冷却和联合运费。验证范围为源码战场场景和测试存档，未人工抽取商店商品或打包。
