# 存档 1 成长更新的任务间隔

本轮活动 A 为桥面缓存，选址版本未进入 A。尤复原版 rulesmd.ini 的任务区分 Rate、AARate，普通/区域索敌分别 27/36 个逻辑帧；此处借鉴按任务决定复查频率。先拆既有成长路径，以同窗口阶段耗时和调用密度选择 B。

首次隔离插桩因英雄函数参数名写错，已停止自有测试进程并丢弃。修正后的 A2 共 168,216 次成长入口、167,661 次二期资格判定、104,152 次旧版空闲分流和 2,517 次完整旧卡牌更新。成长、二期、二期资格在慢帧分别为 29.289、9.037、3.313 ms，层层包含。B 在无活跃 v2 状态、无适用兵种天赋时按兵种与被动共享否定结果，27 个物理步后复核，新增状态和天赋立即走原路径。测试包含换装、换边、恢复状态及到期。

开发树原版和候选各跑相同的成长综合回归，1036 项逐项结果一致，其中旧断言 two talent limit V3 两边均失败。当前 V3 第三天赋槽与旧预期不一致，原报告保留。另跑当前成长、归属、地面能力与 15 项缓存生效/失效专项，均通过；合入后复用这些专项。

## 正式裁决

3× 存档 1 最好 P95 235.400 → 284.559 ms，均值 267.998 → 314.741 ms。按规则跳过 1×。候选未合入；开发树原文件 SHA256 核对相同，活动 A 仍是桥面版。 进程审计通过；当前步数和单位分布不同，独立采样内的热点变化不能单独解释正式整帧变化。新一轮优先对正常自动索敌的检查间隔分流，参考 rulesmd.ini 的普通/区域警戒 27/36 逻辑帧，保留显式命令及失效即时响应。

退步归因边界：每物理步成长父项仅省约 0.220 ms。140,083 次非玩家空被动本来就能早退，新的否定缓存只覆盖 15,593 次命中。慢帧基地管理 41.442 → 45.262 ms、阵营 AI 52.260 → 53.200 ms。外部引擎审计通过，动态轨迹、补步和后台负载仍有波动，无法证明是这些区段单独造成正式 3× 退步。
