# 六关战役目标点与雷达标记

用户在《首脑游戏》存档 2 反馈没有目标点。原版第七关依据 `SOV07_TRIGGER_INDEX.md` #28/#30/#31：43/44/45 号地点依次展示城堡、盟军信标、苏军信标；含闪烁指令和信标雷达事件。这里保留导览顺序，持续菱形和中文标签是移植界面的补充，不等同逐条执行原版动作。存档 2 已解放两翼、城堡仍存活，重新加载即重算目标，不需迁移档格式。

- `scripts/ui/campaign_objective_marks.gd` 统一战场和雷达标记入口；主战场接 `battle.gd` 既有迷雾上方绘制层，标记用屏幕坐标并不拦输入，不自动攻击、不揭开迷雾；雷达菱形走 `minimap.gd` 的定位容差与悬停说明。多个密集目标优先显示菱形，鼠标靠近可见名称。闪圈切换清除，手动雷达回跳历史仍保留。
- 《首脑游戏》：导览分别显示各对象，进入战斗标两座信标，完成一翼撤其标记，完成两翼仅标城堡；先拆城堡也可走旧胜利流程，标记立即清撤。
- 《时空转移》：海防七目标→四碉堡→待占电厂→时光机→待接管苏军基地→心灵控制器，穿越间隙不绘旧标记；修正 `campaign_command.gd` 曾串用第七关目标的选关文案。
- 《好莱坞梦一场》：雷达离线时小地图不报点，战场仍标已经侦察的回收厂；供电后两处报四厂位置但不开视野。回收厂停运后转资金箱，清剿只标已侦察的敌方任务建筑；结束撤标。
- 原创《结晶裂谷》两处孵化巢各有目标标记，分别撤除。《断轨平原》守波、《灰烬要塞》生存，无固定地点，不加标记。遭遇战/远征不进入战役标记管线。

验证：Godot 4.7.2 隔离 APPDATA。最终 `head_games.tscn` 49 项、`time_shift.tscn` 51 项、`hollywood_campaign.tscn` 91 项，均无头 exit 0、stderr 空；正常战役菜单出击后用夹具加速推进。`head_games.tscn -- --cold-objective` 使用真实存档 2 的隔离副本，10 项（定位、主图标记、冷读取、撤标、结算）exit 0/无 stderr；图形窗口同用例生成并人工检查 `slot2-objective.png`，可见城堡上菱形、中文与雷达菱形。原创三关 `campaign_objective_marks.tscn -- m01/m02/m03` 分别 3/6/3 项通过，从菜单选择、夹具直接装配正式战场（不是模拟按出击）。此前原创模拟出击用例未取得场景切换结果，不计通过。完整 `minimap_regression.tscn` 本轮直接运行被隔离 runner 的保护条件拒绝，不计通过。证据 `%TEMP%/IronTide-CampaignObjectiveMarks-20261126/`，尤复最终 `delivery-*.log/.err`，原创 `direct-*.log/.err`。未改玩家档、替换运行中的游戏或打包；未做所有关卡的图形截图或自然通关、未专项实测锁定暂停的雷达点击。
