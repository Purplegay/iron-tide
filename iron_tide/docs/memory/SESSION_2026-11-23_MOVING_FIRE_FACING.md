# 普通移动中开火的朝向更新

`scripts/units/unit.gd` 普通移动且目标在射程内时改用 `_face_while_firing`。一次提交车身行进朝向和炮塔目标朝向。锁定采矿朝向、低速和目标重合时沿用原函数。目标角度变动仍触发重绘，动态车体保留逐步刷新。攻击移动遇敌停车另走原分支。

Godot 4.7.2 运行 `.validation/moving-fire-facing/probe.gd`，从生产代码提取函数并替换重绘计数、刚性资格和武器类型判断。768 组新旧朝向与重绘约束对照零失败。固定行进方向、固定瞄准角、满足刚性复用条件时，600 步的朝向函数重绘请求从 1200 次降到 0。Godot 会合并同帧请求，实际绘制次数和整帧耗时待图形场景测量。项目原有 `grizzly_visual_regression.tscn` 在隔离用户目录运行，21 项通过。原始证据在 `.validation/moving-fire-facing/`。本次没有复现玩家原战局，尚待区分大部队下令瞬间同步寻路和持续交战两类卡顿。
