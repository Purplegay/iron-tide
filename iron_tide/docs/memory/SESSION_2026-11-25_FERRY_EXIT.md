# 气垫运输船卸载出口

原先卸载以世界正东方向起按三个同心圈找空地，最远距离为第一圈的 2.2 倍，乘员直接出现在落点。普通封闭运输舱乘员在途中还可能保留登船时的坐标。未取得玩家当时的录像，具体画面成因没有逐帧复现。

scripts/units/unit_logistics.gd 的 unload_one 现在让 LCRF、SAPC 优先从船头卸载，左右搜索贴船的安全出口。恢复可见后重置显示插值，出口前方可走时让乘员短距离走开，超时空步兵跳过自动移动以避免触发传送。没有安全出口则继续等待。

Godot 4.7.2 隔离用户目录，无头加载真实战斗场景。tests/ferry_exit_regression.tscn 覆盖两种规则和两种船，用普通步兵检查登船隐藏、深水保留、远距离转场后船头落点、显示插值起点、走出命令和实际位移。24 项通过，stderr 为空。证据在 %TEMP%/IronTideFerryExit1125/reports/result.json。没有逐帧渲染验收、载具卸载实测或玩家原关卡录像对照。

## 下船时从远处飞来的反馈

封闭气垫船内的普通乘员原先可以长期停在登船坐标。unit.gd 现在在乘员的物理更新里同步 LCRF、SAPC 的位置。ferry_exit_regression 增加航行中隐藏乘员随船的检查，两种船和两种规则共 28 项通过。

隔离有头战斗场景用苏军气垫船和 E1，在相距 450 单位的两点装卸。给乘员附加像素标记，关闭乘员自主行走，在卸载后采集每种规则连续八帧。改动前后标记均在出口附近，中心 (981,358)，目标约 (982,359)。因此本例能确认旧登船坐标的隐患已处理，对玩家看到的飞行现象仍缺少具体关卡和乘员类型。截图与测试脚本在 %TEMP%/IronTideFerryExit1125/pixels_a、pixels_b 和 pixel.gd。

## 手动按 E 卸载

用户确认从战场按 E 触发。ferry_exit_regression 已改成选中运输船，通过战场视口发送 E，检查深水等待、靠岸卸载、首帧采样与乘员实际迈步。盟苏两种船、原版与扩展规则共 32 项通过。单独用苏军船搭载 E1，真实 E 事件后船和乘员正常执行物理更新，两种规则各抓 20 帧。扩展规则画面标记先在出口 (981,358)，再到相邻步行位置 (997,350)。原版首张采到的画面已在步行位置。取图会消耗时间，不能据此还原所有玩家帧。原局的乘员类型和现场仍待确定。本轮仅更改回归用例。画面证据在 %TEMP%/IronTideFerryExit1125/pixels_key，日志为 keyout 和 keytestout2。
