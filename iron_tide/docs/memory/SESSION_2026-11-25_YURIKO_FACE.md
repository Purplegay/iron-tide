# 百合子模型脸部

以手记 story_portraits.png 第一格获救装和第三格校服为参考，更新 assets/ra3/yuriko 下 JapanYurikoTech1、JUCommandoTech1 两套 GLB 的脸部顶点和内嵌贴图，并同步同名 YurikoUniform PNG。沿用镜像 UV，缩短鼻部突出、轻收下颌，获救装保留忧虑表情，校服带浅笑。原动画继续使用同一骨架。

验证覆盖模型静止正面和斜侧面纹理近景。Godot 4.7.2 在独立工程导入并实例化两套模型，实际身体材质均读取 1024×1024，动画列表分别有 16、30 项。战场光照、缩放及动画播放中的观感待实机确认。

## 0.31.51 单位独立换头及颈部调整

当前单位模型使用独立蒙皮网格 `YurikoUnitHead`，取代上面的原头改顶点方案。获救装和校服各用一张从手记对应表情烘出的 512×512 头部贴图，含 mipmaps。头部沿模型竖轴整体下移 0.40，衣领上方的原颈部按斜领口渐进压缩。脸型、头骨绑定和两套动画轨道保留。需要从原始导出的 GLB 重建时，用 `tools/ra3_mirage/build_yuriko_head.py` 指定两套模型路径；默认取模型目录下的 `school_days/story_portraits.png`。

每套独立头部 2,153 顶点、3,552 个三角形。获救装移除 538 个旧头三角形、保留身体 1,360 个；校服移除 318 个、保留身体 690 个。上述为源模型最高细节面数，不含护盾。Godot 4.7.2 已通过项目单位渲染入口切换 0→1→2→0，核对头部蒙皮、贴图、待机、移动及攻击。两套模型的 16、30 个动画片段数据与换头前逐轨一致。对照图采用同机位待机帧，比例观感待玩家确认。验证目录为 `.validation/yuriko-unit-head-v2/`，主报告为 `unit.log`，对比图为 `neck-comparison.png`。

## 0.31.51 手记头型的独立解锁

原版头型为默认外观。本节取代上节关于“独立新头默认用于单位”的状态。试衣间在好感达到 20 级且实际读完第五章《靠窗第三排》（desk）后开放“手记头型”。两项可以任意顺序完成，最后一项在送礼或完成阅读时提示解锁。获得资格后由玩家选择是否装备，选择随指挥官档案保存。仅取得章节书页、打开阅读页、解锁衣装或使用 GM 开放剧情均不能单独替代两个条件。

单位、试衣间、技能演示均由 yuriko_model.gd 根据当前有效头型选择模型。原版资源在 assets/ra3/yuriko/classic/，使用原始零售模型导出的网格、骨架动画与材质；手记头型继续使用上一节的短颈模型。头型选择适用于已获得的全部衣装。校服 II 与 III 继续共用各头型对应的校服网格，保留各自的章节动作、头像、灵能配色以及第五、八章的衣装门槛。

Godot 4.7.2 的隔离档案手记回归 1,303 项通过。覆盖两种达成顺序、界面解锁提示、拒绝残留装备标记、手动切换、存档重读、演示以及实际召唤时的第三套衣装。日志在 .validation/yuriko-head-unlock/school-final.log。
