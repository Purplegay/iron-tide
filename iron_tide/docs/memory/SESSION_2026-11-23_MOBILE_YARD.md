# 基地车收起后的视野和建造范围

unit.gd 在单位初始化时由 DeploysInto 和目标建筑的 hq 标签识别基地车。fog_of_war.gd 让其视野至少等于对应建造场的基础视野乘以建造场视野倍率。扩展模式下，build_range_preview.gd 将己方存活、在场且未搭载的基地车作为移动建造来源，建造地基按展开形态计算。单选时显示范围。原版模式用展开后的建筑提供建造范围。

Godot 4.7.2 无头运行 build_range_regression，两种模式 235 项通过。新增检查走真实建造场收回入口，验证收回前后视野半径、移动后实地视野、预览随车移动和开雾落点判定。移动由测试设置位置，验证范围限于真实场景逻辑。报告 `%TEMP%/IronTide-MCVReach-180648/result.json`。
