# 远征增援支线

用户明确要求普通支线可以减负，能带来增援的支线需要保留。此记录更新 SUPPORT_ROUTES 的九关救援排期。

field_operations.available_arrival 为路线预告和战场任务共用的预约计算。普通关只要有可兑现日期就派发联络人，可以与赴约友军、抢修侧桥或第二项任务并存。按历史基础任务池抽中的呼救电台、断桥工兵也在周目扩展池和普通支线减负规则中获得保留。侧桥先部署以便后续任务寻找间距合适的位置。地图仍需有可达、安全的位置。已有战场检查点使用原任务。

Godot 4.7.2 隔离用户目录 Temp/IronTide-ProtectedAid-76416。cycle_mail 模拟每次成功救援，五个周目均排满第 6 至 24 关的 16 个非首领日期。multi_front 场景 67/67，field_missions 场景 140/140，含电台、侧桥、独立 AI 友军、检查点和结算。排期计数不代表逐图实战。出生容量不足的路线（包括双人侧桥图）仍只能容纳两家，预告按实际阵营显示。未打包，未读取玩家存档。
