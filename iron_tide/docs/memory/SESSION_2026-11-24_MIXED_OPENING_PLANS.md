# 跨阵营开局方案

生产配方二级现在按整套方案保存。阵营筛选共用同一条草稿清单，支持多套、当前方案、自动数字命名和自定义名称。旧档中的盟军和苏军清单依次合并为方案 1。每次开局读取生效方案快照，待排项按可用建筑、许可和正常生产限制重试。优先使用兵种的原厂，同优先级选择较短队列。

Godot 4.7.2 隔离运行 tests/opening_orders_regression.tscn，输出 OPENING_ORDERS failures=0。覆盖旧预设合并、默认名、自定义名与当前选择读档、混编草稿、施工等待，并在战场场景中设置远征生产许可，验证美国大兵和犀牛分别进入盟军兵营与己方苏联车厂。验证范围为上述订单流程，未跑整趟远征。
开局订单预览按连续相同兵种折叠，显示头像、单位名与数量。点击折叠项移除一个订单，间隔出现的同类按原顺序分组。隔离测试 opening_orders_regression 输出 failures=0，覆盖相邻折叠、非相邻分组和点击移除。

ESC 战场顶栏的暂停按钮旁增加关闭和恢复开局订单的按钮，显示本局待排数量。暂停标记随 allied_state 纳入战场快照。订单排完后隐藏按钮。隔离 opening_orders_regression 回归通过，覆盖顶栏可见、暂停保留待排与在厂队列、恢复派单和排完隐藏。存档依据快照字段核对。

## v0.31.24 开局订单排序

开局出兵预设中点击「调整顺序」，先选连续兵种组，再点目标组，即可把整组移到目标原来的位置。可跨行、滚动后选择另一端；再点源组取消选择。退出排序后点击订单仍逐个移除。保存后，开局按新顺序尝试派单，工厂或许可暂缺的订单继续等待。
