# 0.32 存档 1 的单位属性重算

0.32 六家场景使用同一份 3,777 条记录的隔离快照。381 个单位、207 栋建筑和 5 个电脑阵营。程序和配置取自冻结源码，在 Windows 私有桌面用 Godot 4.7.2 图形 Release 测量。

基线一次 30 秒诊断记录 249,096 次重算，含计时探针累计 1040.469 ms。独立约 1/37 抽样的 2029 次同物理帧重复调用里，2 次改变了攻防或移速。成长更新之后可能执行状态、技能或行动逻辑，也可能提前退出。保留成长回调处属性发布时机。

候选把技能计时入口中增益到期后的重算合到该函数末尾。Ability.tick 只改技能剩余时间；其他入口直接推进增益时仍立即重算。动员兵先查交替推进是否生效，再查所属阵营与天赋；第二代成长移速按当前生效字段调用原公式，保持乘算顺序和数值。重算没有跨帧缓存和新存档字段。原版规则中 VeteranCombat、VeteranSpeed、VeteranArmor 在 extracted/rules.ini 第 16–19 行，本次保持原倍率与部署转换。成长天赋属于 Iron Tide 扩展。

两次诊断按共同兵种及各兵种较少的调用次数加权，239,124 次的等权对照为 4.179 → 3.819 µs/次。各局时序与同兵种的具体状态可有差异。
