# 永久研究直接使用战略核心与资源图标

远征研究读写局外核心余额，首至末节点消耗100至1000核心。移除兑换入口。旧档的剩余战略点在局外读档时按1:1并入核心，和删除旧余额一起保存。远征历史收益仍只结算军需券、核心。取代先前价格交接中的兑换方案。

统一消耗图标脚本 scripts/ui/resource_cost_icon.gd 生成并缓存九种轮廓。在远征研究、营地补给、事件维修包、常用单位养成和卡池消费入口按实际费用使用。券与钻石混付组合显示两枚图标。

隔离 Godot 4.7.2 headless 场景 expedition_pool_research 85/0、expedition_pool_battle 7/0、pool_demo_entry 40+16项通过。实测3124核心购买首格后3024，旧77点连续读取两次后共3101，验证各纹理可生成。视觉布局仍需在桌面成品包核对。

驻防基地顶栏三种余额各自显示同源资源图标与独立金额标签。主菜单余额、挂牌挂机收益、基地待领取收益、商店券库存、卡池碎片与券，以及科技和英雄部分付费按钮接入对应图标，新增皮肤券轮廓。隔离场景按截图的151000军需券、3250核心和5950钻石验证三组标签与纹理，输出 BASE_WALLET_ICONS_OK 3，技能卡40及天赋16项演示通过，opening_orders_regression 零失败。此轮验证为无头控件和金额检查。

英雄火力与生命训练改为按钮内居中排列说明、军需券图标和金额，图标紧靠数字，满级隐藏价格。隔离场景核对雷铸火力23级5416券与生命20级4600券，HERO_TRAINING_PRICE_ICONS_OK 2。独立长按回归31项通过。本次验证范围为界面节点、价格和输入逻辑。
