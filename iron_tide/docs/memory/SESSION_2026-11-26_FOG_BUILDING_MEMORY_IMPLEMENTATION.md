# 战争迷雾：建筑末次目击（2026-11-26）

## 决定和原版依据

用户确认实现：灰雾显示最后看见的建筑，而非透出实时建筑；再次侦察才更新或清除。原版依据见 [尤复调查](SESSION_2026-11-26_YR_FOG_BUILDING_MEMORY.md)：本机零售 `rulesmd.ini` 默认关闭常规回雾和黑幕回长，但引擎有独立 `FoggedObjectClass` 建筑记录路径。本次沿用 Iron Tide 已有灰雾开关、视野范围、到期及淡出；没有宣称逐像素复刻尤复。

## 实装

- `scripts/world/fog_of_war.gd` 发布玩家视野时只记录已看见的非友方建筑，包括中立建筑，以末次观察时的位置为键。`fog_building_memory.gd` 在已探索灰雾生成无碰撞、无战斗分组的显示节点，重见地块或玩家重遮蔽时更新或清除。看到出售或拆毁立刻清除，未看到则保留旧影像。同点新建筑不会在雾中覆盖旧记录。没有修改 `actor_visible_to`、AI、目标选取、碰撞或视野租约。
- `building.gd`、`building_turret_art.gd` 和 `ra2_art.gd` 复用建筑主体、损伤、展开、墙帧、活动层、房色、炮塔帧和 2× 图集的绘制参数，保存的是纹理路径和区域，不持有实体。程序化建筑用简化轮廓；驻军的独立车辆、血条、选框、烟火等不冻结。`minimap.gd` 复用相同记录绘制暗色方块，不提供敌方实时数据。
- `battle_snapshot.gd` 保存可选 `fog_buildings`，`battle_saves.gd` 校验记录形状、数值和资源路径；旧存档不会倒推未记录的历史，只会在重新获得视野后生成记录。未操作玩家存档。
