## 7. 结论与下一热点

固定场景同进程交替走 A 通用路径与 B 图集路径，各 2000 次车体提交，耗时 22.268 → 11.693 μs/次。 车体、炮塔、车体阴影三份原始素材各 32 朝向，共 96 组朝向数据；复用纹理、按素材身份弱引用共享，首次绑定需建表。未单独测首建耗时或进程增量内存。

两场 3× 均检出玩家主游戏，B 均值 223.037 ms，只列带负载结果。正式 A 的正/反序 141.041 / 160.868 ms 继续留存。尚缺两个空档 3×，跳过 1×，候选未写入开发树。通用精灵路径减少的慢帧时间有一部分转入体素提交。直接父级 sprite 减少 0.482 ms，整个单位绘制反升 0.653 ms。两侧最慢 5% 平均赶步 3.900 / 4.125，两场负载与画面内容有差异，剩余差额尚不能归因。
