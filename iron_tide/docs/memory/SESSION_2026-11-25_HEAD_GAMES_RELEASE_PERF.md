# 首脑游戏解放卡顿

原图任务依据见 SESSION_2026-11-25_SOV07_SCRIPT_AUDIT.md。困难难度从战役菜单出击，跳过影片，对两座存活信标依次调用 receive_hit(100000) 并检查胜负，测量这两个同步调用的墙钟时间。逐翼逐对象核对归属。

| 模式 | 苏军翼 108 个对象 | 盟军翼 128 个对象 | 两次选择面板刷新次数 |
|---|---:|---:|---|
| 修改前，无头 | 1274.87 ms | 3512.00 ms | 108、128 |
| 修改后，无头 | 153.24 ms | 85.26 ms | 1、1 |
| 修改后，1280×720 窗口 | 153.16 ms | 56.75 ms | 1、1 |

scripts/units/allied_abilities.gd 的 change_side 支持延后全局电力、选择和生产队列刷新。scripts/world/head_games.gd 在本次解放涉及的所有单位和建筑完成归属变更后统一刷新。其他调用默认立即刷新。

Godot 4.7.2 使用 res://tests/head_games.tscn -- --release-perf，各模式各跑一次。两次修改后测试均退出 0，标准错误为空。测量覆盖信标受击到同步解放返回，仍可见短顿。窗口显示后续帧、战役中后期存档、大部队接管后的持续帧率和发行包均待验证。
