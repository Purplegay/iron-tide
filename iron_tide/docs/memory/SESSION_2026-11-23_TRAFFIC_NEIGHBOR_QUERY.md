**最终决定：撤回避让候选。** 本地 v0.31.20 开发树的两个避让文件已按合入前备份逐字节恢复。兵种规则缓存和隐蔽判断复用保留。上次交付用同轮重跑的毫秒数决定合入，用户随后明确，以前一轮优化结束时已记录的整帧 P95 为固定基准。以后只有合入的优化才前移该基准。[隐蔽判断复用交接](SESSION_2026-11-23_SHARED_VISIBILITY.md)

## 查询耗时与行为复验

在另两场 3× 实战中，对每次避让刷新同时运行新旧查询，两侧使用相同的外层计时封装，并交错先后顺序。仅统计完整测量区间。存档 2 共 25,813 次，平均 8.091 → 7.279 微秒，下降 10.04%。存档 3 共 36,174 次，平均 8.421 → 7.658 微秒，下降 9.06%。61,987 次返回的单位和顺序逐项一致。初测时两边计时封装不同，约 13% 的初测结果由以上复测替代。固定散布场景每批 7,488 次查询，在合入前和合入后两轮中，候选四批中位耗时分别高约 1.2% 和 5.5%，局部收益随单位分布而异。[实战复测与日志](../../.validation/traffic-bucket-query-3x/) · [合入后固定场景](../../.validation/traffic-bucket-query-3x/live-qa/bounds/log)

候选短暂合入 v0.31.20 时做过独立复验。8,921 次边界及顺序比较零差异，覆盖相切、跨格、传送、移除重登、负坐标、碰撞层切换及全图查询。通行回归 872 项、部署回归 280 项全部通过。[当时的复验记录](../../.validation/traffic-bucket-query-3x/promotion/validation.log)
