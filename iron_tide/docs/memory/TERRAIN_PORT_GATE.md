# 地形移植画面验收

每次移植或重烘地形，用实际加载的 PNG 运行 `python tools/check_native_terrain.py 地图.json 地形.png`。`tools/bake_native_slopes.py` 已在保存前自动执行。工具扫描相邻格高差至少 2 层的边缘及周围一圈，统计同屏幕竖向颜色重复且横向有变化的采样比例。当前 80% 为经验阈值。已实景验收的好莱坞南桥头触线会中止烘焙，其余命中输出地图坐标、命中数。

把相邻告警格合并为一处，在原版等距镜头下同时查看道路两端、路缘、挡墙和桥面。对照零售地图格高、TMP 子块、坡向和延伸像素。保留同机位修前修后截图。涉及桥梁时另用实际单位下令，从桥头上桥、沿街穿过桥底、从桥面返回街道。把确认修好的区域加入回归覆盖。
