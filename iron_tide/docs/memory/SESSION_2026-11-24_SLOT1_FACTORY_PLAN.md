## 正式结果

存档 1 两场 3× P95 正序、反序分别为 236.827 → 220.668，185.571 → 179.181 ms；最好 185.571 → 179.181、均值 211.199 → 199.925 ms。1× 平均 FPS 18.806 → 19.292。已合入。 两次 3× 外部引擎审计通过；后台 CPU 估计 A/B [(22.6, 24.1), (17.8, 18.1)]%。独立诊断有插桩且战况推进不同，单场 P95 波动的原因没有完全定位。
下一热点是开火推进 _advance_firing。最慢 5% 帧中 10.758 → 13.893 ms/帧，每帧平均调用从 1286.7 降到 958.7，单次却从 8.361 升到 14.492 μs；全样本单次反而从 8.931 降到 7.661 μs。先拆冷却中检查、实际发射、命中及死亡回调，并按真实发射数对齐。当前证据只能定位到慢帧里单次调用变重。1× 反序 20.126 → 19.433 FPS，后台 CPU 估计还从 21.4% 降到 17.6%，具体回落原因未定位。开发树版本 0.31.31，正式比较沿用 v0.31.20 冻结链，活动源码清单 1358 项已校验。
