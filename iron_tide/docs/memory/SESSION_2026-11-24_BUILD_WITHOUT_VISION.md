# 迷雾中建造

按用户要求，`scripts/world/battle.gd` 的 `build_spot_ok` 移除了地基顶点视野检查。建造预览和实际放置共用此判定，继续检查建造范围、地图边界、桥面、地形、水陆、占用、数量与资金。预览移除了“仍需空地与视野”。`build_range_preview.gd` 的注释同步更新。

`tests/fog_rules_regression.gd` 替换旧的视野拒放断言。Godot 4.7.2 在独立用户目录中加载实际战场，单独执行新增用例。RA2 和扩展模式各 4 项，合计 8/8 通过。用例清空己方可见与探索掩码，检查未探索状态、空地合法、已有建筑拒放，并从点击放置处理函数实际放下一座电厂。验证范围为无头战场，未运行完整迷雾套件或做画面验收。
