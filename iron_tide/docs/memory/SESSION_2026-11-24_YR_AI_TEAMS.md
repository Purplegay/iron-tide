# 遭遇战装甲小队策略

1. 从 Steam 原版 ra2md.mix / localmd.mix 提取 aimd.ini，仅作本地对照。SHA-256 为 5df41eaec00a78d0760ef5eecdf27d65ae1cd537309c7eac973318266986f89d。
2. 追踪 TeamType → TaskForce → Script。0CA48EFC-G 和 06BC7B5C-G 用 3 MTNK 或 2 HTNK 猎矿；0CABE7DC-G 用 4 MTNK、1 MGTK、1 SREF 打工厂（显示名称称六辆灰熊，实际配方为四辆）。06BB841C-G 和 0C31CA7C-G 用 2 HTNK + 1 HTK 或 3 HTNK + 2 HTK 打工厂。
3. 当前单挑、多席位都从 Campaign.wave 分配十名守军，其余使用一个 attack_position。将专队接在进攻名册形成之后，沿用存档、战争迷雾和分帧调度入口。

4. 实装独立任务编组。盟军和苏军分别有猎矿与打战车工厂两种任务。先从同一陆地连通区凑齐完整战车厂打击队，再用剩余单位凑猎矿队。单次出击每类最多一队。任务共享本次已知敌情，检查武器能否攻击、是否有可达射击位置；多席位将成员和目标随现有派单写入快照。派发前再查敌我和可见性。普通部队沿用原有攻势，缺兵不阻塞出击。
5. 用现有攻击光标版冻结 A 和同一存档、引擎、种子开始两场 3× 图形测量。策略功能与性能基准分别记录。先用原版 83 项战役断言完成冒烟，再增加单挑及多席位实单、编成与派单中途读档断言。

6. 第一版正序 141.041 → 215.117 ms，反序 160.868 → 227.616 ms。B 其他进程 CPU 33.63% / 35.91%，历史 A 13.8% / 13.5%。专项用例修正：原固定坐标是原生地图无效地形，改用当前席位集结点所在陆地区；单挑夹具先完成出生集结，再检查实际可出击名册。最后 127 项战役及 29 项派单断言通过。扩展作战旧套件 466 项中有 12 项涉及飞机与间谍失败，去掉本次改动的开发树对照复现了同样 12 项。
7. 第一版另跑带计数的存档 1。93.68 模拟秒内，41 次出击规划总耗时 39.373 ms（含主力原有目的地计算），完整专队 0，发出专队订单 0。本样本无法用专队交战量解释正式整帧退步。复核 aimd.ini 的 0A6E452C-G 与 09B575AC-G 后，第二版增加 2 辆 SREF 轰击武装防御建筑、3 名 SHK 攻厂，并沿用同一派单和可见性机制。开始第二版的单挑、多席位实单、读档、两场正式 P95 与自然触发诊断。

## 第二版结果

单挑与多席位、盟军与苏军四个场景覆盖真实攻击命令、隐藏与易主、十名守军、派单中途存读档。战役 131/131、派单 29/29、堵路 18/18、交战 104/104、战术 62/62。综合作战 454/466；未修改的开发树重复同名 12 项飞机和间谍失败。

| 存档 1 | A 正序 / 反序 | B 正序 / 反序 | B 两场均值 |
| --- | --- | --- | --- |
| 3× 整帧 P95 | 141.041 / 160.868 ms | 219.846 / 196.246 ms | 208.046 ms |
| 其他进程 CPU | 13.8% / 13.5% | 22.9% / 37.4% | — |

同一存档、引擎和初始状态，冻结 A 与 B 只有五个策略相关脚本不同，两场无其他游戏引擎。局部插桩另场推进 93.35 模拟秒，49 次出击规划中有 5 次凑齐光棱小队，共分配 10 个席位，9 次专队攻击请求实际进入派单入口。此处分别统计编组和提交，不将它们当成击杀或命中。整个规划段（含原有主目标选择和诊断输出）累计 65.818 ms，单次最高 2.671 ms。该场最慢完整帧 316.18 ms，其中逻辑 209.26 ms。正式 P95 差异的具体归因未证实。

两轮均未通过正式 3×，跳过 1×。已从默认开发树撤回本轮策略及专项改动，核对其余源文件与改前开发树对照一致。开发版 v0.31.31 的独立可运行候选在同目录验证区的 strategy-project/project.godot，六个源码及测试文件与验证快照逐项核过，完整差异见 yuri-teams.patch，已在开发树验证可正向应用。新策略复用既有出击时钟，未新增每单位轮询。原版触发权重、缺兵生产、完整脚本后续动作未移植。

下一项策略重点是让生产队列按可见目标补齐缺编队员，同时给无目标和等待过久的小队退出条件。性能侧应对齐慢帧中逻辑与寻路实际开销。原始证据在 .validation/yr-ai-strategy/，含两版正式成绩、计数场、专项与开发树对照。
