## 导弹候选裁决

0.31.20 攻击光标基线的 3 倍速 P95 为 141.041 / 160.868 ms。冻结候选的空档正序为 231.492 ms，已留存的反序为 187.773 ms，均值 209.633 ms。基线均值 150.955 ms。候选判退，跳过 1 倍速，维持原性能基线。两场候选 P99 为 274.197 / 208.182 ms。原始无插桩测量只保存分位数，无法还原精确的超 16 ms 帧占比。复跑命令为上一轮证据目录下的 `python -B bench.py 3`。引擎、存档、元数据及脚本和配置清单通过原有审计，跨日复用美术导入资源的逐字节一致性未验证。

## 谭雅详情页

0.32 使用 Godot 4.7.2 Compatibility。原版 TanyaSequence 的 Guard 0 帧映射到 TANY_0.png，页尺寸 2048 × 1314，缓存按 RGBA 计 10,764,288 字节。以独立图形 Release 进程画同一帧四次，每次实际调用成功。在纹理缓存为空时首次提交为 12.731 ms，其中取页 12.595 ms。在另一个进程调用现有 prepare_infantry 并等待异步预热，完成历时 59.716 ms，首次绘制为 0.101 ms，其中取页 0.004 ms。两个进程的后续绘制均在 0.011–0.028 ms。均为单次专项，绘制提交为主线程耗时。

历史版以原始存档 1、381 单位、207 建筑和 5 个电脑阵营再跑 30 秒，推进 93.55 模拟秒，当前或上一轮绘制引用均未找到后转取谭雅共享页的记录为 0。该场无法把旧样本 103 的尖峰归因于谭雅。诊断覆盖 272 帧，其中超过 16 ms 的有 272 帧。最慢的 14 帧平均每帧包含 2.93 个物理步，物理回调合计平均 124.00 ms。有效视口 GPU 样本 P95 为 2.26 ms。这些是历史源码上的诊断数据。
