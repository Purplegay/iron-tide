## 未解锁篇目也可点击

未收集的残章使用与已收集篇目相同的独立问号。点击锁定的章节、残章或日记不足的活动标题，也会在列表上方显示来源。日记足够时，标题仍按标价解锁，问号可免费查看。残章已带回但尚未相遇时，提示给出雨棚相遇条件。

## 初版

`scripts/screens/yuriko_school.gd` 在学期章节、日常活动和已收集残章的每一行放置独立的书本问号。悬停显示来源，点击将来源显示在列表上方。篇目尚未开放或日记不足时仍可查看。说明依据 `yuriko_field.setup`、`Bonds.settle` 和 `Book.available` 的条件编写。

`tests/yuriko_school_regression.gd` 从每个章节和日常活动所在行触发问号，核对提示和阅读状态。独立用户目录下 Godot 无窗口场景回归通过，校园 1268 项，远征 284 项。日志保存在 `%TEMP%/YurikoHelp-020846/`。实际窗口中鼠标悬停的视觉效果和发行包留待验收。
