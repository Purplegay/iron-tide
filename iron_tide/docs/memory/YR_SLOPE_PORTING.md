# 尤里的复仇斜坡移植

2026-11-25 用户定调，所有地图斜坡以《尤里的复仇》零售地图为准。读取地图格高、对应剧场 TMP 子块的坡型和方向、延伸像素与剧场色表。按原版等距坐标合成整段路面后，按四角高度采样。坡顶和坡底的相邻平地也可能含坡面的延伸像素，战场验收应看道路两端、车道线、路缘和人行道。

`tools/bake_native_slopes.py` 逐格对照导入的坡型编号与原始 TMP 子块，异常时报告地图坐标及子块。四角映射已与 `refs/ts-ra2/src/game/theater/rampHeights.ts` 的 0–20 号条目逐一比对，通过 21/21。

好莱坞左上角回归位置为科技医院旁 (81.5,48.5)。本轮用 NEWURBAN 素材重烘 1286 个坡格和 38 个相邻平地格，整幅图与此前实机验收的地面纹理逐像素一致。本轮验证覆盖地形纹理和坡型数据。车辆在坡面上的俯仰、按高度寻路及其他地图的实景验收仍需单独验证。历史窗口验证见 [好莱坞道路坡](SESSION_2026-11-25_HOLLYWOOD_STREET_SLOPES.md)。
