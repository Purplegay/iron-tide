# 3× 渲染几何缓存与武器目标规则缓存

沿用兼容冻结版 v0.31.16、地形行索引和销毁特效池。两档各保留玩家与五个 AI，1600×900 私有桌面，图形 Release，每场约 30 秒，正常渲染和模拟。16 场 3× 无插桩候选对照均报告外部游戏负载。1× 两档平均 15.7/19.1 FPS。全部证据及独立候选保存在 [运行目录](../../.validation/target-domain-cache-3x/)。

用户明确同意大胆用空间换时间，包括渲染缓存。每个候选独立与其基线对照。以下两个候选均未合入。

## SHP 动画帧

候选在 manifest 加载时为有图像的帧预解出裁切矩形和图集矩形。缓存随素材清单回收，所有使用同一素材的单位共享；每次绘制仍使用当前目标坐标、比例、色调和水线。全量 150 份清单、19,212 帧，其中 11,362 帧非空。三组比例逐项比对目标矩形及图集区域，差异为零。私有桌面真实渲染 13 种素材各 3 帧（含水线、缩放与着色），ABBA 四次画面 SHA256 相同。抽样画面不覆盖全部实战视觉状态。

每遍全量非空帧几何微基准，各进程 8 次计时中位数，基线 6.549/6.625 ms，缓存 1.465/1.999 ms，累计校验值一致。全清单加载前后采样 OS 进程私有提交字节，缓存组比基线组平均多 1.54 MiB，为进程估计；单纯两个矩形的数值字段为 363,584 字节。加载耗时基线 109/109 ms，候选 121/111 ms，包含验证脚手读取。实战独立采样中，两档计时窗口内的完整帧间分别记录 10,628/11,749 次几何绘制。局部微基准按调用量外推，每秒仅约节省 0.2 ms CPU 时间。

## 武器目标判断

第二个候选每单位增加一个枚举值，在 unit_id 赋值时更新，区分普通兵、碾压、乌贼、炸弹、寄生和突击队。护盾、可见性、阵营、浮潜、目标、武器和特殊状态逐次读取。两种规则模式、十种攻击兵种、七种目标以及同实例更换 ID 的对照中，2,240 次资格判断和 200 次分类检查零差异。微基准每批 11,200 次调用、5,920 次允许，两组耗时重叠。两档整帧首对下降，反序后上升。当前没有可重复的整帧收益。

无候选的独立互斥分段探针按整帧排序取最慢 5%，单位为平均 ms/慢帧。两档的动态目标准入（含隐蔽判断）1.34/1.40，世界可见性 0.97/1.04，空地/弹体判断含 C4 0.49/0.58，兵种等前置判断 0.53/0.55。下一轮优先检查同一次资格判断里两处对隐蔽与反隐的重复查询，并核实哪些场景有实际重复。若做复用，应验证观察方、指定攻击、探测器变化、接触揭露、迷雾和水下目标的语义。参考网页 RA2 的 CanvasTextureAtlas 按图像查矩形及 Yuri 重建的 SHP 帧边界接口，均未用作性能基线。

全量整帧运行及探针的源文件审计均无运行中变动。开发树的当前性能及 3× 稳定 60 FPS 尚未验收。
