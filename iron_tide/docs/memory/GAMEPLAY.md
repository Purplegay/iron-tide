## 英雄契约

炉火、守望者、北辰、铁脊的徽章、W／被动奖励、等级、演示、升级及快速装配统一维护。未获奖励不可装配；已装配显示状态。未获得契约共用每抽0.35%，命中后等概率选择、不重复，全获后退出池子；目录及入口动态读取配置。

早期炉火“未实现”快照不能覆盖后续实现记录；同样不能用一次UI回归宣称所有旧机制缺口已补齐。任务和W破盾等细节仍查原文与当前源码。
