# 机场飞机出击后返航

玩家指定的目标提前阵亡时，Unit._refresh_target 会结束攻击。旧的 _finish_target_order 清理了追击，只有遭遇战 AI 另有带弹返航的兜底。现在 _finish_target_order 在处理后续命令后，对仍处于飞行状态、没有后续移动或攻击且带 AirportBound 标记和有限弹药的飞机调用既有 request_return，由后勤系统分配停机位。后续移动和攻击命令优先。

在 tests/logistics_regression.gd 加入从机场起飞、离机位超过 90 世界单位、目标先死的场景。RA2 和扩展模式的入侵者、黑鹰均能带弹返回并停靠。Godot 4.7.2 隔离无头战场，后勤 206、机场命令 50、真实物理步进近 24 项全通过。单机打空后的既有回归修前也通过。额外实测四架入侵者从同机场同时攻击，全部耗弹后返回各自机位并补满，四架距各自机位皆为 0。结果和编队探针见 .validation/plane-return/。未使用玩家原局存档，未复现仍有活目标时另有空弹不归的问题，未测试无可用机位的玩家现场。
