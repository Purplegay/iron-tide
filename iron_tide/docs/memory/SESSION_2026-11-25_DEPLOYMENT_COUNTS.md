# 远征招募和出战数量

普通招募和特装招募按整批入库。保存和读取存档时保留超额步兵。营地补员服务仍按兵种缺额计算。手动出售仍需玩家操作。

army.gd 的 deployment 按已选兵种顺序、可用库存、兵种限额、玩家保存的数量和本章出战人口拆分出战与预备行。援军计划只使用出战行。胜利和撤离先计算实际参战者的超时空减时，再合回预备行。旧存档缺少 deployment_counts 时默认在限额内尽量出战。

roster_box.gd 出战卡片右端设置小号 − / +，减至零撤下兵种。满编招募新兵种进右栏。screen.gd 分列出战编制、出战人数、预备人数。
