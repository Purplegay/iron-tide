# 盟军终关战场黄标与尤里超武视野

玩家截图雷达有黄菱形、战场没有。对照好莱坞任务标记入口及 ALL07SMD `0460BDBC` 脚本生成 YAGNTC 与 YAPPET、后续 Detect_PD/Detect_GM。发现 Battle 战场绘制白名单漏了盟军 01/07，前一轮只验了标记数据；另通用 `broadcasts_superweapon` 白名单漏了精神控制器和基因突变器两种战略类型，导致迷雾广播、警报和 HUD 也没有走到它们。

`battle.gd` 连接可测试的实际战场 draw 回调，补两关；原黄金主目标与清剿红标不变。`building.gd` 登记两类超武走通用逻辑：建成广播、实际揭开周边视野、充能警报栏、发射展露和存档重算，共享战役与遭遇战，不影响战术支援名单。`ra2_sfx.gd` 登记原版 EVA 检测键；`allied_finale.gd` 脚本生成后调用一次建成通告，不伪装玩家放置。旧档的活超武按迷雾重建重新广播，不重放建成警报。未改变超武发射逻辑、脚本充能设置或胜负。

Godot 4.7.2 真实菜单隔离无头 49/49、独立进程雷达后冷读 5/5，exit0 stderr 空。日志 `.validation/finale-target-broadcast/`；检查实际战场 draw 连接、黄色主目标数据、两座超武在玩家视野内、警报栏显示。未有头核对标记像素位置、未现场试听、未验两座已建成状态的专门旧档/跨模式图形回归，未更新发行包。
