## 正式裁决

存档 1 的 3× P95 正序 197.655 → 236.827 ms，反序 214.302 → 185.571 ms。最好 197.655 → 185.571，均值 205.978 → 211.199 ms。跳过 1×。候选未合入，活动 A 仍为此前建筑选址上限前置版。 两场正式测试后台 CPU 占用估算（A/B，%）[(29.4, 22.6), (33.5, 17.8)]。正式外部引擎审计通过。专项只覆盖同批重复拒绝；独立采样的战况和慢帧构成不同，无法将整帧变化归因于单一函数。

下一热点：当前 A 的 train_army 在慢帧占 5.436 ms，B 为 3.636 ms；两场各调用 76 次，单次平均 3.591 / 3.578 ms，几乎相同。继续做阵营规划时先分别测工厂队列计数、建设预留资金与可见敌情。尤复 rulesmd.ini 第 78 行 TeamDelays 为按难度控制检查/组建队伍的间隔，其含义与每个工厂的生产队列不同。建设订单在进入存档之前如何累积尚未由本轮复现。固定样本读取的首次诊断脚本因 Variant 类型推断未能编译，显式指定类型后通过，首次结果作废。
