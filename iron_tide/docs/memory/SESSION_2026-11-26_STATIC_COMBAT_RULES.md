# 2026-11-26：战斗静态规则在加载时预解析

## 实际改动

- `scripts/autoload/game_data.gd::reload()` 在 RA2、尤复、扩展和能力覆盖合并完成后统一调用 `rebuild_static_combat_rules()`。重新加载会清空并重建派生表，不写原 JSON、不存入存档。运行期读取共享规则；直接编辑原始字典的测试夹具需要显式重建。
- `AG` 只在加载时解析，查询按当前武器的 `ra2_projectile` 查禁止对地集合；删除 `unit.gd` 每次扫描创建的临时弹体缓存，`skirmish_micro.gd` 使用同一查询。缺失/未知/空 ID 都不拒绝地面；`AG` 沿用旧路径的大小写、空格及默认值语义。弹体墙体阻挡、破片武器/数量和投弹加速度也预解析。
- 弹头：心灵控制、超时空、辐射、友军伤害、墙木伤害、死亡武器、亮光/火花/摇晃、特殊随机命中特效标志、变形参数、伤害距离/卧倒参数和命中动画列表。武器：音波、激光、辐射束、电弧标志及共享只读光束配置。单位原生地面/水下目标规则、同型音波免疫和超时空免疫也移至共享规则；超时空免疫仍按能力覆盖整行替换，而非混合两行。
- 不缓存整把运行期武器或最终攻击许可。主副武器、英雄对空增益、目标飞行状态、潜航与距离、房色、阵营、视野、墙体占点、伤害事件和随机动画仍在原入口实时判定。
