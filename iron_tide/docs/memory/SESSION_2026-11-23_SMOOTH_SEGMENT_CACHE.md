## 实验和范围

在隔离副本中，对静态通行网格的拉直检查，按通行类型、起点和终点保存可通行或阻挡结果。地形版本、格子尺寸或地图行列变化时清空；首次使用某种通行类型时保存网格副本，每次进入该类型的拉直逻辑时核对副本，使同版本内直接修改通行格也会失效。带临时单位阻挡的路径逐段检查。每种类型最多保留 64 个起点，每个起点最多 256 个终点。原有通行格扫描顺序、拐角和路径选择规则由新旧输出对照验证。

在已接受版本的两档图形实战里另跑探针，按地形版本、通行域和有方向的精确端点统计。探针每种域每代最多保留 4,096 条线段和 256 条整路。下表表示该窗口中的重复频率，候选用分起点限量表，二者缓存容量和替换方式不同。
