# 远征逐家击败播报

远征走独立任务结算，旧版只检查全场敌方建筑余量。`scripts/expedition/objectives.gd` 在每秒任务检查中同时收集仍有建筑的敌方阵营，按敌方席位判断各家建筑是否清零，将已提示阵营记录在任务状态 `defeat_notices` 中。建筑沿用远征原判定，包括防御建筑。最后一家先提示再结算。此改动只涉及提示，残部继续按原规则行动。

`scripts/world/house_elimination.gd` 抽出原有 `announce` 供两种模式共用。每家单独显示文字，同次检查中多家清零时共享一次 EVA 语音。

Godot 4.7.2 在独立用户目录启动真实远征战场，设置双敌军歼灭关并依次将每家建筑 HP 置零。首家清零时 HUD 显示、语音播放或入队计数加一、战斗继续，重复检查无第二条，末家清零在胜利前发出提示。原遭遇战回归通过 61/61。无头测试覆盖事件顺序和音频调用，实际扬声器听感及冷读档未验。验证脚本和日志在 `%TEMP%/CodexIronTideValidation-Defeat-8fe80ac2450b48689859af32669c8dbc/`。
