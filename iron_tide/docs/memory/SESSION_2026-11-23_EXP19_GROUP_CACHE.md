# 第 19 关混编头像缓存

用户接受用空间换时间。scripts/ui/hud.gd 按兵种及英雄身份保存本场曾用的分组头像控件，清空时移入隐藏池，再次框选时重用，数量、血量、军衔与当前成员重新绑定。缓存随 HUD 销毁。

同主档 66 人、8 组，窗口回放顺序为旧、新、新、旧。重复框选同步耗时依次 22.873、8.552、8.690、12.645 毫秒。首帧依次 62.832、45.352、44.664、48.578 毫秒。两个新版回放各复用 8 个相同实例，均显示 66 人。首次框选均为零命中，样本不足以评估整局帧率和内存字节增量。回归 208 项通过 200 项，8 项既有混编右键断言与上一版相同。
