## 高低层修复

用户确认问题是缺少高低层。yr_hills 三座木桥改用桥下原图和独立零售 SHP 桥面。引道 TMP 821、823、824、826 的三个可走子格给出六端共 18 个入口。两种桥向按各自纵轴投影，复用战场右键分层路线与车辆接地偏移。桥面限制侧向离桥和跨断口，跨层单位物理碰撞放行，断桥只击毁坍塌段上的桥面单位。高度和桥头渐升沿用既有 45 像素 / 三格近似，未逐像素复原原版断面。

验证使用隔离 APPDATA。tests/hills_bridge_layers.tscn 实际扩展遭遇战，40 项通过，窗口和无头运行均通过。三座桥逐格调用移动层级与点击逆投影，长桥另用灰熊坦克实际右键沿地面横穿桥底、由入口驶上桥面。长桥测试坍塌时上层死亡、桥下存活，断口禁点和修复后恢复点选。好莱坞战役 --bridge-tech 59 项通过。日志 %TEMP%/hills-final.out、hills-budget.out、holly-layers.out。短桥未逐端实车下令，大编队、玩家旧档冷载、工程师现场修桥和截图同机位目测未覆盖。未打包。
