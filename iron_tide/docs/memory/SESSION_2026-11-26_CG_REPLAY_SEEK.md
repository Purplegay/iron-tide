# CG 收藏回看：可拖动进度条

用户追问回看进度条。`scripts/ui/hollywood_film.gd` 仅为收藏回看增加 HSlider 和当前位置/总时长；拖动期间暂停画音、松开单次定位，继续播放并按目标时间更新字幕。普通片走 Godot 4.7.2 原生 Theora seek，独立音轨按相同时间重启；盟军 A01/A07 伊娃简报沿用片尾留帧，时间轴含完整续音，可拖入续音、拖回视频段或到片尾自然返回。战役内全屏、雷达小窗、收藏发奖和存档不变。已安装技能和仓库技能源文件同步把可拖动回看纳入门槛。

片源沿用既有零售影片和音轨，未重烘媒体。Godot 4.7.2 隔离 APPDATA 无头运行 `res://tests/cg_collection.tscn` 25/25，独立 `-- --cold` 69/69，均 exit 0；seed 唯一警告来自主动模拟写盘失败。通过真实菜单进入收藏，注入鼠标按下、移动、释放，在苏军片检查前后拖动/独立音轨同步，在盟军 01 伊娃简报检查拖进续音的留帧、音频位置和字幕、拖回后恢复画音、拖到末尾自然关闭。另用真实 A01_F00E `.ogv` 探针验证内嵌音轨影片的视频时钟支持前后 seek，未实听。日志 `.validation/cg-replay-seek/{probe,seed,cold}.{out,err}`。未验有头渲染/实际音响、未逐片拖动其它影片、未打包发行。
