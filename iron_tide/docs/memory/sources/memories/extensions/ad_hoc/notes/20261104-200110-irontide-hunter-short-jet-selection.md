# IronTide · 猎隼皮肤尾焰比例和选中灯效

本条更新猎隼外骨骼案例，覆盖早期记录里全喷时采用长尾焰的描述。用户指定全喷短小粗壮，焰腹贴近喷口。v0.25.21.1 主焰轴向基准为 20 个 TNKD 模型单位，三股外圈火最长伸出 13；起步仍是叶轮高速转、先绕一圈再全喷，转向焰根随车、末端偏移，停车渐熄。其他型号按各自喷口与车体比例重测。
选中规则针对灯光。战场初始静止，选中时炮上四根主灯管错拍心跳、侧板四灯缓慢呼吸，八根均有柔光外晕；取消选中后 3 秒逐步减频，颜色与亮度停在当时状态，再次选中续播。工房直接演示。涡轮按车辆运动驱动。
