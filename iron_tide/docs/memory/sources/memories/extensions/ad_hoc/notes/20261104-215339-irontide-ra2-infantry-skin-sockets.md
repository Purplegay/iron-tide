# IronTide RA2／尤复人物皮肤制作规则

用户要求以重装大兵「岸防导弹手」为案例。新做或返修步兵、英雄皮肤时，从该兵种自己的 SHP/序列逐帧定位肩背或关节挂点。挂点位置、身体朝向分别校准；共用的单向待机片段若自行转身，应按动画帧决定配件朝向与遮挡。不得照抄 GGI 的坐标、房色阈值或朝向表。
行军随身、部署按装具选择固定位置，过渡连续；远近分层，侧视不叠在武器上。留八向站立／部署对照及完整待机动图，对单向待机用相反命令朝向逐帧对照，验证移动、部署、开火打断后的衔接。
参考 C:/Users/admin/IronTide/docs/MODEL_RENDERING.md「RA2 人物皮肤的逐帧挂点与遮挡」及 docs/fixes/v0.25.24.1/README.md。GGI 已处理 222 个动作帧，两段待机各 15 帧。记录时守望者与炉火沿用 E1/E2 原版待机，英雄装甲方向仍取 fidx，其专属待机与逐帧转身适配尚未实现。
