# IronTide 武器冷却圈约定

用户于 2026-11-02 确认。适用于 RA2、尤里的复仇（YR）、RA3 和起义的所有阵营。制作苏联单位、移植其他单位及回查旧单位时，都沿用此约定。

- 按实际独立装填的武器或炮位显示冷却圈。共用弹匣、轮流开火的双炮共用一圈；同种武器若在不同炮位独立装填，则各占一圈。射界外未开火的炮位保持就绪。
- 只展示当前武器模式。切换后显示新模式的炮位；切回时读取真实剩余冷却。乘员改变多功能步兵车的武器时同步更换颜色。颜色跟随武器种类，同一武器换座位不变色。
- UI 仅读取实际武器的连发间隔、弹匣装填或攻击冷却；依据该单位所属游戏的武器配置和运行逻辑核实。RA2/YR 核对自身规则及老兵、精英或部署武器。不得按炮管外观推算，也不得为小圈另开倒计时。
- 收割者的火箭和三门榴弹炮共四圈；先锋炮艇的对撞炮模式两圈、前机枪模式一圈。YR 战斗要塞满载五名武装乘员时共六圈，两行三列，车体武器在前、乘员按登车顺序。其他新增单位若同一模式超过五圈，先向用户确认布局。
- 展示和回归入口分别为 iron_tide/scripts/ui/attack_cooldown_indicator.gd、iron_tide/tests/attack_cooldown_indicator_regression.gd 和 iron_tide/tests/ra3_reaper_cooldown_regression.gd。增加 RA2/YR 单位时，同样检查开火、装填、武器切换和读档后的显示。
