# IronTide RA2／尤复专属皮肤开发准则

用户指定今后盟军、苏联的专属皮肤立项和重做以猎隼外骨骼的创意和完成度为基准；见 C:/Users/admin/IronTide/docs/MODEL_RENDERING.md 的「RA2／尤复专属皮肤开发准则」。每款先说明兵种专属主部件与可辨识的招牌动作，区分主辅节奏。造型、连接、材质、特效挂点以及动作收尾要经得起近看，只做通用换色和粒子不足以立项。
猎隼主灯管指炮上四路错拍心跳，侧板四灯五秒慢呼吸，全部带柔光外晕。涡轮起步高速旋转，蓝焰绕圈后向车后全喷，转向焰根随车、焰梢拖曳。参照这一层次为新兵种原创，具体装置、节奏和坐标按型号重定。
验收覆盖战斗默认倍率、工房近景、体素 32 向或 SHP 实际动作、真实命令过渡与原生炮口，留游戏内动图。自动验证与玩家观感确认分开记录。
