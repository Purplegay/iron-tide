# 载具生产点击卡顿（0.32）

截图显示工厂队列 50/81，已排光棱坦克 30 辆、幻影坦克 20 辆。修前每辆车入队都会同步通知侧栏，点击处理结束又刷新一次。每次刷新遍历当前生产卡，重新计算可用状态和说明。订单变化还会更新底部队列控件。

现版本仍逐辆检查产能、空位、前置与单位限制，追加后立即令在训人口缓存失效。一次操作有订单入队时，工厂在结尾播放一次生产语音、通知一次队列变化。跨厂点击先选定目标厂，再由该通知更新面板。暂停队列的左键恢复也使用工厂通知。

## 点击复测
