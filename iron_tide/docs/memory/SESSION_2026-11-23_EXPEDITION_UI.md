# 2026-11-23 远征交接

用户要求每次完成项目工作都主动写入跨会话记忆，记录改动、查实的机制和验证范围。

- 战地接驳。`runtime.gd` 和 `relics.gd` 规定首次维修开启 10 秒窗口，手选后该批剩余等待减半，超时选最后一批。Godot 隔离验证手选、超时、同批多单位和空队列。
- 实验室。`objectives.gd` 的地图点 0、2 分别读取两座实验室的进度，各自满 45 秒就显示绿圈和「✓ 已接管」。四种完成组合通过隔离检查。
- 单位生产页。`hud.gd` 的远征目录按当前工厂、页签和 `queue_block_reason` 过滤。工厂替身验证五种列表状态。
- 资源栏。`screen.gd` 使用 24 像素补给箱和维修十字，图标随名称和数量整组换行。Godot 隔离检查纹理和宽窄布局。以上检查均为隔离测试，完整实战画面待复测。
- 磁能坦克。代码核对确认第 11 关起，变电所最后一把钥匙和双曝光底片可将 TTNK 加入候选目录。定向货位从候选中按羁绊选取。普通「许可与增援」成功招募发放本轮许可。TTNK 的 RequiredHouses 为 Russians，盟军可用招募增援，制造仍受国家限制。
- 商店货币规则的详细记录见 `SESSION_2026-11-23_MARKET_CURRENCY.md`。远征禁止补给买补给，清除旧未售补给商品（含锁定）。战后事件避免并列 60 和 100 补给，免费首项改为一次免费刷新，维修包兑换显示库存和需求。
