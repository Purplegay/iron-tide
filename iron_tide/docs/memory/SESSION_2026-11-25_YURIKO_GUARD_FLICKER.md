# 百合子心灵控制守卫标记

截图中出现受控单位周围的亮斑和连接施法者的细线，按 Lure 持续状态定位。原烟光每批 2–5 个，寿命 2 个源动画帧，另有辉光、火花及连线噪声滚动。

`scripts/units/yuriko_power_fx.gd` 在 Lure 入口创建固定透明度的淡紫色圆环和细线，持续跟随单位、检查视野和控制状态。其余施法事件仍走原粒子流程。

`tests/yuriko_guard_visual.tscn` 用 Godot 4.7.2 OpenGL Compatibility 实跑手记的技能演示按钮和等级切换，确认守卫数 3/5/7。把演示创建的一个守卫标记移入透明视口，固定两端，连续读取 90 帧，图像非空且像素完全相同。验证范围为演示入口和持续状态标记，截图对应的战局及其他动画仍需单独复现。本轮改动在项目源码，未导出发行包。
