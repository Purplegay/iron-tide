# 玩家单位受击反击

`unit.gd` 的 receive_hit 原本已为玩家保存攻击者，但只有 AI 会被新接触立即唤醒，玩家的常规评分也可能继续选择旁边的单位。玩家受到新的有效敌对命中时现在提前刷新目标。在自动防卫和仅还击姿态，优先检查攻击者是否属于当前武器的合法射击目标。显式集火与进行中的连发优先，追击距离沿用既有规则。

在 tests/automatic_defense_regression.gd 增加场景，让玩家灰熊在附近有敌军步兵、扫描计时尚余 0.3 秒时受到建筑伤害，运行一个物理步并核对目标。Godot 4.7.2 无头运行，独立用户目录。两套规则修改前共 132/134，新增用例均失败。修改后 134/134。ra3_apocalypse_retaliation_regression 修改前后均为 37/41，通过天启中弹还击并击伤炮塔的断言，失败项均为部署直升机的光标、起飞、起飞脱钩和二次降落。原始结果在 %TEMP%/ITCounter231132 下，before 为移除本轮两处逻辑的对照。验证限于上述场景，未读取玩家存档或打包。
