# 桥梁移植交接

1. 对照原图和可玩边界，逐座清点高桥、低桥、断桥及维修小屋。逐端记录桥面宽度、引道、地面高差、坡向和边界裁剪。分别核查桥上与桥下路线、遮挡，以及每段损坏和修复后的通行。
2. 好莱坞第二关曾出现坦克贴桥边突然掉到街面的故障。旧排序逻辑按车心所在格清除桥面状态。移植高桥时，让单位在实际移动后更新所在层，车身、阴影和选中标记共用桥面高度。车辆沿引道上下桥，完整桥面限制侧向越界，街道上的单位可从桥下横穿。
3. 用实际战场车辆走过引道，连续向桥边横移，再从桥头驶离。另从街道横穿桥下，核对高度和遮挡。逐桥记下实车走过的端点、测试的单位和编队规模，同时记录地形数据核查范围。
