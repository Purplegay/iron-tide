# 首脑游戏任务脚本实装

原始对照见 SESSION_2026-11-25_SOV07_SCRIPT_AUDIT.md。data/head_games_orders.json 保存九条回收厂输送线、十五个驻军编组和七十四条 AI 条件。本轮改动位于 head_games_orders.gd、head_games.gd、head_games_sites.gd、head_games_combine.gd 及战场胜负、生产和所有权入口。

* 用全灭条件处理玩家失败。城堡倒下后按任务时钟三秒释放两翼，欢呼并等待九秒结算。
* 九路村民/牛按来源房屋和回收厂存亡出发。居民抵达门口才消耗并记收入。西南回收厂失守时两翼按归属派出调查编组。新增牛的零售 SHP 贴图和动作，截图 [农舍路线](evidence/SOV07_FARM_COW.png)，拍摄时移除迷雾以便观察。
* 开局分派驻军、坦克进碉堡、尤里新兵进反应炉。城堡呼叫的工程师收到修理命令。东西墓室毁坏使对应灯熄灭，原图格子提示使用 CSF 原文 KBO AEO。地图绑定、路线、灯与队伍状态可随存档保留。
* 条件出兵接入地图 AI 表的房号、难度、单位数量/资金、比较算符、初始权重和兵力编组。三个房号分别选队、通过现有工厂付费生产、集结、出击或驻守。移除本关运行时通用五波计时器。原表一个 TaskForce 无兵员，选择时略过。现版共享敌方资金，选队间隔用 125 规则秒；不模拟原引擎的动态权重学习、每个 TeamType 的全部行动指令。混编 Alpha 关键成员损失后等待两秒再招募，出击后开始下一周期。未证明全部 KIA 旗标等价。
* 摧毁或占领敌方建造场会永久取消对应尚未建造的超武。修复本关尤里建筑数据遮盖遭遇战实际 superweapon 定义，现可充电，充满且有可见目标时会调用正式发射入口。发射仍受供电、视野与武器自己判定约束。

Godot 4.7.2 隔离用户目录六分支退出 0，无脚本错误或警告：--routes 7 项、--orders 17 项、全关 42 项、--sites 309 项、--combine 11 项、--nuke-voice 19 项。日志 %TEMP%/s07-retail-run-*.log。居民到厂、驻军进入反应炉使用真实物理步。路线另做快照捕获与同进程恢复，敌基因突变器以预充能测试夹具实际命中我方步兵。其他超武未逐种自然实等发射。全关用例手动推进部分时钟与胜负条件。未三难度人工通关、未导出发行包。
