# 指挥官信物按远征周目开放

第 1 周目 0 件，第 2～3 周目 1 件，第 4～5 周目 2 件，第 6～10 周目 3 件，第 11 周目起 4 件。commander_keepsakes.gd 统一计算容量。run.gd 在出发和营地补带时校验，出发按通关记录计算周目，营地使用当前远征保存的周目。旧档超额的信物在本轮继续生效，重新出发时按上限选择。screen.gd 显示数量与下一次扩容周目，出发时可取消已选信物，营地有空位才显示补带按钮。

在独立 APPDATA 用 Godot 4.7.2 跑 expedition_keepsake_regression.tscn，269 项通过。覆盖 1～12 周目的容量映射、二周目营地与出发限制、旧档超额组合在真实战场的指令和恢复。远征界面场景无头加载退出 0。验证范围为源码场景和隔离存档，未人工点击界面或打包。
