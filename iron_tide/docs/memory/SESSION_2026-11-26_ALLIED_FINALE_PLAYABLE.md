# 盟军终关《脑死》可玩预览

## 玩家入口与流程

用项目目录 `启动游戏.bat` 重开，战役 → 盟军战役 → 盟军任务 07《脑死（试玩）》→ 出击。非旧发行包。若旧大厅仍开着，退出旧进程再从当前工程启动。本轮只有终关，盟军 01 仍未开放，不用苏军 `yr_time_shift` 冒充。

开局五名工程师，在原图 DD 附近。选择工程师，右键受损的苏军建造场；接管后能使用该基地的电力。实际零售 rulesmd.ini 中苏军雷达 `NARADR` 需要 `NAREFN,NACNST`，必须先建苏军精炼场，不通过删前置或塞一座非原图精炼场绕过。落地雷达后 120+15 模拟秒触发基地车和护卫；基地车可在落点按 J 展开。摧毁南极心灵控制器并清理当前预览的敌军资产后进入普通战役结算。
