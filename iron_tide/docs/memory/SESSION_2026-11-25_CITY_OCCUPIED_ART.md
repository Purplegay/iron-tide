# 洛杉矶民房驻守外观

城市建筑原先只导出 SHP 第 0 帧，乘员数量变化后仍绘制空楼。为 54 种有城市专用贴图且原规则允许进驻的建筑补齐普通、受损和驻守三帧。绘制位置以空楼帧为锚点。首位乘员进入显示第 2 帧，末位撤走依据建筑生命值恢复普通或受损状态。

Godot 窗口从任务入口运行 tests/hollywood_campaign.tscn -- --city-house，在机场附近 CAMIAM03 上验证右键进楼、归属变化、实际绘制帧 2、撤空后恢复中立及实际绘制帧 0。日志 %TEMP%/it-garrison-state-final.log。其余楼型使用同一选帧逻辑。
