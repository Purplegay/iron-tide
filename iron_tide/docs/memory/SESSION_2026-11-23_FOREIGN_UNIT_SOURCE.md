远征跨阵营兵种来源说明

scripts/expedition/screen.gd 在商店、奖励、事件和军团兵种卡上按当前国家和单位实际阵营显示外军来源。根据本轮训练许可匹配联系人，根据当前纪念品和第 11 关门槛显示伙伴招募渠道，同时展示生产许可状态。旧档缺少来源信息时仅显示可确定的信息。改动限于界面。

offer_partners 将伙伴加入 catalog，招募登记 licenses，战地联系人也能在胜利结算时授予指定许可。growth_pool 从 licenses 生成攻防商品。幻影坦克是背面朝外的袖镜的伙伴。坦克杀手可来自格蕾塔的训练许可，也可经伙伴招募。

Godot 4.7.2 隔离 APPDATA 无头实例化 expedition.tscn 并调用真实界面方法，第 11 关苏俄 MGTK 显示袖镜及待招募，TNKD 显示格蕾塔和已有许可，HTNK 无额外说明，三例通过。未读取玩家档，未进行屏幕排版目测或打包。
