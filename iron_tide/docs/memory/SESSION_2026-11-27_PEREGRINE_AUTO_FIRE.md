# 2026-11-27 游隼射程内自动开火

玩家反馈游隼不会主动攻击射程内的敌军。游隼是 ORCA 英雄，沿用原版入侵者的机体 ID，但拥有独立空中补弹。`unit.gd::_refresh_target()` 原把一切有弹仓的单位当作待命不索敌；即使通过该门槛，`_automatic_target_allowed()` 在玩家默认自动防卫姿态仍会读取 ORCA 的原版 `CanPassiveAquire=no`。
