# 遭遇战尤里阵营与海军

大厅玩家和电脑席位可选尤里。YuriCountry 映射尤里基地车、建造厂与生产设施。tools/yuri_skirmish.mjs 读取本机零售 rulesmd、artmd 与温带素材，生成 data/yr_yuri.json。遭遇战提供 16 座建筑与 16 种可生产单位，另有奴隶矿工与巡航导弹两种附属角色。战役单位与建筑继续取任务定义。

生产支持尤里兵营、战车工厂、水上船坞。YHVR 容量 12，单体上限 6。BSUB 用鱼雷对海，发射独立 CMISL 攻岸。已接入矿工经济、回收、克隆、心灵探测、基因突变、区域心控、实验室力场护盾与电脑海军生产及运输调度。

Godot 实际场景 tests/yuri_skirmish.tscn 在经典遭遇战模式通过 78 项检查，包括双方尤里预建开局、32 种模型、实际舰艇入队与水面出厂、步兵登艇卸载、巡航导弹命中岸上建筑、复制、两种超级武器充能释放。海运测试在出厂后移动运输艇至岸上以单独检查卸载，导弹测试直接推进飞行。tests/head_games.tscn -- --building-art 回归 32 项通过。两个进程均 exit 0、stderr 空。大厅双方选择项、16 种单位科技齐全可下单、十五格传感范围和施工停机也已验证。日志在 .validation/yuri-releasecheck.log 与 .validation/yuri-campaign.log。

未验收完整跨海 AI 对局、冷进程存读档和发行包。超级武器区域效果和导弹飞行曲线是移植近似。心灵感应器接入主动侦察、反伪装、反潜和对可见敌军指向己方的攻击目标线。尚未逐项验收全部单位精英武器、受损动画及全部剧场。
