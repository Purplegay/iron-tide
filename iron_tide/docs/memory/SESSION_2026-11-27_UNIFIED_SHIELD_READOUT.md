# 战场护盾读数统一（2026-11-27）

## 根因与玩家可见改动

战场单位 HP 入口已经能取到多种实际吸收盾的总量，但只调用了英雄重装/熔炉和余波接力两套盾条画法；其余只有单选/查看数字时可能发现，在未选中满血单位上尤其不明显。建筑又单独绘制 Brutal 的盾。原生罩壳的交接见 `SESSION_2026-11-25_UNIT_SHIELD_VISUAL.md`，本批统一的是血条和面板，不重做外壳。

`shield_readout.gd` 把同一份真实耐久用于 `unit.gd`、`building.gd` 的战场血条和 `hud.gd` 选中面板。`hp_bar.gd` 集中定义青蓝色、上方细条、己方数字和防护状态；重装盾与余波接力旧私有盾条移除。多盾加总，有正余量就保留至少 1 像素填充；上限全部已知时按合计上限画，部分上限未存的旧状态用 HP 与已知上限取大作为显示尺度，不虚报上限。己方未选中也显示盾的剩余点数，敌方在战场只显示条形；选中面板沿用既有可查看规则，提示列实际来源。铁幕、力场、救援保护、百合子自身灵能护盾不消耗盾点，显示“防护中”；没有可消耗盾时只画空心提示。不把范围内盟军一律宣称为无敌，百合子领域按原有来源与距离决定拦截。只读展示，未改吸收顺序、技能或存档格式。
