# 百合子礼物报价刷新

私信与礼物页新增全店报价刷新。使用既有战略核心钱包，每个本地自然日的首次手动刷新免费，之后依次扣 10×2、20×3、30×3、50×6，再固定每次 100。零点自动报价与手动次数分别计算。付费按钮显示核心图标及本次费用。

`yuriko_bonds.gd` 以日期和当日刷新次数生成三件礼物各自的报价，零次时沿用原报价种子。次数与余额一并保存，失败时回滚。购买和刷新校验报价日期及次数。`screens/yuriko_school.gd` 接入按钮和报价更新。

Godot 4.7.2 独立存档运行 `tests/yuriko_school_regression.tscn`，1323 项全部通过。新增覆盖零余额免费刷新、余额不足、连续 16 次付费显示和扣款、重载次数与余额、异日计数及过期购买报价。失败写盘警告来自既有购买回滚测试。跨日使用日期参数验证，未实等零点。验证使用源码场景。
