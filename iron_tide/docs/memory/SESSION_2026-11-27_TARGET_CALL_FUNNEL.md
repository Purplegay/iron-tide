## 结论与后续

准入拒绝的扫描已经被截断，不能宣称省下 34,096 次枚举。拒绝前仍建立敌对分组字符串，可在保留现有调用时序的前提下审查是否推迟到准入通过之后，至多减少本场 34,096 次轻量调用；历史全入口 `foes_group` 为 62,358 次累计自身 17.48 ms，优先级低。不能把整个准入直接前移，因为前方命令恢复、现目标失效、子类继承及同帧队列/配额可有真实副作用。

更值得验证的外层入口是逐候选 `OpenTopped.command_range`：分开统计普通双武器、海军例外、特殊空军和有载员分支，查普通分支是否能在同一次扫描中复用已解析的能力位，而不合并空地武器或候选域判断。既有函数热点（旧原生记录，非本次探针）：`command_range` 全入口 83,193 次、自身 64.47ms、含子调用 586.83ms；`_weapon_for_target` 全入口 174,080 次、自身 71.39ms、含子调用 818.47ms。父子耗时不可相加，也不能把旧全入口毫秒按此次计数直接折算。

索敌部分未实现候选，未验证逐目标或跨地图行为。
