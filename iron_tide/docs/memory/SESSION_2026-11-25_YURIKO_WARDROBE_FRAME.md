# 百合子试衣间动态取景

原镜头仅在入场及调整倍率时按头骨高度取景。`scripts/screens/yuriko_school.gd` 现在每次推进姿势或旋转后将正交镜头对准当前骨架的世界包围盒中心，按水平跨度与倾斜相机的竖向投影限制拉近倍率，并给关节以外的模型留出余量。

`tests/yuriko_school_regression.gd` 从试衣间选择三套衣装及走动、施法，用最大倍率边播放边转一圈，每组采样 120 帧，检查全部关节落在 1024 方形视口的 16 像素内边距内。独立存档截到试衣间结束的 Godot 4.7.2 无头回归通过 1316 项。验证依据为关节投影，未逐像素检查衣摆、头发与灵能特效。完整回归后续战场加载遇到 `minimap.gd` 引用缺失的 `hollywood_mission.gd::markers()`，未完成。
