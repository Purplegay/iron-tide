候选修改 FlowField。原来确定一个格子的行进方向，需要在 Dijkstra 扩展后再遍历一遍相同的八个邻格。现在边更新邻格代价边选择方向。对角通行的两侧障碍检查、方向平局的遍历顺序和实际存储的浮点精度沿用原规则。优先队列上浮或下沉时移动沿途的元素，最后写入待放置的元素。ts-ra2 898d891 的 NodeHeap.up/down 也以这种方式搬移沿途节点。Yuri 重建 b01d3cf 中 FootClass 的路径代价和距离方法仍为存根。
