## 8. 正式裁决

沿用攻击光标版 A，两场 3× 最好值 141.041 → 187.956 ms，两场均值 150.954 → 221.024 ms（+46.4%），不合入，跳过 1×。

| 顺序 | A → B P99 ms | A → B 其他 CPU | A → B 模拟秒 | A → B 峰值单位 |
|---|---:|---:|---:|
| b1 | 195.265 → 237.939 | 13.8% → 25.0% | 93.23 → 93.51 | 403 → 407 |
| b1r | 196.581 → 290.403 | 13.5% → 25.6% | 93.48 → 93.57 | 393 → 394 |

局部在微秒级缩短，父级单次变化很小。B 两场外部引擎扫描清洁，但其它 CPU 占比高于历史 A；插桩轨迹中 B 慢帧也有更多物理步。两点都影响归因，无法据此量化整帧差额中由补丁造成的部分。整帧取既定历史 A，保留本轮所有样本。
