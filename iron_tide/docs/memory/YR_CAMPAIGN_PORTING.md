## 修改后整关复查

- 按任务函数维护检查表。每项写清触发条件、执行对象、玩家可见结果、中断路径和恢复行为。核对游戏内实际生效的房号、单位及建筑定义和科技前置。
- 用新的隔离存档目录，从战役菜单实际出击，分别验证胜利、全灭和关卡专属失败。用夹具推进计时、移动角色或造成伤害时，明确标注这些步骤。自然游玩覆盖单独记录。
- 遇到所有失败都集中在一张生产卡时，先核对工厂归属与科技前置。分别验证缺前置的提示、通过工程师占领后解锁、排队、扣费、出厂，以及失去设施后目录刷新。
- 在关键过场或阶段切换前后各写一个档，用独立进程冷读。检查暂停画面、任务阶段、地图通行边界、对象归属和血量，再继续推进，检查目标和演出各触发一次。对建筑争夺还要测下令、到门、转属三个时点，避免提前结算或读档后丢失命令。
- 桥坡逐座验收。任务桥段建筑和通用桥面分别查证，连锁坍塌、分层通行、维修与读档各记覆盖。图形窗口核对简报、字幕、雷达小窗、自然结束和跳过后的操控，倍速场景另量画面和音轨进度。
- 工程交接记录各用例通过数、错误日志、复跑参数与待验范围。第一关的旋涡断点、失厂和工程师占领复查可作为参考。见 [苏军第一关运行复核](SESSION_2026-11-26_SOV01_RUNTIME_AUDIT.md) 和 [好莱坞运行复查](SESSION_2026-11-26_HOLLYWOOD_RUNTIME_REVIEW.md)。

连续播放两段影片时，在第一段片尾回调已执行、第二段播放器尚未挂载的间隙也写一次档。独立冷启动后核对下一段、交还操控和镜头导览。调查科技卡锁定时，同时追查前置建筑本身能否按原规则取得，核对实际关卡定义及生成器的布尔解析。见[首脑游戏运行复查](SESSION_2026-11-26_SOV07_RUNTIME_REVIEW.md)。

## 战役单位红边回归

房色用于舰身、车身等原画的阵营色区域。识别描边走统一规则：己方黄色、友军白色、攻击目标红色。迁移关卡时不要按任务 ID 把 `actor._col` 用作识别描边。从战役菜单出击，移开鼠标，在未选中且未受攻击时检查己方单位，再检查实际攻击目标。苏军第一关以金门大桥旁水面舰艇和潜艇为样本，第七关以深红色基地车为样本。两关测试场景均支持 `-- --outline`，检查实际绘制层的着色器颜色。

## 工程记忆要能让下一位直接复现

每次交接写清五件事：**原图依据、玩家能观察到的行为、改了哪个入口、怎样验证、还差什么**。重要数字注明单位；区分编组出发和抵达、字幕显示和声音播放、地图放置和工厂生产。附具体测试场景与参数、结果、截图或日志。测试中若预充能、手动推进计时或移动目标，要写清这个步骤。源码验证、完整游玩、冷进程读档和已打包发行分别记录。

写法示例：苏军第七关的 `On-nuke silo` 使用事件 19，建筑索引 54 对应 `NAMISL`。普通或困难难度下，至少一翼仍受控时，玩家首次建成核弹井或铁幕会听到 `xs7yu01.wav`。测试从正式落成入口检查实际播放文件，并覆盖俘获设施、重复通知和两翼均已解放。该测试用了已经生产就绪的建筑，未实等生产倒计时。这样的记录能直接指导复测。[核弹互动交接](SESSION_2026-11-25_HEAD_GAMES_NUKE_TAUNT.md)
