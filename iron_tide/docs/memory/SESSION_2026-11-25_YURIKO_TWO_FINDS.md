# 百合子远征初遇、日记和破碎残章

首次相遇默认在海岸。战场情报一级（本轮或局外已购买），以及本轮已招募但个人档还缺初遇记录的远征，可以在其他地图显示雨棚。路线页与战场共用判定。旧战场恢复时可补初遇。

## 0.31.51 拾取时的百合子通讯

地面小队首次取到日常日记或破碎残章时，百合子在现有战场通讯栏说一句，对应的物品提示仍显示。台词在 `data/yuriko_find_lines.json`，两类各 20 句，仅使用署名字幕。同一远征、关卡、物品类型稳定选句。普通目标携带这类战利品时在完成后触发，黑匣子在送达后触发。已相遇、本轮已招募或本场听过雨棚事件即可收到通讯，未初遇时普通小队先行回收的奖励保持匿名。读档恢复已取物品或已完成目标不重播；奖励仍按原有胜利结算规则发放。

Godot 4.7.2 已用隔离玩家档案在当前工程运行百合子远征专项，486 项通过。核对了 40 句独立文案、两类物品的真实拾取、替代目标交付、通讯栏显示或排队、重复靠近、检查点恢复以及原有胜负奖励。日志为 `.validation/yuriko-find-lines/bonds-final.log`。
