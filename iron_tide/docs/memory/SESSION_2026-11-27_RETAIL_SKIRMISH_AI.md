# 尤复遭遇战 AI 首批接入与远征复用

2026-11-27，Iron Tide 开发版 0.32。单挑的 SkirmishAI、多席位的 HouseAI 和肉鸽远征的普通电脑基地使用同一套零售小队规则。

## 原版依据

用 `ra2pipe/lib/yr_source.mjs` 直接读取 Steam 零售安装中的 aimd.ini 和 rulesmd.ini。复核命令从 IronTide 仓库根执行，形如 `node iron_tide/tools/export_retail_skirmish.mjs "<游戏安装目录>" "<对照输出.json>"`。导出包含原始文件 SHA-256、行动操作码、触发阈值、难度和阵营建筑表。本轮独立复读的输出与 `data/ra2/retail_skirmish.json` 字节一致。

| 行为 | 已接内容 |
| --- | --- |
| 盟军猎矿 | 采用 0CA48EFC-G 编成的三辆灰熊和 General Harvester Hunt 的猎矿目标。没有查到该 TeamType 在全局 AITriggerTypes 中被直接引用，启动时机采用 Iron Tide 策略。隐蔽矿车的位置不能作为攻击目标，无可见接触时按出生区、原版集结距离和本局迷雾选探路点。 |
| 苏军反基洛夫 | 0CA2FEDC-G 的门槛是两艘基洛夫，编成六名防空步兵。使用当局可见敌情，抵达己方防空炮周边后分散进入区域警戒。既有机动防空紧急采购和基地空袭反应继续运行。 |
| 苏军基地巡逻 | 0A452C6C-G 和 0A452E5C-G 共用两个恐怖机器人。按原版敌军坦克种类、数量和难度筛选。巡逻依次访问己方矿场、战车工厂、电厂和哨戒炮，每站警戒三十秒，再循环。缺失建筑跳过。 |
| 受击与寻敌 | 遭遇战电脑区分移动、巡逻、进攻、采矿及登车任务的反击权限。零售小队的无目标普通扫描使用 27 加 0 至 2 个规则帧，防空步兵区域警戒使用 36 加 0 至 2 个规则帧。当前帧相位代替原版随机抖动。武器射程、可攻击域和可见性继续由战场裁决。 |
| 基地和远征 | 电网在成型基地采用原版 50 余电，防空配额参考 .14 占比和 10 座上限，三家使用各自的基地防御候选。资金和生产仍走当局队列。凶残 1、2 仍走现有后勤、训练、结算和存档。远征的指挥车、专属任务单位和车队排除出通用编队，要求反攻据点时猎矿任务让位。 |

## 验证范围

在隔离用户目录使用 Godot 4.7.2 无头场景。从正式工程重同步候选，核对 14 个交付源文件及配置。新增 `tests/retail_skirmish_regression.tscn` 专项 30 项，覆盖真实受击、迷雾前后命令、缺第三辆灰熊时的购买和实际扣款、排队及编队中途读档、苏军防空落位和巡逻首站、远征第 20 关出击和指挥车归属。测试推进战场时钟，并将小队移到指定位置验收到站状态。另通过凶残 1（282 项）、凶残 2（94 项）、供电建造（120 项）、战术（62 项）、进攻编组（83 项）、命令派发（29 项）和远征防守（35 项）。八组共 735 项，日志无脚本错误。
