# 苏军第七关夜色

零售 sov07.map 的 Lighting 基础环境强度为 0.55，RGB 为 0.4/0.4/0.7，Ground 为 0。此前仅地面乘以该色，树木另设颜色，单位和建筑走通用暖色后期。现在 post_layer.gd 按 yr_sov07 地图选用基础光照着色器，在世界画面合成后统一乘以 (0.22, 0.22, 0.385)。去掉地面与树木的重复着色。HUD 在更高层独立绘制。

Godot 4.7.2 图形窗口从苏军战役入口进入，tests/head_games.tscn -- --opening 通过 28 项检查，stderr 为空。目视核对开局道路、车辆、步兵和雷达。截图 evidence/SOV07_NIGHT.png。验证范围为开局画面及现有生产测试。当前实现用统一基础环境光近似整张地图，也会作用于战场内绘制的血条和特效。原版逐格高度光照、局部灯源和特殊天气属于独立效果。
