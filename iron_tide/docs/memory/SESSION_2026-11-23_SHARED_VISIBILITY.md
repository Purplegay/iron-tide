# 兵种规则合入与同次武器判断的隐蔽复用

用户裁决将上一轮兵种规则缓存合入 v0.31.20 开发树。仅将兵种 ID 赋值时更新的分类及其资格判断消费者移入正式 unit.gd，保留开发树其它修改。开发源码的隔离 Release 对照，2,240 次目标判断和 200 次包含身份切换的分类检查零差异；未打包、提交或推送。上轮 P95 证据仍见 [兵种规则缓存实验](SESSION_2026-11-23_RENDER_GEOMETRY_DOMAIN_CACHE.md)，合入决定不改变测量结果。

## 下一项独立候选

武器资格和世界可见性在同一次同步调用中可能分别检查同一目标的隐蔽状态。对普通单位仅计算一次是否可省略此检查；幻影兵种、报点、回声、伪装、渗透/谭雅相关状态、潜水隐蔽及场内存在幻影场来源时走原逻辑。雾格、追踪、声呐、浮潜、乘载与攻击命令继续在真实消费处判断。没有跨物理步保留目标资格。候选随后已合入 v0.31.20 开发源码。
