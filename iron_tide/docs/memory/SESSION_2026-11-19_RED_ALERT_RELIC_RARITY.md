# RED ALERT 藏品稀有度调整

日期：2026-11-19

## 需求

用户要求红色警戒按钮对应的圣遗物提高为传说级，并降低出现概率。

## 修改

- `scripts/expedition/relics.gd`
  - `red_alert_warrant` 增加 `rarity: "传说"`。
  - 增加 `drop_weight: 0.15`，表示抽取权重为普通藏品的 15%。
  - 藏品详情显示“传说藏品”。
- `scripts/expedition/market.gd`
  - `choose_from()` 改为按藏品 `drop_weight` 加权抽取；未配置权重的藏品保持 1.0。
  - 奖励和商店标题显示传说前缀。
  - `rewards()` 与 `bonus_rewards()` 的直接等概率抽取改为同一加权选择，并移除已选项避免重复。
  - 0.15 是相对权重，不是固定 15% 掉落率；实际概率取决于可用池。
  - 尚未做大量抽样统计或人工视觉确认；最终修改后再次运行真实战场校验通过。

持久记忆工具已达 100 条上限，本轮状态已保存于此项目交接文档。

因此 `red_alert_warrant` 仍可在商店专属藏品位和战后藏品奖励中出现，但相对普通藏品明显更稀有；已有持有、开局补充一次 RED ALERT 和按钮战斗效果不变。

## 校验

- Godot 4.7.2 编辑器扫描通过。
- 真实 `res://scenes/battle.tscn` 无头启动退出码 0。
- 未发现脚本解析错误或运行时错误。
