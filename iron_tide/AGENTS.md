# 项目记忆

性能优化在同源行为对照无新增回归、真实对局确认实际工作量减少且不把成本转移到上游或维护时，直接合入，不逐项再请示，也不必等待净 CPU 或整帧 P95 通过。调用量、局部净耗时和整帧 P95 分开报告，只有计数证据时不宣称提速。

每轮性能优化都同时检查外层调用点和内层子调用：先按耗时确认热点，再量外层可以少发多少次调用、内层可以省多少次子调用或遍历；分别报告，并把新增门槛或维护开销纳入净成本。通过同输入行为对照后再推广，不为凑齐两侧强行改动，也不以降低更新频率换调用减量。

后续战役按苏军第七关《首脑游戏》的方式整关迁移。战役移植、续作或验收开工时，先加载 `yr-campaign-porting` 技能；若环境没有安装，直接读仓库内的[技能源文件](docs/skills/yr-campaign-porting/SKILL.md)。再读[尤复战役迁移与交接规范](docs/memory/YR_CAMPAIGN_PORTING.md)和[战役迁移记忆索引](docs/memory/YR_CAMPAIGN_MEMORY_INDEX.md)，核对目标关的零售地图和脚本。从玩家点击出击验到结算，覆盖原图事件、场景、阵营、生产、CG、语音、字幕及存读档。新增单位交付带中文名的全员实机截图。工程记忆写明原图依据、玩家操作与结果、实际修改入口、测试方法和证据，并记录近似与未验证范围。

三关战役续作每轮同时接入任务触发器与地图 AI。两张逐 ID 表分别报告原图总数、本轮补接、累计正式接入、逐条实测、未接或不适用；更新状态不重复扣除待核验数。全局 AI 启停覆盖、本图 AI、任务增援要分开计数。每轮交付按功能组说明本次接了哪些任务触发器和 AI、玩家会看到什么，并提供本轮完整零售 ID 对照，不只报数字。

所有地图的斜坡迁移按《命令与征服：红色警戒2 尤里的复仇》原版执行。以零售地图格高、对应剧场 TMP 子块坡型、坡向和调色板为依据。验收完整路段，包括坡底、坡顶、相邻平地的路缘与车道线。移植前先读 [尤复斜坡移植记录](docs/memory/YR_SLOPE_PORTING.md)。

移植或重烘地形时，按[地形移植画面验收](docs/memory/TERRAIN_PORT_GATE.md)检查实际加载的贴图。将高差边缘的纹理告警按位置归组，在战场同机位核对，并保存已确认问题的回归样本。

移植桥梁或排查单位上下桥时，先读 [桥梁移植交接](docs/memory/BRIDGE_PORTING.md)。

每次移植地图，按原图和可玩边界逐座清点高桥、低桥、断桥、桥头和维修设施。核对桥面宽度、桥上与桥下的路线和遮挡、断桥与修复。逐端核对引道路面、高差和坡向，同时核对普通坡地的高度、坡型、通行和画面衔接。边界截断处保留原图地形。区分原版数值和移植近似值，从实际战场验证并记录逐桥覆盖范围。

战役 CG 收藏默认在各阵营内按所属关卡号自动升序排列。新增战役只登记关卡号和关内影片顺序，不手工重排目录；结局片归触发它的关卡，不按影片文件编号另排。

用户要求每次完成 Iron Tide 工作后主动记录实际改动、查实的机制和验证范围。跨会话记忆满额时，把记录写进 `docs/memory/`，并如实说明保存位置。接手续作时先查对应主题的交接记录。

验证默认使用无头模式和隔离存档，隐藏测试控制台，不反复打开窗口打扰用户；需要有头验收时先征求用户同意。

性能采样、压测或 A/B 验收时，必须在隔离测试进程关闭普通对局自动存档和远征定时检查点，开跑前确认各对照组均已关闭；没有测试专用开关时先补开关并验证，不用缩短测量时间代替关闭。此要求不得影响玩家正常游玩的存档。

每次新增或调整主动 W 技能，必须同时接入 Auto W 并制作可播放的技能演示。演示要让玩家看到自动施放的触发条件和实际效果。新增或调整被动技能、天赋时也要同步演示。交付前从玩家使用的界面打开，验证播放和等级切换。

新增或调整消耗道具、货币的按钮时，按实际支付资源显示对应图标、名称和数量。混合支付列出各项，免费操作明确标注免费。

新增英雄时，同时开发可在肉鸽远征中招募该英雄的支线、战场线索和独立个人故事。同步更新支线百科，核对英雄名册，并从路线预览、战场任务到胜利入队验证玩家流程。

后续优化按红警2《尤里的复仇》的完整机制核对，桥和坡同时检查原图格高、剧场图块、战场绘制和遮挡、分层通行、损毁与修复。现有覆盖见 docs/memory/SESSION_2026-11-25_NATIVE_BRIDGE_SLOPE_AUDIT.md。

每次新增或重烘单位、建筑及其动画层，同批完成高光优化并在实际战场加载验证。体素模型核对原版 VPL 法线高光、朝向和双倍贴图，SHP 素材保留原画明暗并核对双倍细节页。交付说明具体覆盖与验证范围。
