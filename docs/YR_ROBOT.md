# 尤复机器人坦克与控制中心

2026-10-23。Godot 独立实现，使用本机 Steam 正版文件作为规则和素材输入。
实际工程 `C:/Users/admin/IronTide/iron_tide`；数据是可选增量包 `data/yr_robot.json`，

## 本批行为

- 建造场的主建筑栏新增机器人控制中心：600 资金、600 生命、耗电 100、2×2 占地，
  前置为己方战车工厂和建造场，不额外要求作战实验室。沿用排队、分期付款和待放置库存。
- 战车工厂新增机器人坦克：600 资金、180 生命、重甲，需 GAWEAP 与 GAROBO。
  原始 BuildTimeMultiplier=1.3：单厂基础耗时 RA2 模式 32.76 秒，扩展模式 15.6 秒，
  实际生产仍受现有缺电/工厂倍率影响。其它单位未新增此倍率。
- 每方任意一座存活、展开完毕且正常运转的己方控制中心即可控制本方全部机器人。
  敌方建筑不能授权，建造/展开中不能授权；失去最后一座或缺电后停止移动、射击、连发与主动技能。
  中断前的移动目标保留，恢复后继续；离线新移动命令给出原因，不替换旧目标；停止命令仍有效。
- 同一状态入口用于战斗判定、命令反馈和选中面板。选中离线坦克使用原版离线语音，
  不播放接受移动命令的确认；车体和炮塔变暗，控制中心的运行层停转。
- 保留地面两栖移动域，沿已有寻路与碰撞链跨水面并返回陆地；独立炮塔转向与炮口定位。
  Robogun 使用原始 65 伤害、4 秒 ROF、5 格射程、AP/Cannon 弹头/弹体，不能对空。
- Trainable=no：击毁敌人不产生经验或晋升。按原始弹头的 MindControl / Radiation 标记拒绝
  免疫目标和命中扣血；PsychicDamage 与 MindControl 不混淆，普通物理攻击不受影响。

## 资源与复现

`ra2pipe/yr_robot.mjs` 将原 rulesmd/artmd 标准化到外部候选目录，只发布 ROBO/GAROBO 范围。
控制中心通过明确的 `ra2md.mix > genermd.mix > GGROBO*.SHP` 读取非雪地版本，
避免通用扁平索引被 SNOWMD 的同名资源覆盖。主结构 6 帧；运行/受损主体 0–19 / 20–39，
影子是 40–79，不当主体播放；建造使用原始 GAROBOMK 的前半帧。
坦克原 VXL 导出同画布的 8 朝向车体/炮塔/阴影；炮口取真实炮塔前端的体素坐标。
素材及音频仅用于用户本机项目，不将游戏资源视为可自由再分发。

```powershell
node ra2pipe/yr_robot.mjs '<本机尤复目录>' '<新建的外部候选目录>'
python ra2pipe/yr_guardian_audio.py '<候选目录>' --pack yr_robot --namespace yr_robo
python ra2pipe/verify_yr_robot.py '<候选目录>'
```

后两步使用 Python 3.12。11 个 PCM 文件、8 组机器人语音/声音通过独立 audioop 解码逐字节比对；
原版完整单位语音包优先提供指令语音，本增量补充机器人开火、上线、离线等声音。
导出记录 5 个原始 MIX 的哈希，核对原文件未变化。发布后执行实际工程 Godot editor import。
