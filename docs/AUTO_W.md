# Auto W 覆盖范围（v0.30.23）

解锁自动战术施放科技后，技能栏开关或右键 W 可按兵种调整，右侧指令甲板支持全开／全关。沿用原有偏好和战斗存档；关闭 Auto W 时仍可手动施放。

两轮新增 11 项，总计 35 项自动策略。定点攻击策略只使用当前可见主目标，不替玩家移动、换目标或部署；沿用真实技能入口的冷却、范围、地形、状态和单位资格检查。每单位沿用原有 0.25 秒错峰决策，不新增全地图扫描。

| 新增技能 | 自动条件 |
| --- | --- |
| 谭雅 · 三点破门 | 自身停稳且没有移动命令，当前可见地面目标停稳且没有移动命令，落点在技能范围内且合法。 |
| 鲍里斯 · 红色走廊 | 同上，完整走廊落点合法；开始真实呼叫，玩家之后移动仍可按原机制打断。 |
| 雷铸 · 三极电庭 | 同上，三个电极落点全部通过原技能校验。 |
| 棱镜十字 | 自身与当前地面目标停稳，落点位于实际攻击范围内。 |
| 过载封条 | 自身停稳，当前合法武装载具／防御建筑正瞄准我方存活单位；不覆盖已有封条。停火、冻结、眩晕的敌单位以及停运防御建筑不触发。 |
| 牵引弹头 | 自身停稳、下一轮攻击即将就绪，有合法可见地面目标；V3／无畏舰遵守原武器最小射程，武装直升机须已部署完成。 |
| 重炮压舱 | 舰船停稳且没有移动命令、生命至少 70%，即将向可见目标开火。 |
| 观察哨线 | 停稳且没有移动命令，即将向可见目标开火；已有观察状态不重复开启。 |
| 搜索浮标 | 范围内当前可见的敌方潜艇，优先当前目标，否则选择最近的已发现潜艇；有效浮标不替换。 |
| 诱导跃扑 | 明确攻击载具命令且目标合法可见，接近至两格保护范围加半段加速可行距离时开启；自动索敌和攻击移动不触发。 |
| 战线换气 | 三秒内受伤、尚未回满、正在执行普通移动命令，目的地与实际运动方向均远离可见攻击者；不改变路线、不自动起身。 |

金鳞战垒仍保持手动。搜索浮标只针对当前可见潜艇，不根据隐藏攻击者身份推断其位置；看不到潜艇时仍可由玩家手动选点搜索。镜像与双星的首次召唤可自动，二次换位／引爆仍手动。本轮没有调整技能伤害、冷却或消耗。

验证入口：`res://tests/auto_w_regression.tscn`，包含 `auto_w_tactical_cases.gd` 和 `auto_w_maneuvers_cases.gd`。后者额外覆盖隐藏潜艇、未知攻击者、浮标到期、手动选点、明确攻击、短时技能距离、三种步兵的受伤撤退及共同拦截条件。覆盖全部八项真实自动施放、停火／移动意图／运动／隐藏目标／冷却／禁用／暂停／手动选点／眩晕拦截，定点技能的移动目标／射程／友军／空中目标排除，以及 V3、无畏舰和部署直升机的牵引弹头。原全局开关、存读档和传统模式检查保留。

两轮运行报告分别在 `.validation/auto-w-tactical-20261118/`、`.validation/auto-w-maneuvers-20261118/`，使用当前源码与独立用户目录，GPU 场景运行于未激活的隔离桌面，无截图。自动时机的实际手感仍待玩家确认。
