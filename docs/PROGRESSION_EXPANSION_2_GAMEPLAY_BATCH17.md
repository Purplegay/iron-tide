# 玩法第十七批：支援卡所属方与演示审计

2026-11-18，v0.29.35。本轮核对第五稿“己方仅指同一所属方，不包含盟友”的共用规则及C05／C16／C18／C22，修正四处使用联盟friendly关系选择受益者的偏差。目标仍active；不是全量需求已通过的结论。

## 行为修正

| 卡牌 | 实际修正 | 保留行为 |
| --- | --- | --- |
| 护航水幕 | 只选择同一side的最近两艘，另一个同队所属方的更近舰船不再占名额 | 本舰必选，已选对象离距后按原时限保留，不补选 |
| 弹着校射 | 每个攻击所属方只读取自己的区域，另一同队所属方的更强区域不会覆盖本方 | 本方多个区域只取最高，强区到期后恢复仍有效的弱区 |
| 伴行维修 | 同行资格只来自本方真实载具；同行者变为另一同队所属方即终止资格 | 仅自身回血，真实位移／三秒准备／受敌伤和中止规则不变 |
| 撤离护送 | 两个受益步兵名额只在本方选择，另一同队所属方的近步兵不占名额 | 不作用本人和英雄，不强制移动，低血阈值与间隔保留 |

修改局限于四个对应模块的受益者／区域所属方筛选。伤害、敌对目标与友伤排除继续使用原联盟关系，未修改BattleRequest.friendly或AI规则。普通24卡、16天赋和英雄数量均不变。

另修正 `ui/expansion_2_demo.gd` 的校射数值时间轴：首区于1秒出现、4秒后结束；弱区于2秒出现、独立到6秒结束。满级示例先20%，重叠仍20%，强区结束变12%，全部结束为0；其他档位读取本身配置。此前强区到期的sample.value仍保留强值，文本只笼统说明弱区剩余；现显示明确生效值。

UI与演示设计文档中的“蓄电转储五秒”及“交替推进停车首射”是旧稿残留。当前战斗实现和演示已分别为永久储存至下一发、五秒内持续攻速与攻击强化，本批同步文档，未重复改这些战斗规则。
