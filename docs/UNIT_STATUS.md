# 单位状态显示统一约定

2026-11-12 用户确认：所有单位的持续 Buff、Debuff、倒计时和叠层统一为小状态图标，不能各自在头顶堆文字。状态栏使用小格，鼠标悬停显示具体内容。

2026-11-17 超时空恢复例外：用户反馈无法直接看到冷却秒数，因此统一世界 HUD 在图标行上方、血量文字左侧显示「恢复 X.Xs」；底部超时空状态格同时显示秒数。超时空军团兵与超时空伊文共用此显示。读取真实 `chrono_left` 并沿用 `BattleClock.real_seconds` 换算，结束后自动消失；不改变冷却规则，世界倒计时仍遵守未选中渐隐。伊文炸弹的底部状态格也直接显示实时秒数，该状态属于被装弹目标，与伊文本人的传送恢复分开。实际观感待用户确认。

## 单一数据链

- `Unit.buff_entries()` 汇总普通 Buff、扩展技能与原生状态。
- `scripts/units/expansion_visual.gd::entries` 读取英雄契约、新卡池技能、临时哨位/镜像、废铁装甲等；使用稳定 `id`，不可全部以 `progression` 作为 HUD 字典键。
- `scripts/ui/unit_status.gd` 只读适配原生控制/恢复/炸弹/护盾、技能活动时间及天赋叠层，统一 `id/name/text/icon/left/timed/stacks/limit`，提供悬停说明。
- `scripts/ui/status_chip.gd` 为 28 像素状态格，名称和解释放 tooltip，角标显示层数。状态变化原地更新，增加/消失重建；状态多时横向滚动，不挤出窗口。
- `Battle` 的世界 HUD 绘制小状态标记，同源图标，最多显示 6 格，超出以 +N 标记；全部状态仍可在选中单位的状态栏查看。遵守原有视野、死亡与装载过滤。
- 未选中的单位头顶状态标记在 1 秒内从 100% 线性淡到 20% 不透明度；选中立即恢复 100%，取消选择重新渐隐。图标底框、图标、负面状态边框、层数和 `+N` 角标使用相同透明度；多选中的所有单位及选中的收割者部署炮台均保持清晰。只影响世界状态标记，血条、模型和底部 Buff 详情栏不淡化。渐隐缓存属于世界 HUD，使用弱引用与真实时间，不写入单位战斗状态或推进 Buff 计时。
- 收起单位菜单后仍保留状态格；不能把它放进随单位详情隐藏的父节点。多选沿用当前代表单位，不混合不同单位或不同目标的层数。
- 选中有效单位后始终显示独立的「Buff / 状态」栏；没有条目时显示「暂无生效中的增益或减益」。最后一个状态结束时恢复空态，取消选择或单位死亡时才隐藏。收起单位菜单仍保留空态栏。
- 已装配并生效的「钢铁拾荒」在未拾取或装甲耗尽后保留 0 层状态格，悬停显示当前层数、对应技能等级上限和等待拾取说明；0 层不表示获得额外装甲。已有装甲继续展示各块真实耐久，只读展示不创建战斗状态。
- 被动/天赋详情使用同一份状态说明。普通伤害数字、HP/护盾读数、暴击等瞬时战斗结果不属于持续 Buff 名称。

## 已核对的文字来源

| 来源 | 处理 |
| --- | --- |
| expansion_visual：哨位寿命、继任、镜像、曳光、弹仓、废铁等 | 统一状态行与图标，移除头顶持续文字 |
| allied_abilities：超时空恢复、抹除、心灵控制 | 单位改用状态标志，保留能力特效；超时空恢复额外显示实时秒数 |
| soviet_specials：伊万炸弹倒计时 | 单位状态格显示秒数，保留炸弹贴图 |
| talent_stack_indicator：蓄电、辐射扩散、主副目标热量、稳流 | 保留只读层数接口，主/副目标分开，单位改用状态图标；演示工具仍可复用原绘图函数 |
| ra3_reaper_heat：Heat / Split / Echo / Flux 等命中文字 | 保留命中环，状态适配器读取对应效果节点的短暂寿命与层数 |
| revival_indicator：英雄复活倒计时 | 世界 HUD 改用统一状态格；原倒计时数据接口保留 |
| 倒车、固守、普通技能释放名称、护盾恢复提示 | 对应持续状态用图标；保留倒车灯与战斗特效 |

只读展示不得推进计时、补建战斗状态、重置层数或改写存档。不同目标的 Heat 不合并。敌方精确护盾数值继续隐藏。新增状态应接入这条数据链；除上述超时空恢复倒计时外，不新增独立的单位头顶文字。
