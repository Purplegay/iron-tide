# 英雄第二十七批：鲍里斯计时控制与持续冻结的演示区别

2026-11-18，v0.29.69。旧抗扰通讯演示在右侧画超时空兵，同时让鲍里斯两秒后解除控制；虽然说明写了持续擦除不解除，画面仍会暗示超时空射线也按两秒解除。本批改表现，不改变实际控制规则。

新增只读 `scripts/ui/boris_control_demo.gd`，生存Lv.2采用18秒三段时间轴，播放控件同步时长：

- 新增计时控制：第1秒同时给英雄／普通鲍里斯4秒计时眩晕，英雄缩为2秒、在第3秒恢复；普通单位到第5秒恢复。明确这不是超时空兵射线。
- 已有控制：先前8秒计时控制缩为4秒；一秒后再施加2秒、缩为1秒，此时原有剩余3秒继续，不被新的1秒覆盖，不会再次把旧控制减半。
- 持续时空冻结：第1秒超时空兵开始维持，超过两秒仍冻结并继续擦除；第5秒攻击者主动停火，才解除维持。画面不显示虚构的“两秒冻结倒计时”。
