# 画面与操作手感整改清单

更新：2026-10-21。最新优先级：RA3 风格 UI、RA2 素材，优先经济/生产、对局规则、地图/迷雾和画面/资源，见 RA3_INTEGRATION.md。
以现有盟军对局为主验收场景，同时回归扩展模式。完整机制差异仍由 `RA2_PARITY.md` 跟踪。

本清单共 **60 项**。未勾选项均未验收完成；“已有能力”表示需要保留和打磨，不表示缺失。
状态：**代码证据**＝已查到具体实现问题；**画面证据**＝上一轮渲染截图可观察；
**待体验**＝需要实际操作或专项测试；**设计建议**＝拟调整方案。
下面的体验目标是本工程的建议标准，不冒充原版 RA2 定值。

## 第一批：先解决“点不准、误操作、看不清”

推荐顺序：**C01 → C02 → I01 → I02 → I03 → I04 → U01 → U02 → U04 → U06 → V01 → B01**。
先完成这一批，再决定镜头速度、单位加减速和整体美术风格的细调。

初始排查证据（C01、C02、I01—I04、U01、U02、U04、U06 已实施或确认并通过自动验证，待使用者体验确认）：

- 小地图 `_draw()` 用等比缩放和居中留边，`_to_map()` 却按控件全宽高换算；非正方形控件会出现点击位置偏差。
- 小地图视野框按轴对齐矩形绘制，未转换实际旋转相机的四角。
- `_apply_selection()` 用世界距离 `<14` 区分点选/框选，显示缩放改变同一鼠标位移的判定；框选框本身使用屏幕坐标。
- 同一方法包含“单击已选单位释放主技能”，与双击选同类共用点击链路；扩展模式存在误施放风险。
- `_ui_wants_right_click()` 只检查当前悬停控件的 `rmb_cancel` 分组；需要覆盖图标子控件、空白面板、小地图和拖拽跨区。
- HUD 顶部直接展示投影比例、K 值、GM 入口；视角提示的默认值还写着 2.25:1，与当前 2:1 默认值不同。
- 生产栏已接回 33 个原有图标，选中头像仍由 `UnitIcon` 绘制程序化剪影；截图可见风格混用。

## 十分钟体验路线

1. 进入盟军对局：观察默认视野、资金、电力和可建造入口。
2. 点选步兵、车辆、建筑，再框选混编；重复点击与双击，检查是否误触技能。
3. Shift 改选、数字编队、双按定位；把鼠标移到 UI 和小地图上重复操作。
4. 用滚轮、中键/右键拖图、贴边滚屏和小地图定位；检查缩放前后落点。
5. 派 6/20 辆车走开阔地、绕建筑、过窄口；停止后反向移动。
6. 连续生产、批量生产、取消、资金耗尽后恢复；观察队列与声音。
7. 放置电厂、兵营和工厂：合法/非法位置、取消再放、完成后出兵及集结。
8. 进行一场小规模交战：观察目标、血条、弹道、爆炸、死亡与警报。
9. 暂停、恢复、切到其他窗口再回来，检查镜头、拖拽和热键状态。
10. 切回扩展模式，确认自定义技能、养成展示和原操作仍然可用。
