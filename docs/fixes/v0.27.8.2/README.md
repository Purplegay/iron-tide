# v0.27.8.2 · 遭遇战 AI 应对基洛夫空袭

每家盟军或苏联电脑按己方当前可见的敌方基洛夫数量做采购决策。一艘对应四座防空塔，两艘六座，三艘八座，四艘及以上十座。该目标适用于所有难度，仍需满足建造前置、供电、资金和合法选址，防御队列依次建造。

盟军车厂优先造多功能步兵车，兵营解锁后优先造火箭飞行兵；苏联对应防空履带车和防空步兵。每种兵按两倍飞艇数量再加二确定紧急补充目标，最多十二，计算已拥有和在队单位。已下单的工作继续进行。飞艇消失或被击落后，后续采购按常规策略安排。

隔离桌面回归通过 732 项。覆盖盟苏单对手在不同难度实际建成四座防空并锁定飞艇、空袭后恢复 T3 采购、多家电脑建第三座防空、两艘飞艇时的六座目标与两条产线的实际订单，以及己方和未发现飞艇的排除。
