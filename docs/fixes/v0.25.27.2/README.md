# v0.25.27.2 · 试玩包持续卡顿

用户仍在使用 v0.25.24.9。此次用用户提供的 `slot1(1).itsave`（76 单位、28 建筑）及 60 名美国大兵持续选中行军场景，对照工程与实际导出 EXE。

## 修复

- 普通世界血条和武器冷却圈各使用一个实例批次，减少大量选中单位逐条绘制产生的命令。受击白闪、建筑告警和特殊血条保留原画法；超出批次容量自动回退。每个武器继续显示自己的真实装填进度。
- 小地图单位、资源、迷雾等内容更新为 20 Hz；镜头范围框保持逐帧更新，点击与拖动映射不变。
- 场内没有幻影场发射者时，不再给普通单位每帧创建和读写隐身表现字典；发射者消失后清理已有表现。
- 开战／读档时准备当前兵种的开火、命中、死亡与音效素材，强引用保持本场使用的死亡贴图。后来出现的新兵种逐项后台加载。避免光棱链式命中击毁建筑时集中同步读盘、解压。

## 验证与边界

- 测试使用 headless 或独立 Win32 桌面，不切换用户桌面、不弹出测试窗口。
- 同一帧原画法与批绘对照，血条／冷却圈预乘颜色与透明度的平均误差 0.35%。校验六武器两行排列、就绪、半装填及空帧清空。
- 素材预热回归验证 RNG、资金、血量不变，已有素材去重，新兵种后台请求完成，以及无幻影场的透明度恢复。
- 使用隔离的临时 APPDATA，不覆盖玩家存档。用户提供的旧战斗档可以恢复。
- 本次修改表现与资源准备，不改变 AI 难度、伤害、移动速度、攻击速度或存档格式。性能数字和实际导出验证见 `PERFORMANCE.md`。
- 不保证任何规模战斗都无慢帧；具体帧耗时受场景和机器负载影响。
