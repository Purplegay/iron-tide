# v0.27.0.3 · 登运输机时反复寻路

修复海豹部队登夜鹰时逐帧重复寻路。运输机停在不可步行的地点时，乘员保留当前路线，AI 可以到可达处接人。

## 复现与验证

本机 slot1（SHA-256 EDE11D87B73F5586D689C8AE8AB31E0E8EC89AF1742E51EF0D7F58D7B56C78D2），Circuit Board、困难、46 个单位和 65 座建筑。两名海豹部队请求登上同一架夜鹰，着陆位置距最近路径终点约 97 像素。旧逻辑把这个距离当作飞机移动，每个物理帧重新下单。

固定 60 Hz 模拟步长，同一份存档副本在隔离桌面使用 OpenGL Compatibility 运行，每阶段记录 240 个实际帧间隔（Core Ultra 5 250K Plus / RTX 5060 Ti）。隐藏空中单位或停算它们的物理更新时，原版正常战斗帧耗时中位仍约 20～21 毫秒。计数对照如下。

|阶段|寻路次数（前→后）|帧耗时中位数（前→后两轮，毫秒）|
|---|---:|---:|
|恢复战斗|499 → 19|22.4 → 12.7／13.6|
|选择己方地面单位|510 → 32|22.6 → 14.2／14.1|
|下达移动指令|522 → 44|21.7 → 14.2／14.2|

修后两轮仍有约 60 毫秒的单帧峰值。运输与乘车光标回归 386 项通过。AI 行为回归 434 项中 432 项通过，修改前后均有两项“未见敌人时不下达出击或间谍命令”失败。原始存档校验一致。
