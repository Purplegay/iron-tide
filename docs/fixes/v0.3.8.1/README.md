# Iron Tide v0.3.8.1 修复说明

2026-10-27

- 将已提取的《起义》素材实际接入幻影坦克：原版场网格、101帧/30FPS透明度动画正播与倒播，移除统一缩放球体。原曲线前50帧渐显、后50帧保持；反向关闭保留原保持区间。
- 按真实FXLightning.fx材质绑定替换蓝色通用场效果，消费原云纹/扰动纹理、HDR与边缘参数；Godot着色器仍是适配，不宣称直接运行SAGE的FXO。
- 接入开火双层原音（第二层200–250ms延迟）、开关/循环声音及SDK音量/音调；声音随单位/对局清理，暂停冻结延迟触发，迷雾和载具收纳抑制声音。
- 替换当前语音为起义PCM，使用原版待机伪装树、技能/生产图标、头像与三个盟军军衔图标。地形类别映射仍待实现，当前默认使用SDK Misc/Grass树；未凭素材名启用未被SDK ShieldDraw引用的EXMIRAGEFIELDBUILDUP。
- 七组542项检查通过，真实OpenGL/WASAPI无脚本、渲染、音频退出错误；混编3辆带1600条履带痕迹移动中位帧耗时3.382ms。表现与听感仍待使用者确认。
