# v0.25.37 · 四张技能卡与鲍里斯米格抵达养成

## 四张卡

加入现有技能卡池。只有「连锁放电」限制磁爆步兵，另外三张通用；W 装配主动，既有被动槽装配被动。Q、E 和停火蓄电天赋保持各自规则。卡池的稀有度权重、价格和重复卡兑换规则不变。

| 卡牌 | 品质／范围 | 0／1／2／3 级数值 | 行为 |
| --- | --- | --- | --- |
| 连锁放电 | 传说主动／磁爆步兵 | 分支 40%／50%／60%／70%；冷却 40／38／36／34 秒 | 释放后 12 秒内前三次普通电击命中，对主目标两格内最近的最多两名可见地面敌人额外放电 |
| 震荡脉冲 | 史诗主动／通用 | 基础伤害 100／120／140／160；冷却 26／25／24／23 秒 | 自身两格范围电击，存活敌方地面单位减速 25%，持续 3 秒 |
| 接地护甲 | 稀有被动／通用 | 减伤 10%／12%／14%／16% | 普通攻击开火后减伤 3 秒，重复开火刷新，不叠层 |
| 余电疾行 | 普通被动／通用 | 移速 +8%／10%／12%／14% | 普通攻击开火后加速 2 秒，重复开火刷新，不叠层 |

- 连锁分支使用原生武器伤害，继续计算攻防、装甲与取整，不继承停火蓄电倍率，不再次分裂或触发普通攻击被动。基础 50 点电击的四档分支为 20／25／30／35 点；天赋满层时主目标仍可受 125 点，分支不跟着变成 125 点的百分比。
- 脉冲可伤害建筑，但不使建筑减速；飞行中的目标、友军、中立目标和乘员不受影响，已落地飞机按地面目标处理。实际伤害受电击弹头和目标装甲影响。主动技能不消耗停火蓄电层数。
- 四档效果与冷却不受单位原生「技能强化」联动。卡池、装配、详情和演示使用相同数值；通用卡演示默认使用美国大兵，不暗示磁爆专属。
- 稀有／普通沿用抽取获取；史诗／传说保留现有碎片兑换入口。没有新增低品质碎片商品。

## 鲍里斯

按用户确认，强化的是标定后到米格抵达的等待，不是空袭结束后的再充能，也不按建筑血量计算。

新对局每级将入场耗时缩短 2.5%，20 级最多缩短 50%。实现为只提高本次米格入场航段速度，0 级原速，20 级两倍入场速度；出发位置和开火距离不变。返航恢复原速，普通／精英再充能分别保持原有 100／50 逻辑帧除以 15。

## 保存与兼容

沿用局外 JSON 卡牌拥有列表、等级和装配结构；战斗中连锁次数与剩余时间、临时减伤／加速／减速、技能冷却通过已有快照保存。RA2 模式不装配扩展卡，也不获得上述养成。

新战斗冻结 `native_training_version=3`。旧 v1／v2 战斗继续使用先前的鲍里斯再充能强化和正常入场速度；新米格快照保存本次入场倍率，旧快照缺字段时默认原速。玩家已有购买等级不清空，局外改变不追溯修改正在进行的战斗。
