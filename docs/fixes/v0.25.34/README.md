# v0.25.34 · 辐射工兵「辐射扩散」

扩展模式新增辐射工兵第二项专属天赋，解锁为 0 级，可升至 4 级。单位改造提供五档数值、专属图标和可切换等级的演示；第二个天赋格按现有规则购买开放。

| 天赋等级 | 每层间隔 | 满三层额外半径 |
| --- | --- | --- |
| 0 | 5 秒 | 0.5 格 |
| 1 | 4.8 秒 | 2 格 |
| 2 | 4.5 秒 | 2.5 格 |
| 3 | 4 秒 | 4 格 |
| 4 | 1.5 秒 | 4 格 |

每层增加表中总量的三分之一，最多三层。部署后开始累计，起身清空；再次部署从零开始。仅扩大辐射半径，不额外提高辐射强度，也不改跳伤间隔、衰减或寿命。范围内仍使用原有的径向伤害衰减公式。

绿圈与实际伤害范围同步。重叠辐射区保留各来源贡献，收起或死亡后撤去对应扩圈，原始残留辐射继续衰减。与「衰变采样」同时启用时，采样范围跟随扩圈。存档保留层数、未满一层的时间和来源引用；未分配此天赋的对局不获得效果。

这是用户指定的扩展天赋，不是尤复原版规则。测试使用独立用户目录与无窗口 headless 入口；自动验证与玩家视觉验收分别记录。

验证：`radiation_growth_regression` 58 项通过，覆盖五档边界、三层封顶、真实伤害覆盖、起身撤圈、重叠来源、死亡、读档续时及五级演示入口；`academy_regression` 710 项通过。后者保存失败警告来自已有故障注入用例，未出现脚本错误。未进行桌面弹窗式视觉测试。
