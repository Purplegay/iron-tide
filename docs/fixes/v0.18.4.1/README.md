# Iron Tide v0.18.4.1 · 建筑常态贴图预载

建筑开始施工或播放建造动画后，战场按实际建筑的美术定义，把本体、常态动画及相应阴影需要的贴图页加入同一个队列。同一路径只排一次，每帧最多处理一个资源，加载结果沿用战斗绘制使用的缓存。

在 RTX 5060 Ti 上，用同一份代码在独立桌面交替关闭、启用、启用、关闭预载。4000 地图开启 AI 和迷雾，4 辆磁暴坦克和 4 辆天启分两处与 8 名美国大兵交火，记录 600 帧。

| 预载 | 建筑切换帧（毫秒） | 交火最慢帧（毫秒） | 开局前 90 帧中的最慢帧（毫秒） |
| --- | ---: | ---: | ---: |
| 关闭 | 76.9 | 76.9 | 257.1 |
| 启用 | 28.8 | 35.7 | 263.2 |
| 启用 | 27.2 | 36.3 | 263.5 |
| 关闭 | 89.1 | 89.1 | 271.9 |

四次均记录 8 次阵亡，剩余大兵的累计掉血量均为 300。开场首批画面的冷启动耗时仍然存在。
