# Iron Tide v0.18.2.1 修复说明

2026-11-03

## 谭雅的训练名额

同一个 AI 过去可以在两个兵营各训练一名谭雅。尤复为谭雅（`TANY`）和鲍里斯（`BORIS`）都配置了 `BuildLimit=1`，游戏此前只对鲍里斯执行了这条规则。

现在玩家和 AI 各有一个谭雅名额。任意兵营将她加入队列就占用名额，暂停训练仍占用。取消训练可重新下单，出营后则要等她阵亡才能补造。

旧对局中已经出现的谭雅会保留。旧队列轮到重复订单时，只要己方还有谭雅，该订单就会等待并停止扣款。

## 验证

在 RA2 和扩展模式下用无窗口回归检查双兵营、批量下单、取消、出营、阵亡补造和旧格式重复队列；同时检查双方名额独立。
