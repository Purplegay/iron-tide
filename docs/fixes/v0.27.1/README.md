# v0.27.1 · 遭遇战分席位难度与地图选位

- **设置对手**　在遭遇战参战表逐行设置电脑难度，范围从简单到凶残3。新增席位采用大厅的默认难度。开局资金、交矿、补助、生产与难度加成都取各自席位的配置。
- **选择位置**　点玩家或电脑行的「几号」按钮，再点地图预览上的出生点。空位直接分配，已占用的位置互换。难度、国家与结盟组跟随原参战方。大厅按地图和尺寸记住选择，对局存档保存开局配置。
- **胜利结算**　困难通关任务、胜利皮肤取本局所有敌对电脑的最低难度，电脑盟友不计。旧存档继续沿用原对局的统一难度和既有出生位置。

无窗口验证覆盖四方混战和结盟、鼠标点击地图换位、重开大厅、双方基地车换边、独立经济和难度加成、胜利难度判定、对局存档写入和读回。四方对局专项 100 项、大厅设置 92 项、凶残3 专项 96 项、最终伤害专项 124 项通过。地图标记的实机外观待玩家确认。
