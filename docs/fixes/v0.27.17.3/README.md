# v0.27.17.3 · 施工建筑正常受伤

`Building._process` 原先每帧执行 `hp = max_hp * (0.15 + 0.85 * progress)`，即使没有推进施工也会覆盖受击后的血量，完工再次设为满血。因此非致命伤害会在下一帧消失。

改为仅把本次实际施工进度新增的结构生命加到当前血量，保留原有 15% 初始生命和 85% 随施工增加的规则。零进度或资金不足不会恢复生命；完工保留伤害。致命伤害继续走正常死亡流程，无法继续施工或复活。侧栏生产完成后的放置动画也验证可受伤和摧毁。铁幕、力场护盾与 GM 无敌等独立规则未更改。

无需新增存档字段，读取旧档直接使用当前剩余生命和施工进度，不重算或恢复此前损伤。
