# v0.25.48 · 震荡脉冲适用范围与磁暴线圈

按用户要求，`ap_shock_pulse` 仅适用于 `SHK` 磁爆步兵、`TTNK` 尤复磁暴坦克、`TESLA` 磁暴线圈，排除 RA3 磁暴坦克。卡面、成长表、专属筛选和演示名单读取同一适用表。

磁暴线圈在单位改造中可以装配 W 主动「震荡脉冲」。选中后显示技能图标、动态等级说明与剩余冷却，支持 W 热键、点击释放、悬停范围预览。仅扩展模式己方已装配线圈可用，要求建成、正常运转；断电规则沿用磁暴线圈原有充电支援规则。冻结、暂停、战斗结束时不能释放，暂停不推进冷却。

沿用现有数值：0～3 级分别造成自身当前攻击力的 40／60／80／100%，半径 5 格，冷却 26／25／24／23 秒；只攻击范围内可见的敌方地面单位与建筑，地面单位减速 25% 持续 3 秒，建筑不减速。线圈按当前普通／充电武器取攻击力，攻击加成只结算一次，不改原武器开火计时。

## 旧档与持久化

- 保留已抽取卡片、培养等级。旧 RA3 装配经统一兼容过滤失效；恢复战斗存档时移除不兼容的旧运行中技能。
- 新局冻结磁暴线圈装配；旧对局缺少线圈装配条目时视为空，不从当前局外档偷偷补入。
- 线圈等级与剩余冷却保存在现有 `Building.special.tesla_pulse` 字典，沿用现有战斗快照序列化；没有新增存档格式、手写编解码器或新的持久化文件类型。局外装配沿用 JSON `unit_loadouts`。
