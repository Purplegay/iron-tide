## 卡牌分配

| 品质／槽位 | 卡牌 | 可装配兵种 | 0／1／2／3 级 |
| --- | --- | --- | --- |
| 传说主动 W | 连锁放电 | 磁爆步兵 SHK | 保持此前规则，分支伤害 40／50／60／70% |
| 史诗主动 W | 震荡脉冲 | SHK、TTNK、R3TESLA | 两格内基础电击 100／120／140／160，冷却 26／25／24／23 秒 |
| 稀有被动 | 乘员协同 | 战斗要塞 BFRT | 触发命中额外伤害 10／15／20／25% |
| 普通被动 | 空仓返航 | 入侵者 ORCA、黑鹰 BEAG | 空弹返航水平飞行速度 +8／10／12／14% |

震荡脉冲使存活的地面敌方单位减速 25%，持续 3 秒；建筑可受伤但不减速，只影响可见敌人。三个电磁兵种均可施放，机器人坦克不适用。连锁放电仍是磁爆步兵专属。

乘员协同要求同一要塞内两名不同乘员，在 2 秒内命中同一个敌人，只强化第二名乘员当次命中。按乘员实例区分，不要求不同兵种。同一要塞对同一个目标共用 3 秒冷却，五名乘员连续命中不会叠五层；冷却后需要新一对命中。不同目标分别计时。离开要塞的第一名乘员不能继续完成配对，同一乘员连射不能自行触发，卡牌额外伤害不参与触发。单位和建筑共用判定；状态计时及乘员、目标引用可以保存恢复。

空仓返航要求弹药为零、状态为返回机场、有有效机场目标、仍在空中。普通飞行、剩余弹药返航、取消返航、落地或装填均不加速。不缩短升降、装填或攻击时间。

## 兼容与界面

沿用 `ps_grounding`、`ps_aftercurrent` 卡牌 ID，已抽到的所有权和等级不丢失，不重新收费。旧通用装配在不适用兵种上过滤；读取旧战斗时卸下不兼容的震荡脉冲和这两张被动，并清除退休的护甲／疾行临时增益。适用兵种读取当前卡牌定义，乘员协同使用该局已保存的卡牌等级计算新曲线，不沿用旧护甲倍率；旧局后续生产也一致。

卡池说明、装配范围、图标、四级数值与演示同步更新；不会改动单位原生 Q、E 或其它卡牌。
