# v0.25.27.1 · 时间书签低等级重连窗口

2026-11-05。修正 v0.25.27 攻击间隔与书签有效期不匹配的问题。

## 问题与调整

上版 0 级攻击间隔为 6.4 秒，书签却只保留 2 秒。刚开始擦除就中断时，冷却结束前书签已经失效；1、2 级同样存在问题。此前用例预先持续擦除了足够长时间，漏测了立即中断的情况。

保留攻击间隔缩减 20%／30%／40%／50%，仅把书签保留期限延长：

| 等级 | 攻击间隔（基础 8 秒，无其它加成） | 新保留期限 | 立即中断时冷却结束后的余量 |
| --- | --- | --- | --- |
| 0 | 6.4 秒 | 8 秒 | 至少约 1.6 秒 |
| 1 | 5.6 秒 | 9 秒 | 至少约 3.4 秒 |
| 2 | 4.8 秒 | 10 秒 | 至少约 5.2 秒 |
| 3 | 4.0 秒 | 11 秒 | 至少约 7.0 秒 |

保留期限从中断时算起；能够开火时可立即重连，不需要等满期限。只继承已完成进度的 50%；不能凭空产生进度。改锁其他目标仍清除书签，目标死亡或期限结束仍失效。纯 RA2、未装天赋和敌方不获得此加成。单位改造与演示从同一配置读取期限，自动同步显示。

没有改变原版基础武器数值、擦除速度或存档结构。已保存的中断书签沿用其剩余计时，下次中断使用新期限；局外天赋等级和所有权保留。玩家因移动、眩晕、目标离开等原因耗尽期限仍会失去书签，不保证任何距离都能追回。
