# v0.25.32 · 技能强化实际受益说明

2026-11-05。

## 改动

- 单位改造按兵种当前固有 Q、已解锁且兼容的装配 W／被动生成受益列表，每个技能列当前值 → 下一级值。满级只列当前值。
- 通用主动按实际效果列攻击、防御、速度、治疗、瘫痪等数值及冷却；通用被动列对应属性。当前卡牌等级纳入装配效果，固有 Q 按实际运行使用基础卡牌数值。普攻间隔缩减与暴击率显示各自现有上限。
- 假象转移、炮座齐校、搜索浮标、斜甲迎击仅列冷却收益，注明专属效果不受此项强化；阵营专属被动不虚构收益。卧倒、卸载、伪装、超时空移动等原生操作不列为受益技能。非矿车装强化挖掘不计为受益项。
- 没有受益项时隐藏技能强化卡，并给出保留等级的提示；顶部不再显示无受益项的技能强度倍率。底层购买入口也拒绝无受益升级，不只隐藏按钮。
- 旧等级保留，无退款、清零或迁移；之后装上已解锁的兼容技能即可使用旧等级。卸下技能后再次隐藏。强化主动停用时仍展示启用后数值并注明停用，不默默重新启用。
- 每级价格、等级上限、扣费和原子存档回滚保持。现有对局与同局增援保持开局冻结状态；新对局读取最新养成与装配。纯 RA2 模式继续关闭玩家扩展养成。
