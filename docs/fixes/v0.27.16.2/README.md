# v0.27.16.2 · 大规模移动交战

同一份 Islands on the Land 凶残 3 存档，327 单位、155 建筑。上一版与本版都用实时 1 倍速，先预热 4 秒游戏时间，交战、选兵、移动各取随后 15 秒游戏时间。测试机为 Intel Core Ultra 5 250K Plus 和 RTX 5060 Ti。AI 随实时调度演进，每次开火数和路线数略有差异。[原始统计](measurements.json)

第一组完整对照中，移动交战的中位帧耗时从 92.8 降到 59.3 毫秒，P95 从 153.9 降到 105.9 毫秒。新版的 15.07 秒游戏时间经过了 15.20 秒现实时间。该阶段指挥存档中的一支玩家地面单位，全地图各家继续混战。

上一版的独立插桩回放中，移动阶段每帧的单位交战控制约 20.7 毫秒，重新索敌约 8.1 毫秒，路径请求约 5.2 毫秒（其中网格寻路 3.8），局部避让约 3.0 毫秒，滑动碰撞及桥层检查约 1.4 毫秒。计时包含子调用，采样本身也有开销。

- 大规模战局里，单位、防御建筑和碾压按附近区域筛选候选，跨格和传送立即更新。继续按当前视野、同盟、射界和目标条件验证。
- 电脑索敌遇到指挥名额不足时排队，取得名额后唤醒原有索敌流程。
- 大规模 AI 行军的短程绕障使用可复用的原生八向寻路窗口，包含临时路障与斜角限制。跨区或局部无路继续用完整路径搜索。玩家编队使用原路线策略。
- 导航、出入口、部署避让、桥梁、矿车、战斗要塞和 AI 指挥共 967 项回归通过。经典、扩展模式的 200 单位混合行军均全部到点。3700X 的帧耗时待实机验证。
