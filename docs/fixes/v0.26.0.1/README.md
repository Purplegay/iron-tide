# v0.26.0.1 · 凶残 2 最终伤害压缩

此前只压缩全局、兵种和英雄养成的攻击倍率，临时技能及命中时追加的被动可以绕过上限。本版按用户确认，改为伤害形成后统一结算。

## 规则

- 新开的扩展遭遇战「凶残 2」启用。AI 后勤 10 级、兵种改造 8 级不变。
- 基准为同武器、同军衔、同目标护甲／防御和距离下，未叠加养成及卡牌增强的伤害。
- 养成、抽卡技能、被动、命中追加增伤合并后，与基准比较；不超过 200% 时不压缩，超过后使用已确认的曲线，渐近上限 350%。
- 设原伤害与基准之比为 r，r > 2 时：x = ln(1 + (r - 2) / 1.5)，压缩后倍率 = 2 + 1.5 × x / (1 + x)。
- 例如 312% 攻击倍率再叠加 50% 增伤，按最终 468% 统一压缩，不再先压缩 312% 后另乘 1.5。
- 新局不再预压缩攻击属性。弹道记录基础参照，溅射按各目标防御和距离单独计算；发射者死亡后仍保留参照。
- 最终压缩位于取整、生命／护盾扣除之前。原生处决、碾压等特殊规则和 GM 秒杀不改成普通伤害规则。

## 存档边界

新局保存 `final_damage_cap`，关闭旧的 `growth_attack_cap`。旧战斗存档保留已有结算规则，不在读档时追改；仅含旧养成压缩字段的 v0.25.81 战斗继续使用旧机制，避免重复压缩。请新开扩展模式凶残 2 验证本次行为。
