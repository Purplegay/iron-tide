# v0.20.5.1　敌方超级武器和支援能力警报

左上角独立显示敌方战略武器的倒计时、暂停或就绪状态。成功释放时显示武器名、播放警报并在小地图标出目标。收起情报栏仍可看见；发射提示保留 10 秒，同时发动的不同能力并列显示。相同能力有多个设施时，倒计时取最快的一个，美国空降共用的充能只显示一次。

覆盖核弹、闪电风暴、铁幕、超时空转换、力场护盾、侦察机、美国大兵空降。前四项使用玩家阵营对应的 EVA，后三项使用全局警示音。

RA2 与扩展模式的无窗口警报专项 106 项、战略行动 54 项、美国空降 26 项均通过。验证覆盖成功释放、重复指令被拒、己方释放、收起情报栏、音频资源和小地图事件；实际画面与听感待实机确认。
