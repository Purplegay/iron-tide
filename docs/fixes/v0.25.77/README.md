# v0.25.77 · 舰船与飞机普通技能卡

新增四张普通白色卡，保留原五张普通卡及其他品质。卡池、单位装配、0～3 级培养、动态说明、模型演示共用定义；无需额外专属许可。

| 卡牌 | 简介 | 0／1／2／3 级 |
| --- | --- | --- |
| 舰船 W：排水抢修 | 边航行边修船，4 秒内缓慢恢复生命；冷却 30 秒 | 总恢复 3%／4%／5%／6% 最大生命 |
| 舰船被动：锚定校射 | 停稳 2 秒，稳住炮座加快装填；移动解除 | 装填时间缩短 8%／10%／12%／15% |
| 飞机 W：掠翼机动 | 空中展开翼侧流线，减伤 3 秒；落地结束，冷却 24 秒 | 减伤 20%／25%／30%／35% |
| 飞机被动：巡航瞭望 | 连续飞行 2 秒扩大视野；停下或落地收回 | 视野半径 +15%／20%／25%／30% |

排水抢修不适用于海豚／乌贼，不恢复护盾，满血不能空放。锚定校射只给有直接舰载武器的舰船，不给航母或无武器运输艇，不加快舰载机补充；已开始的装填按开始时的时长完成，移动时冷却圈不跳变。巡航瞭望不增加射程、反潜或反隐能力，已揭开的地图继续遵循普通迷雾回覆规则。飞行兵沿用项目的空中单位分类。

抢修与翼侧防护支持已有 Auto W：分别在生命低于 85%、空中最近 3 秒受伤时触发，仍须满足已解锁 Auto W、已装备且冷却就绪。经典模式不加载这四张养成卡。运行状态存在 unit.special，读档不会重新多送回血。
