# v0.25.67.2 · 护盾可反复恢复与三类打断

用户最新规则替代 v0.25.67.1 的永久残盾锁定：每一轮都能最终蓄到最大生命 50%，有残盾也可以恢复。

- 连续静止、不普攻且未受击满 3 秒，增加最大生命 15% 的护盾（不覆盖已有残盾）；之后每完整 1 秒增加 5%，总量封顶 50%。
- 实际移动、位移、普攻发射（含强制攻击）、正伤害受击均清空等待并退出持续增长，保留残盾。没有护盾时被击中也会重置等待；铁幕挡下的命中也视为受到打扰。
- 释放技能本身不重置等待或持续增长；如果技能导致实际移动或自身受击，依然按对应事件打断。仅选目标或普攻冷却不算一次开火。
- 每次实际加盾刷新 120 秒有效期；满盾不自动续期。破盾爆炸的 110% 主炮攻击力、2 格范围及自然到期不爆炸保持原样。
- 天赋说明、战场详情和演示同步；演示先显示受击后剩余 30%，等待 3 秒恢复到 45%，再增长到 50%，之后破盾并重新蓄盾。
