# v0.27.0.2 · 天启星环与熔芯双响

第二个存档位于尤复地图，含 57 个单位、56 座建筑，其中 29 辆是己方 RA2 天启。按玩家档案加载「北境天文台」和「熔芯双响」。同一存档中仅将车身切回原版就能降低行军帧耗时，齐射时每次双炮命中还会额外绘制裂纹。

星环刻度、旋转弧与彗光改为读取共享图集，炮塔表盘刻度和七星连线合批绘制。双炮的红色、金色裂纹用原绘制代码离线烘焙，第二发仍叠加原版小蘑菇云。星环在装填时用于展示的目标检查最多每 0.12 秒刷新一次，换目标时立即刷新。

## 同存档复测

在未切换到用户桌面的独立 Windows 桌面运行 Godot 4.7.2、OpenGL Compatibility，RTX 5060 Ti，实际输出 2332 × 1312。固定随机种子与 1/60 秒模拟步长，每次重载存档副本，在相同位置选中这组天启、下移动命令，再指定同一位置的高血量目标。每阶段记录 180 帧的实际耗时。下表取两轮对应指标的均值，测试顺序为新版、旧版、旧版、新版。

| 操作 | 中位帧耗时，毫秒 | 慢帧 P95，毫秒 | 整帧绘制调用中位数 |
|---|---:|---:|---:|
| 编队移动 | 24.1 → 19.0 | 36.6 → 30.0 | 1290 → 967 |
| 集中攻击 | 29.6 → 20.0 | 38.8 → 30.1 | 1780 → 833 |

各次回放中观察车辆移动距离均为 105.14 世界像素，开火阶段均记录到 12 个炮口闪光帧。皮肤工坊与实际武器的天启专项 33 项检查通过，包含地面双炮、对空灯、停车后星环回收和四个朝向的星图渲染。高负载下仍有约 30 毫秒的慢帧，实机流畅度以玩家体验为准。
