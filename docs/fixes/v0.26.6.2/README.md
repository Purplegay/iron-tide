# v0.26.6.2 · 大单位量战场 CPU 开销

在三个河流三角洲遭遇战存档的副本上验证。依次有 68／87／123 个单位和 46／24／26 座建筑。slot3 有 67 名美国大兵。加载后恢复战斗，再选择 25 个己方地面单位并下达移动命令。原始存档 SHA-256 已在测试前后核对。

- 自动 W 在既有的 0.25 秒施放检查中读取当前装配和开关。受击倒计时仍逐物理帧更新。
- 复用最近绘制的车体／步兵矩形，先排除明显没有指中的精灵，再用原来的透明像素、炮塔和伪装规则拾取。悬停判定复用同一次友军拾取。
- 固定射程武器先用距离排除远处单位。载员、独立防空武器、驱逐舰反潜、无畏战舰、报复追击及建筑边缘距离继续走对应的判定。
- 普通单位按当前状态进入隐形、冻结、定时炸药和英雄效果更新。没有临时增益时直接计算部署和基础属性。

**对照方法**　同一台 Core Ultra 5 250K Plus、RTX 5060 Ti、OpenGL Compatibility。隔离桌面、相同初始存档、随机种子和操作，固定每帧模拟步长 1/60 秒，记录帧之间实际经过的时间。每个阶段 240 帧。slot3 按旧、新、新、旧运行，表中取各版本两次对应百分位的均值，单位为毫秒。计时使用无分析插桩的工程。其他两档各进行一次图形对照。slot3 采样窗口没有飞行中的弹体，结果主要代表单位更新、选择和行军。

| slot3 场景 | 中位数（旧 → 新） | P95（旧 → 新） |
| --- | --- | --- |
| 读档后战斗 | 21.65 → 17.32 | 29.89 → 25.41 |
| 选中 25 单位 | 23.21 → 19.52 | 33.11 → 28.34 |
| 编队移动 | 26.39 → 23.47 | 33.71 → 33.02 |

另外两档移动时中位耗时：68 单位 21.92 → 20.70；87 单位 23.03 → 20.69。68 单位移动 P95 为 34.13 → 35.07，单次对照未见尾部改善。123 单位移动 P99 为 44.58 → 43.95，仍有慢帧。3700X 实机耗时待测。

自动 W、索敌、鼠标、选择、大兵群选、隐形与超时空表现后台检查合计 522 项通过。选取测试为飞机提供实际侦察视野、等待飞机绘制和退出视野后的留视到期，并用已经装配的 W 验证施放与冷却。
