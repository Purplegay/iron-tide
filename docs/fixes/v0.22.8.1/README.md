# v0.22.8.1　鲍里斯空袭、武装直升机炮位与基洛夫坠毁

## 原版对照

从本机 Steam 尤复读取 rulesmd.ini、artmd.ini、soundmd.ini 及音频归档。另以本机 gamemd.exe（SHA-256 `3e81a61775d2745d1dabe397325ef663cd994ffc194da4e998e3bf5d2d308600`）只读核对标定弹命中分支。0x469754 检查空袭资格，0x469784 进入 StartMission，0x41D830–0x41D84F 按状态派机或改派目标。0x41DCED–0x41DCFE 在最后一架退出时记录帧数。工程独立实现这些行为。Jumpjet 坠毁运动与军衔武器选择另对照社区行为参考 JumpjetLocomotor、ArmedTrait；连续坐标与原版实机的画面、声音尚未逐帧比对。

| 单位 | 本版行为 |
| --- | --- |
| 鲍里斯 | 标定弹命中建筑即标红和派机。普通两机、精英四机，每机一份弹药、一轮双弹。可将尚未发射的飞机改派到射程内的另一座建筑。改为移动、换步枪目标或丢失目标，未发射的飞机撤离。步枪独立冷却，最后一架离场或被击落后开始空袭再充能，普通 100 帧、精英 50 帧。 |
| 米格电台 | 玩家方长机按 soundmd 延迟 1.5 秒播放 MIGMove。中止任务整队只报一次 MIGMissionAborted。沿用原版声音样本。 |
| 武装直升机 | 下降期间复查泊位。SCHPDEPL 的 11 帧机身与相应阴影正放展开、倒放收炮。按项目每秒 15 规则帧和 Rate=100（每分钟 100 动画帧）换算，动画本身约 6.6 秒，升降另计。播放原机械声。转场禁止开火，落地后炮塔按 ROT 转向，机炮与地炮分别读取两套开火挂点。 |
| 基洛夫投弹 | 吊舱挂点为 -50,0,-140。按 BlimpBombP 的垂直落弹、加速度和武器速度推进，固定地面落点，目标能在触地前逃出。新存档保存下落进度，既有在途炸弹仍按保存的旧弹道结束。 |
| 基洛夫坠毁 | 死亡时生成独立残骸，在失去战斗能力的位置旋转下落。落地时仅结算一次范围伤害，普通／精英分别保留 BlimpHE／KTSTLEXP 及当时的火力加成。原弹头均为 250 基础伤害、2 格范围，分别按距离和装甲折算。落水使用 ExplosionWaterLarge，陆地使用 KirovCrash。 |

## 验证

无窗口苏联空军、苏联综合、遭遇战 AI、投射物生命周期、精英武器专项通过。覆盖改令前后、同一编队换标、空袭与步枪独立冷却、展开中读档、落点后来被占、抛弹中读档、残骸中读档、海上落点及重复触地保护。
