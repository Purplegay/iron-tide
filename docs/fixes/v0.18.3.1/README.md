# Iron Tide v0.18.3.1 · 尤复多处交火性能

敌方工厂入队、暂停、取消和出兵时，玩家生产栏无需同步刷新。玩家自己的工厂仍即时更新。解锁提示在一次卡片刷新内复用同类前置的候选建筑，查建筑标签时直接使用目录。

选中坦克的轮廓参数相同时复用原绘制命令。车体和炮塔按投影后的两个相邻朝向取最近帧，选中环和射程圈复用圆周顶点。视野重算后，只将变化的格子写入迷雾贴图，离开视野的渐变继续独立更新。

在独立桌面用 Godot 4.7.2、RTX 5060 Ti 跑尤复模式，4 辆磁暴坦克和 4 辆天启对 8 名美国大兵。单处持续交火的 300 帧采样中，帧耗中位数从 10.80 降至 9.53 毫秒，P95 从 23.14 降至 20.95 毫秒。4000 地图双处交火另跑 600 帧，开启 AI 和迷雾，双方版本均记录 8 次阵亡。该场景仍有超过 70 毫秒的单帧尖峰。耗时为本机后台实测。
