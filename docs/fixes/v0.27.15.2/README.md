# v0.27.15.2 · 友方闪电风暴提示

原先充能栏只收集敌方计时，发射警报也只处理敌方事件。电脑盟友可以实际发动风暴，玩家却收不到通知。

- 盟友天气控制器建成时发出情报和 EVA 提示。左上方以浅蓝色单独显示友方风暴的充能倒计时、暂停、就绪或发动中状态。
- 成功发动时立即显示十秒「友方已发动闪电风暴」，播报当前玩家阵营的风暴 EVA，同时在目标位置闪烁蓝色小地图标记。标记可以显示在迷雾上，仍按原规则计算视野。
- 玩家自己发动时显示「我方」。敌方有独立的警报和计时，两边可同时提示。读档恢复已有风暴时延续状态，只在新发动时播报。

后台用真实结盟遭遇战验证电脑盟友发动风暴，检查情报收起时的提示、充能、就绪、发射、落点、EVA 事件、重复施放被拒和超时清除。多方 AI 243 项、战略警报 196 项、风暴 265 项，共 704 项通过。语音事件和 HUD 状态已验证，扬声器听感与玩家分辨率下的显示待实机确认。
