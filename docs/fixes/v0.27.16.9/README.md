# v0.27.16.9 · 可调镜头与 AI 决策错峰

主菜单、战斗内设置共用镜头速度控件，范围为原始速度的 0.30～3.00 倍，默认 1.50 倍；边缘滚屏与方向键立即同步，拖动时实时预览，松手保存，重启保留。战斗设置增加滚动容器，避免设置项超出窗口。

## 慢帧处理

- 多家电脑同时到期的战略决策每个渲染帧仅放行一家，其余保留到期状态，下帧继续；同一家的连续调用不重复扣预算。只错开重决策，不降低玩家命令、采矿、收入、单位移动、攻击或游戏时钟频率。
- 建造搜索复用可建区域的候选格；区域、建筑占地、地图尺寸变化时重建。实际占用、迷雾、地形与出入口仍逐次校验，不能直接使用旧的可建结论。
- SHP 动画帧边界与落脚锚点离线计算，避免战斗中首次切换动作时逐像素扫描大图集。188 套图集、原始透明阈值保持一致；缺失或帧布局变化时仍走原扫描。像素点选和海豚发射点保持按需读取原图。

本轮按用户要求暂停内存专项工作，不加入退出战斗清缓存改动，不以减少内存宣称性能改善。

## 同档验证

隔离用户目录、Godot --headless，无桌面窗口。327 单位、155 建筑的 yr_isleland 存档，1 倍速，每阶段约 15 秒模拟时间。两轮复跑结果如下（P95 毫秒）：

|阶段|旧版两轮|本轮两轮|
|---|---|---|
|交战|59.779 / 70.616|50.975 / 53.918|
|选择|77.801 / 91.639|67.202 / 68.414|
|移动|93.107 / 82.017|75.803 / 74.272|

模拟时间与墙钟时间接近，未靠减慢 1 倍速取成绩。该存档选择阶段仅 1 个可选友军，不代表大部队框选基准。无头测试也不等于实际 GPU、窗口滚屏手感验收。**尚未达到 P95 20～30 ms 目标**；单位更新、交战和迷雾仍占慢帧，不能将本轮改善全部归功于 AI 决策。

[原始阶段指标与源文件指纹](performance.json)。第二轮试验含退出场景清缓存，但所有帧耗时样本都采于退出前；此改动已按用户收窄范围撤回。
