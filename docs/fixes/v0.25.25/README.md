# v0.25.25 · 国家特色隔离与对手国家选择

2026-11-05。新增对手国家选择，按新需求递增第三段版本号。

## 修改内容

原先扩展模式跳过全部国家限制，导致各国专属兵种混用；敌方设置只有盟军／苏联，苏联还会在开局被固定成苏俄。现在 RA2 与扩展模式都按原规则中的 Owner、RequiredHouses、ForbiddenHouses 判定。玩家与 AI 共用生产权限，AI 候选池也排除其他国家的专属单位。

| 国家 | 国家特色 |
| --- | --- |
| 美国 | 空指部美国大兵空降 |
| 韩国 | 黑鹰战机，替换入侵者；扩展开局赠机也改成黑鹰 |
| 法国 | 巨炮 |
| 德国 | 坦克杀手 |
| 英国 | 狙击手 |
| 苏俄 | 磁暴坦克 |
| 古巴 | 恐怖分子 |
| 伊拉克 | 辐射工兵 |
| 利比亚 | 自爆卡车 |

遭遇战「对手国家」可选上述九国，扩展模式额外保留虫群巢穴。敌方基地、AI 生产目录与国家专属权限都使用所选国家。其他国家的专属产品仍按已有侧栏行为灰置，并说明国家限制。俘获敌方工厂仍可生产其普通兵种，不绕过真正的国家专属条件。

## 记忆与兼容

沿用 Godot ConfigFile 的 user://lobby_preferences.cfg，新增稳定的 enemy_country 值，关闭游戏后仍保留上次选择。旧盟军设置迁移为美国、旧苏联设置迁移为苏俄；虫群在纯 RA2 模式下恢复为美国。国家选择优先于缓存的阵营字段。已有地图、玩家国家、各国阵营色记忆保持。

打开大厅、修改下局配置不会覆盖正在运行的对局国家；已有战斗存档的 _countries 字段继续原样恢复，未修改存档格式。此次修正会让旧扩展对局的后续生产也遵守其所属国家，不回收已经存在的单位。
