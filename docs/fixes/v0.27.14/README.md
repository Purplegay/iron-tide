# v0.27.14 · AI 要塞乘员与盟苏出兵权重

电脑的战斗要塞优先招募十格内、陆路可达的己方美国大兵，按距离分配座位，最多五人。已有乘员、其他兵种占用的座位及已获派登车的乘员均计入。参与交战的大兵继续作战；可受调度的卧倒大兵起身后登车。接人时要塞可原地等候十二秒，满员后即可随部队行动。乘员通过实际登车流程入车，可从车内开火。

己方要塞存在空位且现有和在训美国大兵不足时，兵营会按正常价格排队补员。紧急防空、采矿预算、科技、国家限制、人口和生产队列规则继续生效。
