## 规则

删除「衰变采样」天赋的配置、购买／装配入口、图标映射、演示及战斗中的三秒采样、额外伤害和提示。辐射范围天赋「辐射扩散」保留。

仅改变部署辐射的技能强化加成，不强化 Q、W、装配被动或普通手持武器，不修改辐射原有衰减、跳伤间隔和范围。合并辐射场取已有倍率与新释放倍率的最大值，不逐次相乘。经典 RA2 模式没有这项养成加成。
