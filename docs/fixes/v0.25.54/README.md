# v0.25.54 · 单位改造直接换皮肤

在「单位改造 → 选择兵种」的模型下方加入皮肤选择器。尤复单位列出原版、通用皮肤及该兵种的专属皮肤；RA3 单位使用现有整机涂装目录。没有适用皮肤的对象不显示无效入口。

- 选择已拥有皮肤后立即保存，并刷新当前模型；可切回原版。
- 未拥有皮肤显示对应胜场、科技或涂装工房解锁条件，不能装配。本入口只切换，不购买、不扣费。
- 复用涂装工房的兼容性、同名所有权和 `MetaProgress.set_cosmetic` 保存入口；共用原有 `unit_cosmetics` 存档，不新建另一套皮肤数据。
- 只改变当前兵种的皮肤／涂装槽，保留其它兵种、挂件和武器特效。
- 切换时留在单位改造页，当前兵种和滚动位置不变；重新打开恢复上次兵种和已保存的皮肤。
- 写入失败则回退选项，模型和已有装配不变。英雄专属装甲仍在英雄养成管理，本入口切换普通兵种的皮肤。
