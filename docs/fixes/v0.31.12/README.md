# v0.31.12 · 远征第 20 关机动指挥车

原先指挥车第一次转移会向玩家基地到敌营连线的 35% 处攻击移动。现在它在敌营附近三个防守点之间转移，只走可达且绕行距离合适的路线。没有合适路线时就地防守。玩家可以先做支线，也可以直接突袭指挥车结束战斗。

指挥车仍以 30 秒为基础转移间隔，每拆一座节点增加 20 秒。读取带有旧前进命令的第 20 关战斗检查点时会重新选择防守位置。

后台专项在原生地图 yr_hidvally 和测试地图 exp_plain 上通过 50 项断言，覆盖普通犀牛与任务车的区别、三个转移点、AI 调度、拆节点、检查点恢复及过关。在 yr_hidvally 上另以正常 AI 推进 95 秒，指挥车存活并发生位移，战斗仍在进行。该对局使用独立测试存档。完整支线的游玩节奏待实际体验。
