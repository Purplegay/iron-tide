# v0.27.7.1 · 大部队追击与战争迷雾按帧耗时降频

按真实画面帧耗时采样，每约半秒评估一次。窗口均值达到 33 毫秒时降一档，连续四个窗口均值在 23 毫秒以内才恢复一档。单帧计入窗口的时间最多 100 毫秒。暂停后重新采样。

| 从正常到最高压力 | 正常 | 一档 | 二档 | 三档 |
|---|---:|---:|---:|---:|
| 已有追击路线，移动目标重算间隔（游戏秒） | 0.35 | 0.55 | 0.80 | 1.10 |
| 常规视野重算间隔（游戏秒） | 0.10 | 0.16 | 0.24 | 0.32 |

压力升高时按单位错开最多 0.096 游戏秒，追击遇阻重试也随之放慢。玩家新下达的攻击命令立即规划路线，遇敌开火照常判定。视野渐暗继续逐帧更新，隐藏单位首次开火、开火暴露结束及战略武器揭示单独处理。F8 性能快照中的 adaptive_refresh 记录当前档位、基础间隔、追击重算和全图迷雾重建的累计次数。

用同一局“电路板”后期存档副本测试，开始时 316 个单位、95 座建筑，3 倍战速。Godot 4.7.2，独立 Windows 桌面 OpenGL 渲染，RTX 5060 Ti，关闭垂直同步。每组两次，各运行 180 个物理步，工作量按首末采样之差统计。

| 指标 | 固定频率两次 | 自适应两次 |
|---|---|---|
| 追击重新规划次数（含受阻重试） | 382、389 | 245、235 |
| 全图迷雾重建次数 | 70、71 | 38、38 |
| 帧耗时中位数 | 64.5、62.8 ms | 59.0、60.5 ms |
| 第 95 百分位帧耗时 | 97.6、98.5 ms | 85.9、90.8 ms |

高压下已经在追的部队会稍晚调整路线，普通移动侦察也可能稍晚发现目标。此存档仍有明显慢帧。该结果是本机同档对照，3700X 上的实际帧率需单独测量。
