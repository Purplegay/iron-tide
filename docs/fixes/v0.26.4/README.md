# v0.26.4 北辰与铁脊主炮对空

英雄灰熊「北辰」与英雄犀牛「铁脊」的重装生存 5 级允许主炮攻击空中目标。对空每发使用当前主炮基础伤害的 50%，再按同一套弹头、装甲和养成计算。落地目标使用正常伤害。炮弹飞向空中的命中点，对空爆炸只结算空中目标。英雄养成演示同步显示对空射击。

两辆英雄坦克改用通用碾压判定。能够碾压步兵的载具可对仍可碾压的卧倒美国大兵造成碾压伤害，部署后的重装大兵具有保护。5 级原有爆炸致命一击伤害上限继续生效。天赋沿用战斗记录中已有的重装生存等级。

无窗口检查通过 95 项，包括对空开火与命中 16 项、英雄坦克原有机制 79 项。同一架入侵者在空中／落地时，北辰单发实扣 35／71，铁脊 49／99；差 1 点来自整数伤害取整。
