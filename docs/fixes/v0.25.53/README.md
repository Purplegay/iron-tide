# v0.25.53 · Auto W 战术科技

新增「自动战术施放 · Auto W」永久科技，消耗 40 战略核心，仅在开启科技后的新扩展对局生效。经典 RA2 与未研究的对局仍只有手动 W；不自动施放原生 Q 或特殊操作 E。

## 自动施放条件

| W 卡牌 | 条件 |
| --- | --- |
| 烟幕弹 | 最近 3 秒受到实际伤害，且生命低于 70% |
| 引擎超载 | 已在移动，距离当前目的地超过 5 格 |
| 聚焦射击 | 已有可见有效攻击目标、对准且武器即将开火 |
| 连锁放电 | 即将开火，主目标周围 2 格内还有可见地面敌人 |
| 震荡脉冲 | 范围内至少 2 名可见地面敌人；生命低于 40% 时 1 名即可。包括磁爆步兵、磁暴坦克和磁暴线圈，断电线圈不能施放 |
| 炮座齐校 | 天启主炮模式，即将开始新一轮双炮攻击 |
| 斜甲迎击 | 停车，且最近 3 秒受到车首左右各 60° 内敌人的攻击 |
| 假象转移 | 最近 3 秒受伤，且正在执行移动指令；不会自动撤退或改路线 |
| 分区射击 | 保留主目标；自身血量至少 80%，或剩余血量至少为副目标的 2 倍。副目标必须可见、位于侧炮射界及射程内，优先剩余血量低者；有效的手动副目标不覆盖。移动形态与部署形态共用 |

搜索浮标保持手动放置。未列出的 W 不自动施放。原生 Q 即便与上述通用卡同名，也不会被当成 W 自动触发。

## 操作、状态和存档

- 研究后默认开启。技能栏 W 旁增加「AUTO 开／关」，悬停显示对应触发条件；也可右键 W 图标切换。冷却中仍能使用旁边的开关。
- 按兵种记忆，切换影响该兵种所有现存单位及后续生产单位；多选时统一切换选中的可用兵种。部署收割者沿用 R3REAPER 的选择。
- 局外科技仍有原有的「在新对局中启用」开关。战斗内 Auto 设置随存档保存；读档使用当时设置，新局使用最近保存的兵种偏好。
- 暂停、结束、死亡、时空冻结、眩晕、驻载、维修、跳跃／空降、失能与 GM 靶标状态不施放。玩家正在选取技能或命令目标时暂缓自动施放。
- 使用原技能释放入口和真实冷却、效果，不额外生成一套伤害计算。分火复用手动指定副目标的同一验证和写入函数，不切换鼠标指令模式。
- 每个单位约每 0.25 秒检查一次并错开首轮时点；附近目标使用战场共享的分格索引，避免每个单位每帧全量扫描。这里只验证调度与行为，不声称已经证明大军团 FPS 改善。
- 偏好写入采用临时文件替换；失败时不改变当局开关。未修改真实玩家存档。
