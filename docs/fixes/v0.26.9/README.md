# v0.26.9 · 炉火契约技能演示

在技能卡池点「炉火契约 · 查看技能联动演示」可直接进入预览。碎片不足和已拥有契约时都能查看，500 碎片兑换使用独立按钮。英雄养成的炉火契约面板也提供联动入口，英雄装配栏的「技能演示」直接定位到对应单卡。

联动演示中，炉火先手动卧倒，空敌进入射程后两辆履带车出现并射击。可分别选择两张卡的 0～3 级，比较卧倒移速、护盾、溅射以及车辆存续时间、攻速和加速衰减的血条。W 演示可切换受击破盾、带盾起身和自然消盾三种结果。画面标注被动的再次召唤倒计时。预览使用独立时间轴，可暂停、重播、慢放和拖动，不写入战斗、钱包或养成进度。

炉火专项在后台运行，90 项行为断言通过，包含预览入口、兑换按钮状态、返回来源、分别选择技能与等级和时间轴上的触发条件。引擎退出时仍报告资源释放告警；预览的实机画面与手感待确认。
