# v0.25.24.1 · 岸防背架姿态

以 GGI 原始 94×78 图帧的上肩甲为基准，离线采样 222 个站立、步行、开火、姿态转换、部署和待机帧。两段单朝向待机动画各有 15 帧，背架按对应动画中的人物转身角度显示。部署时改以阵地后沿为固定座，收紧携行尺寸，按观察方向先绘制远镜，拉开近镜与发射筒的高度。重建挂点可在仓库根目录运行 `node ra2pipe/ggi_shoulder_sockets.mjs`。

[八向站立与部署](ggi-facings.png) · [两段待机动图](ggi-idles.gif)

展示专项 792 项、原生步兵待机专项 183 项、重装大兵部署控制专项 114 项通过。同一待机帧分别由相反指令朝向进入，比较游戏内渲染结果；两段均逐帧一致。工房观感待确认。
