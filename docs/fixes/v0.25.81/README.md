## 行为

- 仅新开的扩展模式凶残 2 遭遇战启用。经典模式、其他难度不受影响。
- 先合并玩家全局攻击、兵种攻击、英雄火力训练的倍率 m。m≤2 时原样保留；更高时令 t=ln(1+(m−2)/1.5)，有效倍率为 2+1.5×t/(1+t)。该曲线平滑趋近 3.5，不是额外 +350%，也不是任意单次伤害的硬上限。
- 20 级常见组合 (1.35+20×.03)×(1+20×.03)=3.12，压缩到约 2.537。英雄满火力训练的同组合 12.48 倍也先合并后压缩，不在普通单位压缩结果上直接乘 4。
- 被动卡、临时增伤、军衔、部署攻击、武器弹头克制与目标护甲仍按原来的顺序和倍率计算。AI 自身难度加成不压缩。
- 玩家建筑应用全局攻击部分；投射物沿用已计算的发射者攻击快照。固定伤害、百分比或不消费养成攻击的机制不另加一层压缩。
- 压缩在单位／建筑初始化及英雄晋升时计算，不在每次命中或每帧重新取对数，不增加搜敌、粒子或护盾实体。
- 新规则上限写入冻结的对局上下文。旧战斗缺少该字段即保持原样；读档还原已结算的倍率，读档后新增单位继续采用该局规则。
- 凶残 2 大厅提示同步说明 200% 起压、350% 上限和新局范围。
