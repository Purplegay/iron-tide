# v0.27.12.1 · 桥沿寻路与岸边脱困

Circuit Board 木桥上的一段边缘在原图上允许通行，但旧寻路网格把它归到了水中。六张导入地图现在按原图 55 世界单位的格子建寻路网格。建造或摧毁建筑后重算与读档仍走同一张地形网格。

地面部队执行移动命令时，若已被碰撞挤出桥面，可在自身半径附近寻找能抵达的桥面或陆地。它会实际驶回后重算原有路线。远离岸边的深水没有这种出口。

后台在经典和扩展模式各验证了一次：旧版在桥沿内侧 2 世界单位误判为水，坦克在桥沿外侧 8 世界单位无法回到桥上。修复后两项均通过。灰熊、美国大兵、犀牛混编跨桥并返回。另覆盖六张原图的新局与读档、采矿，以及自制地图的桥梁和海岸。
