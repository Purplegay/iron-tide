# v0.26.5.1 · 坦克通过建筑夹道

原有寻路以 40 宽的网格记录建筑占地。建筑边缘碰到一个格子就会封住整格，两侧合在一起会盖住实际可以通车的开口。灰熊、犀牛的行驶碰撞直径均为 30。修复前，两个电厂之间 38 和 52 宽的净空都被绕过。

现在在规划地面车辆的移动命令时，根据实际车体半径、建筑底座多边形和障碍形状检查直线路段。偏侧接近时，车辆可以通过入口与出口的对齐点组成折线，每段都检查地形、净空及部署单位。坦克之间让路时会扣除两车已有的横向距离，并检查侧移空间。长距离复杂地形继续由共享网格规划。

经典和扩展模式均测试 26、38、52、92 四种净宽。可以容纳一辆坦克的直通门实际产生直达路线，26 宽的门绕行。三辆灰熊和犀牛从侧面编队接近，全部穿过 50 宽通道抵达目标。逐步检查车体与两侧建筑底座的相交情况。另检查门内停车让路、12 个单位双向通车、50／100／200 混编行军，以及部署步兵与建筑阻挡。

后台无窗口验证共 382 项。tank_passage_regression 18 项，traffic_regression 52 项，deployed_traffic_regression 280 项，navigation_building_regression 32 项。
