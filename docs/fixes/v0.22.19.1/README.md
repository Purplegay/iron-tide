# v0.22.19.1 · 盟苏占领、偷科技与武器音效

- 占领对方战车工厂后，指令甲板增加该工厂的尤复产品，普通前置、停车位和国别专属限制继续生效。工厂被夺回后收回对应目录。占领异阵营建造场后可建造该阵营建筑，即使本阵营建造场已经被摧毁，仍可推进对应建造队列。
- 原规则给予超时空伊文、超时空突击队、心灵突击队通用兵营前置。两个阵营的兵营均识别对应窃取科技，归属和已付费订单随战斗存档恢复。普通盟苏地图仍需有相应实验室才可能获得该科技。
- 海豹、谭雅和载美国大兵的多功能步兵车回到各武器的原版 Report。鲍里斯、米格、部署的武装直升机补入本机尤复音库的 4 段 PCM 采样。复测了实际武器选择、普通及精英武器、全部变体资源的解码和游戏音频播放入口。
- 针对生产队列右键，复现发现旧测试在 1600 × 900 窗口中点到了滚动区域下方。先滚到队列头像，第一次右键可暂停，第二次取消一个。头像专项按所属生产厂和实际国家测试，韩国造黑鹰、美国造入侵者，单位头像在左侧名单显示。

## 验证

Godot 4.7.2 无窗口、隔离玩家目录。10 个专项共 4,323 项断言通过；其中本版新增 [跨阵营生产和武器音效回归](../../../iron_tide/tests/captured_production_regression.gd) 86 项。另用原审计三个探针复测美国、法国、苏俄的敌方车厂、双方偷科技、六种开火音效与美国大兵对照组。听感和混音尚未经实机确认。
