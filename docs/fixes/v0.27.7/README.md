# v0.27.7 · 战场护盾数值与吸收伤害飘字

可见的带盾建筑和单位在血条上方显示剩余盾量。凶残3建筑每次吸收伤害时显示实际抵消的数值，穿盾命中同时列出生命损失。 满血、满盾、未选中时也可看到数字。护盾耗尽后收起常驻读数。该显示针对有数值的护盾，包括凶残3建筑、坦克英雄和炉火部署护盾。

战场使用原有血条层绘制读数，按屏幕范围和战争迷雾筛选建筑。建筑命中飘字锚定在建筑位置、绘制在血条上方，吸收值来自实际扣盾量。满额吸收仅显示护盾损失，破盾溢出时合并展示护盾与生命损失。

无窗口专项通过 543 项：凶残3 104 项、护盾伤害路径 254 项、炉火契约 106 项、坦克英雄 79 项。实际命中测试核对了护盾尚在和伤害溢出时生成的飘字。炉火和坦克英雄专项退出时有 Godot 资源释放告警。实机战场的文字大小与遮挡情况待视觉确认。
