# v0.26.7.1 · 单位受阻后绕行和恢复移动命令

单位遇到停在路上的友军会重新规划绕行。途中建筑暂时封住通道时保留原目的地，通道打开后继续前进。

美国大兵起初会在七辆警戒犀牛前受阻。现在连续约 0.9 秒未向当前路点取得进展时，使用附近实际挡路的静止友军，计算本次命令的临时绕行路线。移动中的编队以及正在让路的单位继续使用原有局部避让。

建筑截断已下达的移动命令时，保留玩家的目的地，走到当前可达处后重试。玩家可以用停止或新的移动命令覆盖它。

后台在经典和扩展模式测试警戒车列、封路后友军撤走、途中建厂完全封路后拆除、取消等待命令。另验证建筑通道、部署阻挡、海军导航、战斗移动与 50／100／200 混编行军。七组共 594 项通过。
