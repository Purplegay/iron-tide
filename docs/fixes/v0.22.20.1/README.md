# v0.22.20.1 · 围墙与战略支援无窗口回归

围墙和战略支援专项原先无条件等待画面绘制完成，在无窗口模式下超时。现在逻辑、素材和命中检查可独立执行，有图形渲染器时继续截图。本版改动集中在测试与记录。

- **围墙**。在纯 RA2 与扩展模式中，检查盟军围墙、苏联围墙与旧沙袋素材的四方向 16 种连接组合、三个血量档位、地基大小和当前可见像素的鼠标命中。另测点选相连墙体、编队召回、单卖与整组退款、拆毁后更新寻路；苏联防御和支援建筑专项还覆盖连续放墙预览、实际连接和扣费。沙袋仅作为旧素材测试。
- **战略支援**。从已充能的天气控制器释放，核对目标上空的云动画资源、落雷位置、同点爆炸和实际伤害，以及环境光变暗、结束后恢复。超时空传送仪从真实释放入口检查坦克位置、起点和落点两处动画。裂缝产生器核对十格半径、说明与卫星侦察交互。
- **结果**。Godot 4.7.2 使用独立玩家目录，无窗口执行。围墙 1,422 项、战略支援表现状态 26 项、支援建筑 338 项、闪电风暴 263 项、苏联防御 91 项、战略落点 54 项，共 2,194 项通过，脚本及引擎报错为零。实际屏幕上的色彩、亮度与动画观感未验收。
