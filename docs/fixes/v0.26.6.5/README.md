# v0.26.6.5 · AI 军舰近岸还击

盟军驱逐舰会用 155 毫米主炮还击岸上的攻击者。AI 每半秒检查近期来袭火力，海军调度也尊重这一目标。攻击者稍超射程时，舰船会在同一片可通航水域内寻找开火位置，最多对武器射程外两格的来袭目标作出这种追击。进入射程后若主炮仍在装填，会给它留出下一次开炮机会。

还击使用现有的目标可见性、武器目标类型、射程与装填规则。停火、维修和冻结期间不会触发这次改令。对潜目标仍走驱逐舰原有的反潜机流程。

后台回归在纯 RA2 与扩展模式中让驱逐舰先瞄准另一艘船，再被射程外的岸上重装大兵打中。修改前连续推进 10 秒，驱逐舰留在原地，步兵满血。修改后驱逐舰从相连水域接近，主炮实际扣除了步兵生命。另覆盖停火、攻击者死亡、常规海军调度与反潜机出击。航空反潜与遭遇战 AI 两组回归合计 516 项通过。
