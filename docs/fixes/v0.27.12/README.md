# v0.27.12 · AI 交火调度权重

遭遇战里，当上一帧积压的 AI 单位超过当前帧名额时，最近向敌人开火、遭到敌人射击或正在反击的单位优先获得调度和寻路机会。单纯锁定远处目标仍按普通队列处理。向敌对单位或建筑开火时标记交战双方，标记持续两秒对局时间。已有反击计时或受击反馈也可提供优先资格。

| 每帧 AI 单位总名额 | 交火组 | 普通组 |
| --- | --- | --- |
| 128 | 96 | 32 |
| 64 | 48 | 16 |
| 32 | 24 | 8 |
| 16 | 12 | 4 |

两组各按等待顺序领取名额，任一组用不完，另一组可用满剩余名额。玩家命令即时下发。

后台专项用三个电脑席位的 168 个单位验证。21 项检查通过，覆盖双向交火、友军排除、优先级过期、普通单位持续推进、两组互借、总限额、玩家立即下令及存读档续排。另用槽位 3 副本无窗口回放十秒，从 325 个单位、111 座建筑恢复并推进战斗。
