# v0.25.46 · 机制强化迁入专属天赋

2026-11-05。删除单位改造中的独立“技能强化”购买项，把保留的兵种机制迁入专属天赋；收割者分区射击改为 W 抽取卡。

## 本次规则

所有新天赋都有解锁 0 级及 1／2／3 级。升阶沿用 40／120／240 战略核心费用，分配和开关沿用现有天赋系统；以下收益仅用于扩展模式，不强化装配 W、被动卡或额外的 Q 卡牌数值。

## 收割者分区射击

- 史诗主动卡，仅收割者可装备到 W。加入现有抽卡池、兑换和卡牌展示。
- 先下达主目标攻击指令，再按 W 或点按钮，选择侧炮射界内的另一个可见地面敌人。主目标射击继续，侧炮副目标伤害按卡牌 0～3 级为原值的 100%／110%／135%／150%。
- 行走形态与部署炮台共用该卡；停止／重新下令清理分火。协同瞄准仍是独立天赋。
- 原有分区射击天赋转为同等级已拥有卡牌，释放原分配点，保留已购天赋格；不覆盖玩家当前 W 装配，需要自行装备。
- 对旧局保留旧分区能力读取，操作入口改为 W；修正旧局没有 Ability 卡牌对象时悬浮说明报错。

## 旧档处理

沿用现有 JSON 局外存档与战斗快照，没有新增存储类型或编码器。

- 旧技能强化 1～6／7～13／14～20 级，分别折算成专属天赋 1／2／3 级；0 级不自动分配。
- 保留原有其他天赋和属性改造，免费补足迁移所需的天赋格与分配点；原关闭状态映射为对应新天赋关闭状态。
- 已删除的运输／无对应机制养成按旧每级价格累计返还军需券；不扣已有等级的额外核心。
- 重复读档不会重复发点、退款或加卡。原子保存失败保留原存档字节，重试从原持久化余额重新迁移。
- 新对局冻结 `native_training_version=4`，只读取对应天赋。旧 v1～3 对局仍读取原冻结机制倍率；运输加速统一停用。新天赋等级不会回写已开局战斗。
