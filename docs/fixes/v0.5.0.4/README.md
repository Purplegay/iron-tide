# Iron Tide v0.5.0.4 修复说明

2026-10-28

- 按官方起义 XML 修正先锋武器模式：移除未被原版状态调用的 DEPLOY 播放，切换 SkinGuns、SkinMachinegun、Cylinder01；补齐原始炮口网格、发光部件和开火光源，炮塔使用侧向自然角、转向限制及俯仰速度。

- 六组回归 1141 项通过，含新增炮艇表现专项 40 项；报告及图形阶段采样见 RA3_PORTING 的本版交接。
