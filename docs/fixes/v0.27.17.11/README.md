# v0.27.17.11 · 单位更新、交战与迷雾热点

这轮减少重复计算，没有改变单位移动速度、武器冷却、模拟频率或玩家命令优先级。部分阶段有改善，但整局慢帧仍然严重，不能视为卡顿已解决。

## 修改

- **单位更新**：普通地面单位没有装载、卸载、弹药或舰载机事务时直接跳过运输更新；保留武装直升机部署特例。已起飞的舰载机继续处理死亡与重建计时，跳过无法再次起飞时的目标检查。移动中的飞机跳过自动降落所需的重复目标检查。
- **交战**：同次选敌／射程判断复用已经解析的武器，仍实时检查遮挡、乘员武器和目标有效性。增益计算从多遍扫描合并为一遍，保留各类型乘法顺序；没有跨帧缓存武器或增益。
- **迷雾**：大部队离开视野时，将各侦察者离开的区域按同盟合并，再更新共享视野保留时间。保留“各自旧区域减各自新区域”的语义；不把其他单位仍覆盖的区域错误扣除。原生字节搜索跳过空掩码，少于 64 个侦察者仍走旧路径。5 秒视野保留、渐暗和探测规则不变。

## 性能证据与限制

使用凶残 3、3 倍速、3v3 压力模拟的两个繁忙检查点，分别有 333／294 个单位、210／188 座建筑。基线为本轮修改前冻结的 v0.27.17.10 脚本，补丁见 `optimization.patch`，不是与仓库旧 HEAD 比较。

全部顺序运行，Godot 4.7.2 headless、CREATE_NO_WINDOW、独立用户目录，不打开窗口，不改玩家存档。主机是 Intel Core Ultra 5 250K Plus，未在用户的 Ryzen 7 3700X 验证。每阶段预热后采样约 30 秒模拟时间，保留现有运行时帧调度。以下是无计时探针的墙钟帧间隔 P95，不是图形渲染 FPS。

| 地图／阶段 | 修改前 P95 | 修改后 P95 |
|---|---:|---:|
| Islands on the Land · 交战 | 141.685 ms | 141.508 ms |
| 同图 · 框选 | 147.602 ms | 136.317 ms |
| 同图 · 移动 | 143.993 ms | 139.548 ms |
| Ice Age · 交战 | 154.297 ms | 170.368 ms |

第二张图的 P95 变差，不能选择性忽略。该图中位数约 107 ms，前后基本相同；移动／框选阶段因玩家已阵亡而未测。使用墙钟驱动会产生不同寻路次数和交战轨迹，因此以上不构成完全确定性的 CPU 微基准。第一轮整图扫描掩码的实现没有收益，已改为跳过空白字节；重复测试也没有证明整局 P95 稳定下降。

独立带探针短测中，迷雾重建累计耗时约 703 → 605 ms（33 → 32 次调用，每次均值约 21.3 → 18.9 ms）。这是热点定位证据，含探针开销、样本数量不同，不与整局帧耗时混用。单位更新仍是主要开销，交战、寻路与其他世界逻辑仍需后续定位；20～30 ms 的目标未达到。
