# v0.27.16.1 · 多方大战 CPU 占用

样本为 Islands on the Land 凶残 3 旧档。入场 327 个单位、155 座建筑，含 51 名疯狂伊文、14 艘基洛夫、8 辆战斗要塞。玩家提供的日志只记录 Godot 4.7.2 与 RTX 4070 SUPER。以下数据来自隔离桌面的实际图形回放，测试机为 Intel Core Ultra 5 250K Plus、RTX 5060 Ti。测试使用 1 倍速、固定 60 Hz 步进、预热 60 帧，每段 240 帧。原档只有一个可供本脚本框选的玩家地面作战单位。帧间隔包含物理、脚本和渲染等待，固定步进的数字不能直接当作玩家机器帧率。

| 回放阶段 | 改前中位 / P95 | 改后中位 / P95，毫秒 |
|---|---:|---:|
| 自由交战 | 52.1 / 80.8 | 44.9 / 65.8 |
| 选择玩家部队 | 55.3 / 88.3 | 46.8 / 69.5 |
| 下达移动命令 | 54.6 / 89.6 | 45.9 / 67.6 |

分项计时在独立回放执行，计入被调函数与插桩成本。父子项不能相加。详细数据见 [measurements.json](measurements.json)。

| 脚本范围 | 改前 → 改后平均毫秒/帧 |
|---|---:|
| 单位物理与行为总计 | 35.94 → 31.87 |
| 其中，交战与移动控制 | 9.78 → 9.54 |
| 其中，重新搜索攻击目标 | 4.63 → 1.74 |
| 建筑每帧逻辑 | 10.31 → 6.34 |
| 单位绘制指令生成 | 6.07 → 5.63 |
| 战争迷雾重建（摊至全部帧） | 2.18 → 1.37 |
| 每家电脑的经营指挥更新合计（house_ai） | 1.06 → 1.06 |

精炼厂只查询矿车，共享充能设施按能力分组并实时判断所有权、电力与生存。战斗要塞先以可用武器的最大射程排除远处目标，特殊乘员保留完整判定。驻军先按距离排除远敌。屏外尤复单位省去本体绘制，回到画面时重绘。多方大战按同盟合并普通侦察范围，各家保留自己的已探索和限时视野。

回归覆盖精炼厂排队、战斗要塞、支援设施、超武、96 名大兵框选、迷雾和新旧视野逐格一致性。迷雾套件中四项平局局外数据断言在改前与改后均失败。本轮尚未在 Ryzen 7 3700X 上复测。
