# v0.25.60.3 · 护盾受击反馈与入口核对

## 诊断与修改

用户反馈部分子弹疑似无视英雄坦克护盾。当前源码的普通伤害入口在扣生命之前统一调用护盾吸收；本次实际命中检查未复现绕过护盾扣血，因此不将数值问题宣称为已定位或修复。

已确认的表现问题是：护盾吸收全部伤害后，原逻辑仍触发生命条白闪／残影并飘 0，易误认为生命受伤。现在完全吸收只显示蓝色「护盾 -数值」，不产生新的生命条受伤闪烁；超出盾量时显示「护盾 -数值 · 生命 -数值」，保留真实扣血闪烁。命中爆炸、弹体及受击摇晃仍按实际接触表现。

「被动／天赋」详情增加当前盾量／上限、持续剩余时间、最近一次实际护盾受击的来源、弹头、吸收和扣血值。最近一击为临时元数据，不污染存档，且只记最近一次有实际吸收的攻击。满血以外的旧伤不会因蓄盾恢复。

不改护盾容量、蓄盾间隔、持续时间、伤害计算顺序或破盾伤害。超时空擦除等直接移除机制未改为普通伤害保护，也未把其当作本轮普通弹药验收结论。
