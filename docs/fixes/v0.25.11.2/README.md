# v0.25.11.2 · AI 集结分开停车，战车工厂门口留出通道

盟苏 AI 之前会把新造部队和归队部队派往同一个坐标。当它靠近厂门时，前面的坦克停在出口，后车继续向同一点挤。进攻部队此前也共用目标点和流场。

- AI 集结时为每个单位选择可达且能容纳车身的独立落点，给己方生产设施和矿场预留空间。已经占用的位置和友军正在前往的位置都计入间距。地面集结令使用实际寻路结果。
- 集体进攻和基地增援沿用玩家编队的间距及落点分配。原有出击人数门槛、预备队人数和攻击移动语义保留。
- 读入旧档，仍在前往同一集结点的预备队可在下一次 AI 整队时重新分位。行进途中如有新建筑封住预定停车位，AI 会重新选点。
- 验证使用 Godot 4.7.2，无窗口，独立玩家目录。把集结点故意放在实际厂门，在真实出厂回调和物理帧下连续生成 8 辆灰熊或犀牛。修复前两座工厂都出现落点重合、坦克未能全部离开厂门、后续主出口被占用。修复后各 8 辆全部停稳，第 9 辆能使用原主出口。另覆盖旧集结令存读档、途中施工和进攻、防守命令。
- 最终快照的 8 个专项共 1,224 项通过。[工厂堵车专项](../../../iron_tide/tests/skirmish_traffic_regression.gd)。另在本轮较早快照上独立重跑通用交通压力套件，52 项通过，纯 RA2 和扩展模式的双向窄路均有 12 个单位全部通过。
