# v0.27.3 · 结盟胜利收益与越级补正

扩展遭遇战每带一名电脑盟友，胜利收益减少 10%，最多减少 30%。敌对电脑的最低难度每高于最强电脑盟友一档，补回 5 个百分点，最高为原奖励的 100%。

- 以开局参战表计算，途中被淘汰的电脑仍计入。旧存档缺少逐席难度时沿用该局统一难度。

- 大厅显示预计收益比例。结算页显示折扣、补正及实际到账金额。例如一个普通盟友对抗困难敌人，获得原奖励的 95%。
