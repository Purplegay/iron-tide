# v0.27.6.2 · 遭遇战 AI 建造与补建防空建筑

多家遭遇战原先只有普通建筑规划，没有防空采购。单挑原有防空采购也要等矿场和车厂同时建成才会评估。现在两种 AI 都在矿场、车厂就绪后主动补第一座本国防空，遇可见敌机时仅需满足原有建筑前置即可提前下单。普通及以上难度遇空袭可补至两座，简单一座。己方、盟友和未侦察到的飞机不计入威胁。建筑损失后按当前需求重新评估。

多人 AI 的防空施工可与普通建筑同时进行，各电脑按自己的资金、订单余款和在建工程计费，防空仍需实际施工、展开、运行才能开火。兵营和车厂的扩建上限沿用 v0.27.6。

槽位 2 副本为电路板四家遭遇战。读档时，美国凶残3 的资金约 10 万，三家电脑均为零防空。独立推进 AI、施工和生产 60 个模拟秒后，敌方美国有两座可运行的爱国者，两家苏联电脑各有两座可运行的防空炮。

886 项无窗口检查通过。专项验证盟苏主动设防、提前识别空袭、忽略隐藏和友方飞机、向基洛夫开火并造成实际伤害、被拆后重建，以及科技与生产继续推进。
