# v0.25.28 · 新增凶残1难度

2026-11-05。按用户确认：继承凶残，增加所有战斗相关后勤 5 级，而非仅生命、伤害。作为新增需求递增第三段版本号。

## 规则

大厅难度新增「凶残1」（ID 4），原有简单／普通／困难／凶残 ID 0～3 保留。RA2 与扩展模式均可选择，已接入大厅选择记忆、任务标题、AI 决策和存读档。

额外加成直接从 data/meta.json 的后勤 upgrades 读取 5 级：

| 后勤 | 凶残1额外效果 |
| --- | --- |
| 火力校准 | 伤害 ×1.15 |
| 复合装甲 | 防御系数 ×1.15，现有公式实际承伤约 ×0.8696 |
| 强化结构 | 生命 ×1.20 |
| 引擎调校 | 移速 ×1.10 |
| 模块化预制 | 生产速度额外 ×1.15 |
| 快速部署 | 开局资金额外 ×1.10 |

- 原凶残开局资金为玩家本局实际初始资金的 6 倍；凶残1最终为 6.6 倍，保留既有玩家开局资金基数规则。
- 原生产倍率 1.5，最终为 1.725；单位与建筑建造队列共用同一个倍率入口，建筑 build_speed 不重复乘后勤。
- 交矿实际 4 倍、其它正常收入 2 倍、每 10 秒补助 1000，矿车数量与开矿、T1/T2/T3 选兵、RA3 黑名单均继承凶残。
- AI 单位通用初始化读取生命／伤害／装甲／移速；AI 建筑初始化读取生命／伤害／装甲。强化归入现有属性与战斗公式，不修改原始单位数据。不额外给予技能强化、单位天赋、局外档位基础加成、挂机收益和离线仓储。
- 对局开局冻结 enemy_logistics 到既有 combat_context 字典，由现有快照一起保存。没有新增存档格式或版本迁移；旧快照缺此字段时按无额外后勤处理，读取快照保留已存实体属性，不再次叠加倍率。新造实体使用本局冻结值。没有读取或消费玩家的后勤购买等级及钱包。
- 和既有局外属性一样，实体生成时赋值；本次没有增加占领或心灵控制后重新结算属性的规则。
