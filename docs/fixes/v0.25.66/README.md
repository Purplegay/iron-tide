# v0.25.66 · 叠层天赋脚底标记与分层配色

## 内容

- 停火蓄电、辐射扩散、收割者协同瞄准增加脚底分段光环与“名称 当前层／上限”；同时覆盖装配被动「相位稳流」。第 1～4 层分别青、绿、金、紫，未获得的段显示暗灰，数字按当前层颜色显示。
- 磁爆步兵实际开火消耗后显示 0；辐射工兵起身清空后隐藏；收割者主、副目标分别显示「主热」「副热」，按每个目标自身层数衰减，不合并、不把旧目标层数套到新目标；相位稳流读取真实 focus 时间，切换目标显示 0。
- 收割者部署炮台由 ReaperMount 复用同一显示；Heat 与 Flux 命中标记也使用同一层数配色。
- 天赋演示和相位稳流卡牌演示复用绘制函数。停火蓄电演示在满层后保留 0.6 秒再示意开火，以便看清满层；此停留只影响演示，不修改战斗间隔。
- 不增加战斗层数、改变伤害、计时、上限或存档。显示只读运行态，死亡／乘员／英雄残骸不绘制；不扫描全场，无单独粒子节点或显示计时器，只有层数变动时请求重绘，图形段数有上限。单位展示模型屏蔽实战脚底层数，避免与演示覆盖重复。
