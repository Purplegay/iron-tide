# v0.25.29 · 凶残1兵种改造三级

2026-11-05。用户追加凶残1的各兵种单位改造均为 3 级。

## 效果

在原凶残规则与 5 级战斗后勤上，全部 AI 兵种通用初始化额外应用单位改造三项的 3 级配置：

- 定制火力：伤害 ×1.09，与后勤 ×1.15 叠加，合计 ×1.2535。
- 定制装甲：防御系数 ×1.075，与后勤 ×1.15 叠加，合计 ×1.23625；按现有伤害除法，实际承伤约减少 19.11%。
- 技能强化：skill_power ×1.18，已接入该值的技能效果增强、冷却除以 1.18。原生开关、未接入的专属机制仍不受影响；空技能槽不自动获得技能，不复制玩家卡牌或天赋。

生命仍为后勤 ×1.20；移速、经济、生产和初始资金继续沿用 v0.25.28。单位改造作用于兵种，不额外叠到建筑。盟苏及其它 AI 阵营共用此入口。RA2 模式也应用新难度的兵种属性强化，但不会解锁扩展技能。

数值从 meta.json 的 unit_upgrades.tracks 读取三阶，不读取、购买或修改玩家的改造等级。新对局将 enemy_unit_upgrades 冻结在既有 combat_context 并随快照保存；读档后的现存兵种不重复加成，新生产兵种使用同一冻结值。旧对局快照缺该字段时保持原强度；要体验新增三级改造需重启游戏并新开凶残1。无存档结构版本迁移，无新增外部持久化。
