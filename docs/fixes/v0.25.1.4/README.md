# v0.25.1.4 · 交火时完整显示迷雾边缘的大型建筑

位于侦察边缘的船厂中心已经可见、武器也能开火时，高出的屋顶和远侧船坞仍会落在黑雾里。原先只有受击方获得开火点附近的临时视野。

- 向已经发现的敌方建筑开火时，按地基、等距投影中的主体、动画层和已绘出的炮塔覆盖附近的迷雾格。建筑自己开火时，受击方也能看清它的轮廓。只在建筑附近留出迷雾纹理过滤所需的边缘。
- 开火或命中已发现的敌方建筑后保留 3 秒，连续交火会刷新。停战后按普通侦察视野恢复，读档保留剩余时间；盲射或溅射打中尚未发现的建筑，不会凭空揭开目标。
- 专项以真实坦克武器攻击盟军和苏联船厂，覆盖玩家与敌方、纯 RA2 与扩展模式。修复前四种船厂／模式组合中，开火即时和持续交火的完整轮廓检查全部失败。修复后检查建筑不透明像素所覆盖的视野格、玩家迷雾纹理、续时、读档、停战和盲射，共 88 项通过。
- 无窗口回归中，自动防卫、支援建筑、特殊机制与战略落点均通过。综合迷雾套件仍有 4 条平局局外进度断言在变更前后同样失败。实际屏幕上的迷雾过渡尚待体验。
