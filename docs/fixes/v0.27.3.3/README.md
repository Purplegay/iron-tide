# v0.27.3.3 · 英雄基地侦察提示与战斗鼠标卡顿

第三槽为尤复「电路板」四方对局。隔离副本读入 111 个单位、63 座建筑，玩家的犀牛英雄已出场。两座敌对盟军建造厂在玩家的已探索区域。仅凭已探索状态无法还原当时揭雾的具体来源。原存档 SHA-256 为 `4E4AEBE0E93B893A43A11054C889CA1FB39870646515CB6D770AAA0F1492A30B`。

- 灰熊、犀牛英雄首次出场的 5 秒、复活的 10 秒，在小地图以金色脉冲标出实际侦察到的位置。结盟关系决定共享对象。标记固定在侦察当时的位置，暂停时停止计时，读档续计剩余时间，结束后按正常视野回雾。旧档已经过去的侦察不会重播。
- Windows 窗口使用原有鼠标图集、动画帧和热点，通过系统光标显示。空地悬停与指令光标共用一次像素命中检查，点击下令时仍按当下位置判定。战争迷雾分块比较发生变化的遮罩。矿车近处绕行沿用原来的多源最短路，算到需要的格子就停，下次沿同一搜索继续。矿点受阻重选时也会重新检查目标。
- 同一存档同一批 320 个空地位置，悬停和光标判断合计中位数从 0.838 降至 0.366 毫秒，P95 从 1.006 降至 0.469 毫秒。用本局实际寻路目标对照，创建流场并查询近点从 97.2 降至 0.215 毫秒；对整张图 49,284 个格子逐一比较，方向全部一致。
- 无窗口续玩 3,600 个物理帧（60 秒），场上增至 146 个单位，最后 300 帧的墙钟间隔中位数为 29.6 毫秒、P95 为 41.0 毫秒。这是 CPU 侧续局采样，不是 Windows 实机渲染帧率。实机鼠标跟手感与小地图闪烁外观待确认。

无窗口专项通过：四方对局与英雄侦察 124 项、光标 64 项、搭乘光标 194 项、小地图 132 项、坦克英雄 79 项、建筑受击视野 88 项、建筑寻路 36 项、海军寻路 124 项、矿场交通 72 项、采矿 102 项。采矿回归的固定陆地夹具与真实海岸地图分开运行。迷雾综合回归另有 4 项平局结算后局外数据相等的断言，在使用修改前的迷雾代码时同样失败。

Windows 光标图像和热点接口可查阅 [Godot Input.set_custom_mouse_cursor](https://docs.godotengine.org/en/stable/classes/class_input.html#class-input-method-set-custom-mouse-cursor)。
