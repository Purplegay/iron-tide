# v0.27.6 · AI 扩建兵营与战车工厂

盟苏电脑完成作战实验室后，会根据本方资金、供电和现有订单扩建兵营与战车厂，并用多座工厂同时出兵。 单挑和多家遭遇战适用，盟友电脑按自己的经济扩产。已保存的对局在下一次 AI 建造决策时采用新规则。

- 简单、普通、困难各类最多建 2 座；凶残及以上各类最多建 3 座。优先补数量较少的产线；同数量且两者都满足条件时优先补车厂。
- 本方需有矿场、存活矿车和已建成的科技链。预算扣除已下单项目的余款，并为矿车和扩产后的首批部队留钱。现有产线饱和就考虑扩建，未饱和时要求更多余款。预期缺电时先补电。选址检查原有出口和同类型新厂的出兵空间。
- 扩展模式中多座工厂各自下单，同时生产；RA2 模式沿用项目现有同类工厂的生产速度系数。

无窗口回归 870 项全部通过。单挑验证盟苏扩建、各厂接单、资金不足暂缓和全部车厂损失后的重建。多家对局验证了扩展凶残与经典凶残3：双方盟苏电脑在资金充足时各有 3 座兵营和 3 座车厂同时生产，并逐座确认实际交付单位。专项为多家对局 158 项、单挑作战 466 项、生产流程 48 项、经济与战力 142 项、战术 56 项。
