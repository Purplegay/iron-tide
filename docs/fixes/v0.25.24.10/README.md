# v0.25.24.10 · RA3 天启贴身研磨

官方 SDK 的 `Sov_Apoc_TB_Grind.xml` 定义 30 个发射帧，每帧 15 条火花，每条存活 5 帧。旧路径每次命中一次性创建 450 个精灵和 450 条拖尾。新路径按特效年龄批量绘制同一脉冲中仍存活的最多 75 条拖尾，沿用原贴图、火花颜色和寿命。改动限于火花渲染。鱼叉、伤害与碾碎使用原有战斗代码。

隔离桌面，Godot 4.7.2，GL Compatibility，RTX 5060 Ti，固定模拟步长。运行 `res://tests/apocalypse_grind_performance.tscn`，在实战场景中冻结无关单位，直接推进同一辆天启的武器，记录相邻渲染帧间的墙钟时间。

| 单辆天启 | 优化前中位数 / P95 | 优化后中位数 / P95 |
| --- | --- | --- |
| 持续研磨建筑，150 帧 | 14.4 / 36.1 ms | 6.4 / 10.6 ms |
| 拖近并碾碎载具，200 帧 | 6.9 / 17.2 ms | 5.6 / 10.8 ms |

建筑研磨时新增场景节点峰值从 3106 降为 448。测试另断言持续扣血、载具被碾碎、火花实际渲染以及生命周期结束。首次使用新着色器的一轮曾出现 97 ms 单帧，后一次建筑阶段最高 17.3 ms。这组数据覆盖单车鱼叉场景，不能代表整局帧率。
