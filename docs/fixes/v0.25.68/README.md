# v0.25.68 · 单兵种专属卡演示模型

- 当抽取技能卡的 allowed_units 只有一个兵种时，演示区域内实际触发技能的施放者使用该兵种模型，不再用三角标记。规则复用 SkillScope.exclusive，不靠卡名或手工列表判断。
- 当前覆盖海豹部队／疯狂伊文的超时空许可、收割者分区射击、磁爆步兵连锁放电、战斗要塞乘员协同、幻影假象转移、天启炮座齐校、驱逐舰搜索浮标、犀牛斜甲迎击。
- 模型复用 RA2／RA3 展示管线，独立世界禁用战斗逻辑。模型朝向示意目标，沿既有轨迹移动，幻影残影保留透明度。切卡释放旧模型，同卡切等级复用；暂停、拖动与慢放仍由演示时间轴控制。
- 敌方靶子、乘员事件符号与许可解锁结果仍为示意标记；多兵种／通用卡保持原表示。本次没有把示意弹道升级为完整实战特效。
- 幻影冻结展示时停用需要实时生命周期的原生幻影场合成节点，避免未初始化的加法贴图画出黑色矩形；不影响战场幻影场。
