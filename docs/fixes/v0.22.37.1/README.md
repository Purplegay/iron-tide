# v0.22.37.1 · 待命单位遭到射程外攻击时可有限追击

- 可机动、可反击的待命单位受到敌方命中时，在可见、武器能攻击的条件下向攻击者接近，进入自身射程后再开火。武器射程、最短射程和伤害计算沿用战斗规则。目标逃出追击边界或被摧毁时，会停止此次追击。
- 本项目把初次受击位置作为六秒反击窗口的锚点。追击半径取当前武器射程加两格与原规则 GuardRange 的较大值。窗口内再次受击刷新时间，锚点固定。该两格余量属于 Iron Tide 的手感设定。尤复 rulesmd.ini 将 GuardRange 定义为警戒搜索半径，未填写时使用武器射程，CanRetaliate=no 的单位不会因受击锁定攻击者。
- 普通移动命令和玩家手动集火优先。按 G 固守、卧倒部署、停火、维修和采矿沿用各自行为。机场制战机不会因受击开启新一轮出击，V3、航母与超时空步兵未加入这种自动接近。开火姿态按钮的说明已更新。
- 无窗口复现对比：修复前两种模式下灰熊均无法获得射程外一格的攻击者，也不会靠近开火。修复后两种模式均通过，并覆盖连续受击不前移锚点、原地固守、普通移动、火箭飞行兵、开火建筑、攻击者被毁和中途读档。
- 十个相关专项共 959 项断言通过。另跑的 RA3 天启反击套件有四条涉及部署直升机起降、鼠标和寄生时机的断言失败，在变更前快照同样复现；该套件未计入通过数。
