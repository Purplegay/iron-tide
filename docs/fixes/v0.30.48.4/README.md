## 实际改动

- 二期扩展及天赋查询先使用现有玩家阵营限制排除不可能成立的分支。持有被动卡、存量二期状态、控制权变化以及失效对象仍即时处理；不跨步缓存战斗结果。
- 拥堵检查先排除远处或身后的候选，再查阵营与通行规则；无状态查询共用只读空字典。约2秒临时穿过友军、脱困后的恢复时机保持。
- 分帧扣款的资金事件只同步资金文字，不重复重建电力、击杀与倍速状态；电力事件和原有定时刷新保持。资金实际扣除和显示仍同步。
- `launch_game.ps1` 使用编辑器导入资源，再优先选择与project.godot同目录的本机 `IronTideRuntime.exe`，不传入Release禁用的路径覆盖参数。校验两者版本一致，保留 `IRON_TIDE_GODOT` 显式覆盖；`IRON_TIDE_RUNTIME` 可选择同目录的其他匹配运行时。本机已安装匹配运行时，二进制被Git忽略；其他机器没有本地Release时保留原编辑器启动方式，不能据此声称其他机器自动获得运行时收益。
