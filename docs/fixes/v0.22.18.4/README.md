# v0.22.18.4 · 降低大编队选中时的头像与射程圈开销

## 游戏内变化

- 选中超过 12 个单位时，每人仍有独立头像，可滚动、单击定位、双击选择同类。停止头像装饰动画，约每 0.1 秒更新血量、军衔和总血量。相同顺序的名单再收到刷新时复用控件并保留滚动位置。直接选择命令即时更新。
- 12 个以内保留每个单位的实际射程圈。超过 12 个时，同兵种、相同射程和最小射程、相同激活状态的单位只从其中一名成员的位置画圈。各单位的武器判定和下令逻辑沿用原行为。

## 性能与回归

使用隔离的 Godot 4.7.2 无窗口战斗场景，生成 60 名动员兵并建立与框选相同的选择列表，走实际选择通知、头像和射程预览入口。重复调用头像栏刷新 8 次，单次平均从 2.184 毫秒降至 0.043 毫秒。60 个持续动画的头像降至 0 个，60 个射程圈降至 1 个。首次选中整条通知链此次分别采到 39.5 和 35.8 毫秒，仅供定位，未测实际显卡帧率。

[大编队专项](../../../iron_tide/tests/large_roster_regression.gd) 10 项通过，覆盖末位头像血量和单击、双击、混编射程。选择、攻击范围、军衔和晋升四套专项另通过 386 项。综合 HUD 的 4 条失败和头像综合套件的 26 条失败均与修改前逐项一致，涉及生产队列右键、详情头像及生产资格。滚动和部队移动时的实机流畅度待玩家体验。
