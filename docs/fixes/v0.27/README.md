# v0.27 · 遭遇战参战席位与结盟组

遭遇战大厅直接展开参战表，可按地图席位添加电脑、选择国家和结盟组，进行混战或与 AI 结盟。

- 每张地图记住自己的参战名单。Circuit Board 可容纳四家；Ice Age 和 Islands on the Land 可容纳六家。采用地图原有出生点，双人地图保留两个席位。
- 同组共享侦察视野，按组判断短局和歼灭胜负。房主只操控自己的部队。多家 AI 跟踪各自的资金、电力、生产队列、基地和攻击目标。难度使用大厅的统一设置。
- 多家 AI 的首版经营策略覆盖基地车展开、基础设施建设、采矿、步兵和坦克生产、进攻。既有双人遭遇战继续使用原双人 AI。多家 AI 的后期海空军与超级武器策略尚待扩展。
- 通过多人参战回归 56 项（包含实际开火、生产扣款、四人存档恢复和团队胜负），大厅设置回归 92 项，基地与胜负回归 135 项。另在隔离桌面检查了实际大厅布局。
