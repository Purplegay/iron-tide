# v0.27.3.6 · 多家遭遇战电脑升科技

三家及以上的遭遇战原先使用独立 AI，其建造顺序止于战车厂，生产分支只会选择基础兵、矿车和基础坦克。每家盟苏电脑现在按自己的建筑、供电、国别和资金推进科技，重建被毁前置。生产时预留科技资金、扣除已承诺的订单余款，并按可见敌情和现有数量补兵。战车厂解锁后优先补上第一辆光棱或天启；RA3 单位继续执行 AI 生产黑名单。旧对局恢复后从现有资产继续决策。

槽位 1 隔离副本（电路板，四家，敌方美国凶残3）加载时，敌方有 113,510 资金，有兵营和战车厂，未建空指部和实验室。单独推进实际 AI、施工和生产计时器，敌方在 24 个模拟秒内完成实验室，两家苏联电脑在 34 秒内完成。此为经济与生产专项，实战时长受交火和收入影响。

无窗口回归通过 816 项。多家对局 136 项含扩展凶残与经典凶残3，验证两阵营实际交付 T3 坦克、摧毁雷达或空指部及实验室后能重新建成。另通过生产流程 48 项、单挑作战 434 项、战术 56 项、经济与战力 142 项。
