# v0.27.17.7 · 空军受击求援

此前普通 AI 主要响应基地 450 范围内威胁，凶残 3 才有额外的受击警报；飞出基地的空军缺少统一求援。地面单位的 `ai_counterfire.gd` 又明确排除飞行器，该机制是自身就地反击，不能代替友军增援。

现在真实受击在 `unit.gd` 中发起请求，单家 `skirmish_ai.gd` 和多家 `house_ai.gd` 都处理 `air_relief.gd`。按攻击者武器域召集附近可用友军，不强迫只能对地的基洛夫反击敌机。范围 800 世界单位、每家最多 8 个请求／4 个援军、0.75 秒复查；支援保留 6 秒，命中刷新请求但不会每发重新寻路。以上是本项目策略参数，不是原版配置声明。

跳过玩家、经济支援、部署、维修、运输、已有其他交战目标、载机子单位、连发中及返航补弹部队。地面跨不可通行区域不派遣；攻击目标进入现有射程则无需路径探测。命令继续通过已有 AI 限流队列，集结和普通出征暂不覆盖支援目标，已过期的排队请求不再派出援军。敌人不可见时不追踪隐藏坐标。旧存档无需迁移，首次受击即可求援；新请求与支援状态随正常存档保存。
