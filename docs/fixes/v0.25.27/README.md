# v0.25.27 · 时间书签攻击间隔

2026-11-05。按新增天赋效果递增第三段版本号。

## 修改内容

超时空步兵时间书签增加攻击间隔缩减；书签时限仍表示中断后保留半份进度的有效期，不是等待继承的时间。

| 天赋等级 | 书签有效期 | 攻击间隔缩减 | 新兵基础间隔（1 倍速、无其他加成） |
| --- | --- | --- | --- |
| 0 | 2 秒 | 20% | 6.4 秒 |
| 1 | 3 秒 | 30% | 5.6 秒 |
| 2 | 4 秒 | 40% | 4.8 秒 |
| 3 | 5 秒 | 50% | 4.0 秒 |

- 修正 CLEG 在地面持续擦除时提前返回、导致冷却停止计时的问题。双模式均正常计算原有冷却；纯 RA2 不获得天赋缩减。战斗要塞乘员原本已有计时，保持只扣一次。
- 缩减只对扩展模式己方已启用此天赋的超时空步兵生效，与老兵及冷却 buff 乘算。读取本局冻结的天赋等级，不在战斗中读取局外新升级的等级。
- 冷却圈使用同一缩减倍率；单位改造逐级说明和天赋演示补充攻击间隔说明。
- 原始 NeutronRifle / NeutronRifleE 的 ROF=120（本工程 15 规则帧/秒，即 8 秒）保留。持续擦除速率、目标生命计算和中断后立即解冻不变。书签继承已完成进度的 50%，改目标、到期仍会清除。
- 这项加成是 Iron Tide 局外天赋，不宣称是尤复原版规则。短暂攻击后立刻中断，在低等级时仍可能因剩余冷却超过保留期限而失效；没有绕过冷却或保证任意中断均可重连。
