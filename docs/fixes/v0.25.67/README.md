# v0.25.67 · 掩护倒车任意方向自动转向

## 行为

- 灰熊坦克解锁「掩护倒车」后，按 E 可以点选任意方向的畅通地面。车体按原生 ROT 转速先转向，让车尾朝向目的地，再沿点击路线直线倒车。
- 最多倒车 3 格，超过距离沿点击方向截断；保留地形与建筑阻挡判定，不自动绕开障碍。目标预览显示实际路线及最终车头方向。
- 炮塔独立瞄准，倒车期间照常攻击。只有实际倒车移动后才启动每秒 1% 最大生命回血；原来的 3／4／5／6 秒时长、停车后继续回复、重复倒车不叠加不续时保持不变。仅原地转向不会启动回血。
- 途中可停止或重新指定方向；转向中保存再读取仍会继续完成倒车，无新增存档字段。
- 天赋说明和演示同步显示自动转向、沿路线倒车、停车回血三个阶段；演示时长读取实际转向参数和所选等级的回血时间。
