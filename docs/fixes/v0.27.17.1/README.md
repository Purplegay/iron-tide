# v0.27.17.1 · AI 出厂通道与堵门疏通

## 原因与修改

此前 `expansion_site_ok` 对非兵营／工厂直接返回，电厂等建筑可以贴住已有出口；出口检查又只覆盖门口一点。现在所有 AI 普通选址、矿场／电厂经济扩建及凶残围墙都检查生产离场通道。工厂、兵营、矿场前方预留约 200 世界单位，宽度包括车辆半径和寻路格余量。只约束 AI 新建筑选址，不改变玩家建造规则或单位碰撞体。

通道缓存随寻路服务和地形版本失效，不进入存档。每家每 3 游戏秒轮询一个出口，每次最多疏散两个己方堵门单位；闲置者寻找分散停车位，至少 6 秒未进展的移动者走侧向中继点并保留原终点。沿用命令预算，不在每帧给整军重新算路；正在交战、维修、采矿、装载、执行技能或冻结的单位不强行挪走。

## 自动出售条件

固定出口首次发现静态堵塞至少 12 秒后才允许尝试（多工厂轮询会延长实际等待）。存在部队或生产出口堵塞标记才触发；纯单位拥堵不出售建筑。有限寻路若找到绕行，则不拆。必须验证移除单座后整段通道几何和地形均可通行，才出售自己的围墙或重复建筑，按正常出售退款、动画和寻路／供电刷新处理。

每家两次出售至少相隔 30 游戏秒；不出售基地、矿场、发电设施、民用建筑、禁止出售的建筑、在建建筑、最后一座生产／科技建筑，或玩家／盟友财产。新建检查防止反复重建到同一出厂通道。

旧式环绕寻出口的建筑目前仅预留通道、疏散单位，不自动拆除：一个方向受阻不足以证明所有门都堵死。多个障碍必须同时拆除才能通行时，也不会连拆。该策略不是任意基地死角的全局拆迁规划。

## 验证

Godot 无头、隔离存档目录，1058 项通过：出口疏通 46、原出厂 70、单机战术 58、多家经营 248、海空／生产 466、经济 50、凶残三 104、决策预算 16。新增用真实 Building／Unit 和 PathService 测试所有建筑类型让出口、延迟出售、普通退款、出售冷却、关键建筑和所有权保护、多重障碍／地形拒绝、单位堵塞不拆以及计时存档校验。

结果及源文件指纹见 [regressions.json](regressions.json)。没有在用户当前运行窗口中修改状态，也没有用截图所在现场存档复现；当前运行中的旧进程需重新启动更新代码。本轮未导出试玩包、未测大型存档 P95，不宣称性能目标已达成。
