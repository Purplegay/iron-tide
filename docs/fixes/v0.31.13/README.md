# v0.31.13 · 指挥官任务通信

营地「藏品与记录」和「支线百科 → 指挥官档案」均可查阅八位联络人的任务通信和四十章故事。卡片上的章节数显示个人解锁进度，零章也可以打开。救援前的人物情报和带关卡的约定保留任务面板原文，获救后的答话、无新章节时的支援短讯、已获新章节的所有段落均可重读。

新收到的通信按人物、环节和实际文字去重保存。旧远征从已有的获救名单和战报恢复获救状态及原有情报、约定。缺少历史文字凭据的条目提供当前原文。章节仍按独立的赴约记录统计。

Godot 无窗口回归覆盖主菜单百科、营地、战场求援和赴约、实际台词与重载后的局外存档。三个场景共 550 项断言通过。另用玩家远征档副本验证回填，再次加载没有增加重复项。
