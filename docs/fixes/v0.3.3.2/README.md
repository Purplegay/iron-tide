# Iron Tide v0.3.3.2 修复说明

2026-10-27

- RA3 幻影坦克 SDK 收尾：增加可复跑的 XML/素材审计工具，区分声音事件、实际音频、动画定义、模型文件和运行接入，不再把引用名当成可用素材。
- 重新生成并核对 SDK 视觉参数，检查现有图标/特效资源哈希和本地引用依赖；记录原版动画状态、语音覆盖、武器音效和残骸各模块时序。
- 修正交接开头的旧版本、独立炮塔和早期特效描述。本轮无新试玩版提取，不改移动、伤害、冷却、生产或存档规则；原生语音、骨骼动画和碎块残骸仍因 SDK 缺素材而未接入。
- 本轮是审计工具与交接纠错，RA3 幻影内容沿用 v0.3.3.1；具体当前检查及缺口见 [SDK 收尾](../../RA3_MIRAGE_MODEL.md)。视觉状态仍待玩家确认。
