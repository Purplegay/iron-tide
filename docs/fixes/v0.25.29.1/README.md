## 原因与修正

原凶残生产倍率仍为 1.5，没有被新难度调低。定位到已有采购策略每约 1.5～2.5 秒只给每条线补一单：动员兵等低价单位早于下一次决策出厂，会出现有钱、出口通畅但兵营空转。

- 凶残与凶残1按现有上限补足两单缓冲。两轮补单逐条轮转，所有生产线先获得首轮机会，再考虑第二轮；每单重新计算已承诺花费、矿车预留与生产资格。
- 增加 0.25 秒空线检查；只有发现己方 AI 的可用非矿场生产线空闲且出口未堵时才运行采购。队列有货时不因此重跑选兵。
- 原有开局 5 秒准备、建设／科技／微操／进攻决策节奏保持；新增快检查不重跑这些战略流程。低难度与虫群保留原有补单节奏。
- 未提高资金、采矿、生产倍率或队列容量。凶残仍为 1.5，凶残1为 1.725。缺钱、低电、缺前置、暂停或出厂受阻仍按正常规则等待。
- 新增计时器是临时采购轮询状态，不改变存档结构或补助时钟；读档重建 AI 时重新开始短暂轮询准备，不重复发钱。
