# v0.27.16.3 · 窗口边缘滚屏与大型战局

从战场划出普通窗口后，鼠标可继续推镜头。回到战场中央、切走窗口或打开菜单时停止。从界面控件直接划出去不会误推镜头。边缘带对称扩大，滚动在当前绘制帧更新；长帧只限制镜头单步位移，不改部队速度、武器计时或模拟频率。无窗口测试覆盖方向与状态转换，未在玩家桌面验证视觉拖影或真实鼠标跨屏。

## 同档性能

Islands on the Land，凶残 3，327 单位、155 栋建筑。无窗口、1 倍速；预热 4 秒，然后交战、选择、移动各观察约 15 秒游戏时间。此档可用于下达地面移动命令的玩家测试队伍只有一人，其他各家仍在实时交战。数值为毫秒，越低越好。

| 阶段 | 改前中位 → 本版中位 | 改前 P95 → 本版 P95 |
|---|---:|---:|
| 自主交战 | 58.9 → 90.8 | 102.5 → 183.1 |
| 选兵 | 68.6 → 65.0 | 162.7 → 124.9 |
| 移动 | 89.3 → 65.4 | 166.7 → 122.4 |

实时回放中 AI 的路线、开火次数和主机负载并不固定；开发中两次移动阶段的 P95 分别为 148.5、161.0 毫秒。本版移动阶段的 15.04 秒游戏时间对应 15.07 秒现实时间。尚不能据此认定整体帧率已稳定提高，也不能外推到 3700X 或玩家画面的表现。

同一存档锁定状态、交替执行六轮：所有建筑动画图层读取每轮中位 0.495 → 0.194 毫秒；建筑视野合并 0.952 → 0.608 毫秒。建筑动画仍随损坏状态切换；建筑被占领、移除或视野半径变化时重建缓存。矿点索引试验在此图从 1.271 增到 1.858 毫秒，已撤回。短程通行净空和桥面上下层碰撞先筛附近候选，保留原几何判断；滚屏时跳过普通悬停的逐像素拾取，点击仍按当前位置判断。

经典与扩展模式下，边缘输入／视野、桥面交通、坦克通行回归分别通过 26、30、40 项。[原始测量（含中间结果）](measurements.json)
