# v0.27.12.2 · 原图低木桥挡船

原先导入低桥覆盖物时，河水上的桥格同时开放了水路和陆路，导致无畏战舰可以驶进桥面。现在依据地图中的 `LOBRDG` 标记关闭低桥格的水路，舰船寻路和实际移动共用这一判定。步兵、坦克仍可走桥面，高桥的桥下航道继续开放。

读旧档时，若纯水面单位或潜艇已经占在低桥上，会在桥旁八格内查找空闲水格，避开船厂和其他单位；找不到合适位置时保留原位置。下次行动沿当前地形规划路线。

无窗口回归共 432 项通过。重点检查 Circuit Board 的无畏战舰移动命令、步兵与坦克双向跨桥、两艘旧档舰船同时占桥时的恢复，核对六张导入图及自制地图的高桥下水道。两张有低桥的导入图共 656 个低桥格。
