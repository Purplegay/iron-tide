# v0.25.50.1 · 脉冲投影与碉堡四档天赋

## 震荡脉冲

技能预览与通用施放圈在原始世界坐标绘制，却调用已执行旋转／压缩的 `Iso.ell`，再经过相机投影，导致斜椭圆。新增 `Iso.ground_circle`，这两处统一只由相机投影一次；其他经过 `Iso.begin` 的实体绘制保持原状。

震荡脉冲原先使用 0.22 秒通用命中特效，另叠加 0.6 秒通用施法圈。现在使用独立 `core/shock_pulse.gd`：1.8 秒寿命、0.95 秒主波扩散，三层错峰电磁波、蓝白软边、六束短暂放电、外沿游走电弧和火花，最后缓慢淡出。移除该技能通用闪圈，命中电弧从 0.18 秒改为 0.38 秒；连锁电弧默认仍为 0.18 秒。

伤害仍在施放时立即结算一次；伤害倍率、减速、目标筛选、半径 275 与 26／25／24／23 秒冷却均未修改。视觉半径不越过实际范围。每次仅一个节点，最多 8 个同时播放详细火花，额外施放保留基础波纹；不使用逐粒子节点、屏幕读取、全局灯光或战斗随机数。

## 碉堡射程

用户确认四档，替代上一版本的临时三档：0／1／2／3 级为约 6.625／7.25／7.875／8.5 格。保持原基础射程与重装大兵部署射程上限计算，实际驻军武器、视野和演示一致。升级费用沿用统一 40／120／240 核心。改造页逐级说明、升级上限与范围演示下拉同步四级。

旧科技 I／II／III 与旧三档天赋 0／1／2 免费转为新 1／2／3 级，已购射程不会降低；不重复扣费、不损失未分配点，开关继承。`academy.bunker_optics_four_ranks` 只迁一次，新档／重置档已带标记。没有购买的玩家不会凭空获得天赋。

新战斗冻结 `bunker_talent_version=2`；版本 1 的旧战斗继续按原三档天赋计算，没有标记的旧战斗继续按原科技计算。沿用现有 JSON 局外档与战斗上下文字典，无新增持久化文件类型。
