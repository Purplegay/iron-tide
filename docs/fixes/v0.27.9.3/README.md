# v0.27.9.3 · 矿车卸货后驶离地图边缘的矿场

修复矿场靠近地图边缘时，卸空的矿车卡在出口、后车满载却无法进站的问题。离场时检查整条路线能否抵达目标，正前方不通则尝试侧向出口。路口完全被挡时等待并重试。读入旧存档后会重新核对残留路径。

电路板槽位 3 副本中，紫色 AI 前车的路线终点距离场目标约 50 像素；后车装满 40 单位矿石并等待。修改前连续 600 个物理帧两车仍停在原处。修改后回放至第 240 帧后车已进站卸货，第 1440 帧两辆原车均在矿区采矿。槽位 2 的两辆车也在 480 帧内离场驶向矿区。

无窗口运行精炼厂交通专项，76 项检查通过，覆盖盟敌双方、两种规则、四车排队、整车结算和旧路径恢复。验证期间也补齐了编队标记绘制处的 Vector2 类型声明，使当前工作区可正常启动。
