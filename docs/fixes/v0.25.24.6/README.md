# v0.25.24.6 · 重装大兵部署齐射

已部署的重装大兵和美国大兵只在瞄准方向发生变化时重新校验转向，装填结束后仍按实际目标、射程、盲区和朝向判定能否开火。线形导弹尾迹把可见的连续路径合并绘制，每段保留亮芯、光晕和渐隐，遇到迷雾断开。
