# v0.27.16 · 英雄契约兑换与技能卡演示

技能卡池的「英雄」分类与英雄养成共用契约面板。可查看任务进度、技能获得状态和等级，持有 500 兑换碎片可开启契约。原有每抽 0.35% 的获取方式不变；完成任务才获得两张奖励卡。

技能卡演示列表新增炉火契约双技能联动、W 金鳞战垒、被动龙卫截空。未解锁也可播放；专场图标复用英雄面板的金色扫光。

回归：炉火契约 115 项、技能卡演示 1079 项通过，涵盖兑换、任务结算、预览与返回。测试进程退出时报告渲染资源未释放，未验证玩家屏幕上的实际观感。

本版 Windows 试玩包同时包含[遭遇战出生点刷新修复](../v0.27.15.3/README.md)。
