# v0.27.4 · 矿车自动寻找未探索区域的矿点

盟苏矿车自动采矿时可以驶向黑雾中的可达矿点。尤复地图优先采附近矿区，附近找不到矿时再搜索全图。 此规则适用于玩家和电脑、自制地图和尤复原图。仍按实际地形与通路选矿，并考虑其它矿车的矿点认领。尤复矿车带着部分货物采空附近矿区时，先回场交货，再寻找远矿。

资源情报仅供自动采矿使用；矿车行进时按正常视野揭雾，未探索矿点仍无法通过鼠标点选，敌军和小地图仍按战争迷雾显示。

无窗口回归：尤复矿产 48 项、自动采矿开关 68 项、采矿交货 102 项全部通过。「电路板」验证了玩家超时空矿车和电脑武装采矿车都能实际驶向 48 格以外的黑雾矿点。迷雾综合回归 568 项通过 564 项，剩余 4 项为此前已有的平局结算数据断言。
