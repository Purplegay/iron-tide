# v0.27.9 · 多家遭遇战 AI 决策

有三家或更多参战方时，每家电脑使用本方的国家、难度、资金、部队和可见敌情。阵营间继续共享同盟视野。单对手和多家控制器共用经济、战术、海军、运输与超武决策代码。多家控制器保留原有的现场施工、建造预算和逐帧出兵机制。

- 经济与生产：按已知矿区选择扩矿地点，补充矿车、照顾停采与断矿恢复；工程师和小队侦察、争夺油井。高难度优先补空线，现有基洛夫防空策略继续生效。虫巢按资金、部队构成和敌情付费孵化。
- 基地与防御：基地车寻找可展开地点，失去基地车时尝试由本方车厂重建；受伤单位尝试进维修厂，建筑主动维修。按科技补地面防御、碉堡驻兵和磁暴线圈充电。
- 作战：步兵和武装直升机按交战情况部署或撤收，间谍渗透、夜鹰接送海豹，战机满弹后评估目标。海岸、科技和资金允许时建船厂，分配造舰预算并组织海战、登陆。超武按充能、威胁价值和己方视野择机使用，核弹和闪电风暴选点计入友军误伤。
- 调度与存档：集结部队留下守军后，按目标价值形成进攻波；凶残 3 使用分层进攻及防空回援。多家进攻每帧派一队中的一员；存档记录未下达命令的成员与队形位置。旧档的派兵记录和补贴计时继续读取。

在独立桌面、隔离存档目录运行多家遭遇、经济、战术、作战行动、基地重建、凶残 3、战略登陆回归。多家专项覆盖电脑盟友向敌方实验室派间谍、派己方伤车维修、实际释放闪电风暴、本方船厂采购和基地车补造、玩家订单与其他电脑钱包隔离、不同虫群兵种孵化，以及带队形的进攻波读档续派。自动化使用受控战况，不代表所有地图上每种策略都会触发。
