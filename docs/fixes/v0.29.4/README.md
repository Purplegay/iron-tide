# v0.29.4 — AI 接敌与受击追击

修复 AI 自动取得射程外目标后停滞、又因“已有目标”被战略派遣排除的问题。覆盖通用机动地面单位和无弹药返航需求的空军，不限于基洛夫。

- `ai_engagement.gd` 区分真正交战/接近目标与只有一个远处目标；集结招募与完整进攻候选使用同一判断。
- AI 受击后直接检查已记录的攻击者，符合条件时优先接敌。范围以首次受击位置为原点，使用原有防御范围与视野中的较大值；沿用 6 秒受击记忆，连续受击不移动范围原点。
- 地面单位临时追击前保存原移动目的地及攻击移动标记；目标失效或反击到期后恢复路线。新移动、停止、警戒命令清除旧恢复记录。该记录可通过正式存档序列化并恢复。
- 空军临时转向保留原目的地；自动接敌和武装炮艇环绕飞行接上移动逻辑。
- 玩家原有移动命令不被反击改写。警戒、禁火、部署、维修、运输/技能动作及队列任务仍有原有约束；有弹药返航流程、V3、航母、传送步兵等专用出击逻辑不改写。武器目标类型、敌我关系和可见性仍须满足。

性能约束：新增受击判断只处理一个已知攻击者；不新增全军搜索，不提高索敌频率。追击与恢复路线继续经过 `ai_path_allowed` 和既有寻路/调度预算，没有减少单位或降低 AI 更新频率。

## 性能核对

同一六阵营 `yr_isleland` 存档和局外数据，保留玩家席位及五家 AI，Release 模板、headless、固定 1800 帧 / 900 模拟步，模拟时间均为 60.042 秒。相同 CPU 放置策略、相同模拟/派遣预算。修复前副本包含工作区中同期的直升机动画改动，仅撤去本次行为差异。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 整帧平均 CPU 时间 | 42.496 ms | 40.916 ms |
| 整帧 P95 | 74.476 ms | 68.706 ms |
| 整帧 P99 | 95.359 ms | 89.541 ms |
| 模拟回调 P95 | 47.323 ms | 44.676 ms |
| 峰值单位数 | 363 | 365 |

本轮未观察到新增性能退化，且未通过减少单位/模拟步换取结果。两次主机其它任务平均 CPU 占用约 26.55% / 18.41%，因此不能将耗时差额归因于修复带来的优化收益。这是单轮后台 CPU 样本，不是屏幕 FPS、GPU 或 33 ms 目标验收。原始证据为 `perf-matched-before/`、`perf-fixed/` 和 `performance-comparison.json`；两边运行期间源码审计均无漂移。早期 `perf-before/` 缺同期动画改动，不纳入最终对照。

## 未通过的扩展检查与脚手边界

- 旧 `flight_speed_regression` 有 18 项失败，旧 `ra3_gunship_flight_regression` 有 2 项失败；修复前后失败项一致，涉及旧空军名单、导弹速度假设与炮艇环绕几何，不记为通过。
- `flight_motion_regression` 包含 `RenderingServer.frame_post_draw` 等渲染等待，不适合作为此次 headless 入口。运行出现黑鹰转向/降落断言失败后等待绘制信号，本轮停止自有测试进程，未将该视觉套件计入通过项。
- 初次全存档测试复用了已有测试用户目录，旧 slot3 备份干扰了损坏存档用例，结果作废。改用独立 APPDATA/LOCALAPPDATA 后，完整 124 项通过；玩家存档不受影响。

本次没有现场存档，因此修复的是已证实的行为链路，不承诺涵盖所有偶发 AI 停滞。当前交付为工程修改，未打包、提交或推送；实际对局表现待重开游戏体验。
