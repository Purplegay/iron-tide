# v0.27.17.2 · 参战方出局清场

此前 `_check_end` 只统计存活阵营并结算整场胜负，没有销毁已经输掉短局的一家残兵。在多家混战中，该家的单位和防御仍可能继续作战。

现在在胜负检查里，先按原有条件一次确定本轮出局的各家，再冻结所属单位／建筑名单，统一调用死亡清理。冻结在先，防止运输、舰载机或心控释放回调改变名单。单位显示炸毁效果，同时清理运输乘员、舰载机、英雄待复活残骸和残余防御；自动清场不会触发自爆车等武器连锁爆炸，也不计额外击杀、助攻或升级奖励。

短局仍保留“有常规建筑或可展开基地车就没有出局”的规则；歼灭战不能因基地丢失而提前清掉尚存部队。GM 测试场与非遭遇战不进入这套判定。玩家一家出局、AI 盟友仍存活时，对局继续；其他敌家也独立经营。

`allied_state.defeated_houses` 保存出局状态。旧存档无此字段时按当前实际战况首次计算；已出局一家的新增单位／建筑被拒绝，建筑施工停止扣费和推进，读档不复活。未改存档格式版本。
