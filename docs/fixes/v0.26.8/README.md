# v0.26.8 · 炉火契约

在技能卡池每抽有 0.35% 概率获得这份一次性契约，也可以用 500 兑换碎片直接开启。获得后从「英雄养成 → 炉火」的金色双龙边框面板查看任务和奖励。契约开启后新开的扩展遭遇战在结算时登记进度，三项可分局完成。

1. 炉火本人打出最后一击，击毁敌方建造厂或击杀敌方英雄级单位。助攻与其他英雄的击杀均不计。
2. 炉火对敌方造成的实际生命损失跨局累计达到 10000。护盾吸收和超出目标剩余生命的伤害不计入。
3. 困难或更高难度获胜，并且炉火全局未攻击。可以不建造炉火，其他部队可以攻击。

全部完成时获得两张 0 级卡，可分别装配到炉火 W 槽与被动槽，并在任务面板使用现有卡牌培养价格升到 3 级。普通动员兵无法装配。

| 0 / 1 / 2 / 3 级 | 四档效果 |
|---|---|
| 金鳞战垒 W | 手动卧倒获得大兵的部署攻击倍率，护盾为自身最大生命的 50% / 60% / 65% / 80%，冷却 120 / 80 / 70 / 50 秒 |
| 卧倒移动 | 以基础移动速度的 5% / 10% / 12% / 15% 爬行，速度增益与移速光环不能覆盖 |
| 破盾 | 受击破盾或带残盾再次按 W 起身，对 1.5 格内地面敌人造成攻击力 10% / 30% / 35% / 50% 溅射。已破盾起身不会重复引爆。护盾持续 10 秒，自然消失后保持卧倒 |
| 龙卫截空被动 | 发现防空武器射程内的可见空敌时，在可用空地召唤两辆防空履带车。生命为本方养成后同型车的 50% / 150% / 180% / 200%，攻速为原来的 100% / 120% / 125% / 130% |
| 分解与冷却 | 生命加速衰减，分别在 2 / 4 / 5 / 7 秒后分解。召唤起算 60 秒，冷却结束仍有空敌时可再次触发 |

卧倒鳞甲按动员兵原始 SHP 的八方向爬行与射击动作逐帧定位，共 96 帧。待机使用同朝向的爬行首帧。装备英雄皮肤时也使用卧倒鳞甲。

后台专项通过 78 项，覆盖抽取与兑换、击杀归属、跨局进度、装配资格、四档数值、受击破盾与起身去重、自然消盾、60 秒再次召唤和对局读档。英雄独立装配原回归 75 项行为断言通过，退出有引擎资源释放告警。综合养成套件有 13 项既有失败，集中在旧卡适用兵种和档位收益，隔离关闭新契约和卡牌后仍能复现。已检查卧倒图集，实机视觉待确认。
