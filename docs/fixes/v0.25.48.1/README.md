# v0.25.48.1 · 天赋直接解锁，移除单独买点

- 单位页不再提供“购买天赋点”或单独开格按钮，商店移除天赋点兑换区。
- 未解锁天赋显示“解锁”与合计费用；已有天赋继续显示升级、效果开关。满格不能继续购买点数或重复解锁。
- 优先使用已有天赋点及已付费空格。只对缺少的部分按原价结算：点数 40 核心、第一格 40 核心、第二格 80 核心。例如完全新解锁第一项为 80，已有空格但没点数为 40，空格和点数都有则不收核心；第二格和点数均缺时为 120。
- 一次操作完成补格、补点、分配 0 级天赋；不产生额外闲置点数，不自动购买升级等级。旧未分配点数、天赋格和既有天赋等级保留。
- 显示的报价与交易再次核对，不接受旧按钮在价格变化后继续扣款；重复点击已解锁天赋不再收费。

## 保存

沿用 JSON 局外存档字段，没有新存档格式或强制迁移。整个解锁只写盘一次；失败时恢复币种余额、天赋点总数、格子与天赋选择，保留原存档字节。既有底层分步 API 留作兼容，产品页面不再暴露独立买点入口。
