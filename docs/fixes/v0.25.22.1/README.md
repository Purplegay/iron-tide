# v0.25.22.1 · 限制音效缓存并复用同型号单位的武器挂点数据

## 游戏运行时

音效及 EVA 共享最近使用的采样缓存，最多 256 项、16 MiB 音频数据。单条超预算资源仍可播放，缓存淘汰不停止已经在播的声音。播放结束和退出战斗仍使用原有播放器生命周期。

同一型号单位共用炮口和武器挂点 JSON，步兵车不同炮塔模式独立读取，机场复用同一份机体原点。显式清空美术缓存后可重新加载。

三局无窗口对照，每局取 240 个真实声音条目，另生成 40 辆灰熊。第三局退出时音效缓存由 720 项、10,352,360 字节降为 256 项、2,634,856 字节。40 辆车共享一份挂点字典。用 2 MiB 测试音频单独验证字节上限；另验频繁播放、缺音、淘汰后继续播放和重新取回。5 个专项共 468 项通过。上述字节仅指缓存持有的音频数据，不是整进程 RAM 或 FPS。

## 本机磁盘维护

本次清除 20,864 个临时文件，合计 3,009,696,589 字节（按单硬链接文件长度统计）。来源是已交付双包的制作、解压验证和复制目录，以及旧试玩包的重复解压文件。保留下载目录中的包、开发工程导入缓存、游戏存档和历史截图归档。部分旧测试工程的独立 WAV 与 JSON 做了 NTFS 无损压缩，逐份验证哈希，分配空间减少 26,560,780 字节。

以后双包成功交付后可运行 [打包缓存清理工具](../../../tools/clean_package_cache.py)。传入用户 Temp 下该次 irontide-delivery-* 的完整目录，默认只预览；添加 --apply 执行。工具会先校验下载目录的两个成品，再清理与其匹配的暂存副本及该次导入产物。本次重复预检结果为零。已发给朋友的包仍是当时的版本。
