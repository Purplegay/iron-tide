# v0.25.24.8 · 实战存档帧耗时

用户提供的战斗通过原读档入口校验，恢复 76 个单位和 28 座建筑，其中有 19 只敌方海豚、12 辆采矿车。隔离桌面用同一份只读来源的副本对比上一试玩包与本轮源码，固定每秒 60 个模拟步，记录实际墙钟帧间隔。

| 场景 | 中位帧耗时（毫秒） | P95（毫秒） | 本轮最大值（毫秒） |
| --- | --- | --- | --- |
| 继续战斗 | 15.0 → 13.7 | 23.6 → 22.9 | 85.4 → 74.0 |
| 整队移动并平移镜头 | 18.5 → 16.4 | 29.1 → 26.5 | 114.2 → 68.2 |
| 仅平移镜头 | 15.4 → 14.9 | 24.2 → 21.7 | 51.2 → 49.3 |

前两组各记录 720 帧中的最后 710 帧，第三组记录 240 帧中的最后 230 帧。最慢帧仍可感知。反潜查询只访问本方声呐来源，仍实时读取射程、位置、装载、存活和当前阵营。光棱打击触发建筑视野时从随包数据读取建筑动画的可见边界，旧数据缺失时使用运行时计算。重新制作建筑图集后运行 `python tools/bake_building_frame_bounds.py`，并用 `building_frame_bounds_regression.tscn` 核对原图。移动指令跳过已部署步兵必然拒绝的即时路径，寻路搜索周边格时保留原顺序。屏幕外普通地面单位的状态图标跳过绘制。

建筑动画边界 3400 帧逐帧核对通过。反潜、受击建筑迷雾、阵型与部署避让专项通过。全量迷雾套件有 4 个平局时局外数据不变的断言失败，在 v0.25.24.7 与本版独立空白档中均为相同 4 项。
