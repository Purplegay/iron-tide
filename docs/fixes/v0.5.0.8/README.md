# Iron Tide v0.5.0.8 修复说明

2026-10-28

- 按起义 XML、FXShield、FXLightning 和 GPU 粒子着色器修正未来坦克球体及先锋质子炮：离屏特效改为原生加法合成，去掉方形贴片遮底和重复透明度衰减；球壳使用顶点视角衰减、原始随机透明度曲线及地面交线。
- 修正 GPU 光晕／闪光／扰动尺寸被当成半径而放大两倍、颜色曲线与 GammaToLinear 顺序错误；Q 首尾光晕同步修正尺寸，保留上一版亮度适配。
- 质子炮折射改用真实 GPUParticleDistortion 法线、角度、单次覆盖率及 PostFX_Distortion 的 0.08 屏幕 UV 偏移，命中时刷新背景副本，保留原冲击波遮罩侵蚀。
- 六组 285 项检查通过，含 19 项独立公式／像素断言。原版完整 HDR 曝光、全场景深度与多特效统一扰动缓冲尚未复刻，画面待用户确认；逐项来源、修正和缺口见 [特效对照表](../../RA3_FX_AUDIT.md)。
