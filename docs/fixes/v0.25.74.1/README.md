# v0.25.74.1 · 英雄坦克残盾不能恢复

## 修正

原逻辑明确允许残盾在静止、不普攻、未受击 3 秒后增加 15%，再每秒增加 5%；演示亦展示补盾。本次改为实际吸收伤害后记录 damaged，阻止本轮所有护盾增长与续时，直至护盾清零。

- 首次无盾静止 3 秒获得 15%，未受损时仍可每秒增长 5%，上限 50%。
- 任何实际盾伤（包括首次蓄盾途中）立即锁住残盾。移动、停火、继续静止和读档均不会解锁。
- 受击破盾清除锁定并重置 3 秒蓄盾计时；破盾的 2 格、110% 攻击伤害与溢出生命伤害不变。
- 自然到期清零不爆炸，之后可以重新积攒；受损残盾不会刷新剩余时间。
- 实战详情与英雄天赋演示同步显示“残盾不能恢复”，不再演示残盾补满。

## 旧战斗存档

护盾状态规则升级为 3。旧规则无法可靠判断残盾是否受过伤，因此保留原盾量、剩余持续时间，将现存护盾锁定至清零；不会补满、删除或延长旧护盾。新规则存读档完整保留受损锁定和未受损的蓄盾进度。
