# v0.21　单位改造名单与技能卡池

驻防基地新增技能卡池，所有通用 W 主动与被动都需抽取解锁；单位改造只列出盟苏可生产的兵种。国家特有、需要科技前置和扩展专属兵种仍可预先改造。场景单位、召唤物和旧原型继续用于原有对局。

驻防基地顶部或单位改造详情可进技能卡池。共 18 个主动和 6 个被动，每抽 600 军需券，沿用原有稀有度权重。抽取不重复，满池停止扣费，保存失败时不扣券或发卡。原先抽到的技能保留；旧装配中尚未抽到的通用技能在新对局中暂不生效，抽到后原有装配可继续使用。固定 Q 和 E 单独提供，RA2 对照模式沿用原技能规则。

无窗口技能与热键专项 191 项，生产目录专项 1282 项均通过。验证包含真实页签抽取、存档重读、旧装配、改造界面和对局内装配效果。
