# v0.25.39 · 专属天赋费用与辐射扩散等级

## 费用

按用户确认，专属天赋从原来的每次 40 战略核心，改为：

| 升级 | 战略核心 |
| --- | --- |
| 0→1 级 | 40 |
| 1→2 级 | 120 |
| 2→3 级 | 240 |

总升级消耗 400。配置位于 `iron_tide/data/meta.json` 的 `talent_rank_costs`；界面完整价目、下一等级按钮、余额不足禁用和实际购买使用同一来源。购买仍验证当前等级，拒绝过期回调重复扣款、满级购买及未分配天赋升级；写盘失败回滚等级和余额。

已有等级不补扣、不清零。0 级分配、天赋点兑换、开格、卡牌升级、英雄护卫／战术中枢和英雄生存项目保持原规则。

## 辐射扩散

用户要求删掉原第 3 级，而不是新增第 4 次升级收费。最终等级如下：

| 等级 | 每层等待 | 满三层额外半径 |
| --- | --- | --- |
| 0 | 5 秒 | 0.5 格 |
| 1 | 4.8 秒 | 2 格 |
| 2 | 4.5 秒 | 2.5 格 |
| 3 | 1.5 秒 | 4 格 |

去掉原“每层 4 秒、满层 +4 格”的中间阶段，原第 4 级成为新第 3 级。旧局外存档的第 4 级归并为 3 级并持久化，重复读取不会重复调整；旧第 3 级保留为新满级，不追加收费。旧战斗快照中的等级 4 经既有等级读取边界归为新满级，层数和计时仍沿用原快照。展示和演示现在均为 0～3 级。
