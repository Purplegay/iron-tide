# v0.25.56.1 · 卡池演示动态同步

根因是 faction_card_gallery 用独立静态名单登记 13 张卡，而可抽卡池已有 20 张。单位改造虽然创建了两张许可卡的演示按钮，点击后也会因静态名单找不到 ID 直接返回。

列表及数量现在直接来自 MetaProgress.skill_draw_candidates；不要求先拥有卡片，不把已移出卡池的旧通用卡重新加入。动画按卡牌 ID 匹配，不依赖列表下标。每次打开重新读当前卡池；未来新卡自动进入列表，特殊动画仍须实现对应表现，未实现时明确提示，不冒用其他卡动画。

两张许可按配置读取四档门槛：海豹击杀 10／8／5／3 次；伊文实际引爆 5／4／3／1 次。动画展示实验室就绪、动作、累计计数、解锁超时空突击队／超时空伊文；只是规则演示，不改变真实解锁、战斗或钱包。五张普通卡补齐烟幕、加速、增伤、减伤示意动画。保持原慢放、拖动、暂停和切等级保留时间功能，切卡同步标题及进度条。

验证：card_gallery_regression 1012 项通过，包括继承的演示回归、反转卡片配置顺序、20 张卡的四档 ID 匹配、两种许可计数阶段、单位改造入口及只读性。无脚本异常；逻辑测试退出沿用既有 FontAdvanced／CanvasItem／ObjectDB 释放警告。独立 Windows Desktop 截图确认列表和四张许可演示画面，无用户桌面弹窗。演示采用现有规则示意画，不代表实战素材视觉验收。
