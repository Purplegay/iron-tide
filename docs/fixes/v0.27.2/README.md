# v0.27.2 · 建造范围与盟友建造场

按尤复地图格换算建造距离；同一结盟组可以在盟友建造场附近放置自己的建筑。

- 放置吸附步长为 40 世界像素。Adjacent 和扩展建造场的八格距离按尤复的 55 世界像素／格换算，从两座地基的边缘计算。发电厂 Adjacent=2，对应 110；造船厂 Adjacent=12，对应 660；扩展建造场的最低范围从 320 增至 440。
- 盟友范围来源同时检查同组关系、存活、施工状态、BaseNormal 和 rulesmd.ini 的 EligibileForAllyBuilding。范围预览和实际放置共用判定，建筑和订单归建造者。己方占领油井仍按己方规则处理。
- 经典和扩展模式验证边界、建造场选择、盟友所有权、未完工及敌对拒绝、真实就绪订单的落点与归属。范围、建筑预览、油井及多家遭遇战回归共 1048 项通过。尤复综合回归的 578 项中通过 568 项，剩余 10 项建筑预约科技和科技树界面断言在修改前后均失败。
