# v0.26.6.3 · 光棱坦克在桥上追击

普通右键点岸上建筑时，原先寻路的目的地靠近建筑基座。友军卧倒封住前方桥面后，即使桥上还有足够的空间开到武器射程内，光棱坦克也可能停在原地。

光棱坦克现在优先规划到射程内的开火位置，并核对寻路实际终点与目标之间的距离。建筑按基座边缘计算。该位置到不了时，继续尝试原来的接近路线。

## 验证

在纯 RA2 和扩展模式中，用普通右键命令一辆光棱坦克攻击岸上的磁暴线圈，三名已部署的重装大兵占住前方桥面。修改前两种模式都能锁定目标，但推进 8 秒后坦克仍在起点。修改后坦克沿桥前进约 193 个世界像素，在线圈基座边缘约 550 像素处首次造成伤害。回归另检查了进入射程后再次右键能原地继续攻击。
