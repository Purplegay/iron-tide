# v0.25.73 · 六种复杂遭遇战地图

入口：驻防基地／遭遇战 → 战场布局。原有经典海岸、双桥争夺、隔海登陆保留，新地图使用现有 RA2 美术资源。

| 布局 | 主要结构 |
| --- | --- |
| 多桥河谷 | 三座桥连接主河两岸，支流分割侧翼；其中一座断桥可修复，桥头民居、油井和宝石形成多路争夺。 |
| 环湖争夺 | 中央大湖、南北水道、外环陆路与两座跨湖桥；可绕行，也可争夺桥梁捷径。 |
| 群岛登陆 | 十字海峡分出四块陆地，双方隔海开局，侧翼岛屿有资源；需要空军或运输登陆。 |
| 运河城镇 | 双运河、四座桥、中央岛带和驻军民居；舰艇可以穿行桥下。 |
| 双湾半岛 | 南北海湾夹出中央陆桥，右侧外海互通；正面城镇与海岸迂回。 |
| 内陆矿区 | 中央宝石、多处普通矿与五个油井锚点；两座独立侧湖，偏重陆战，不要求开局可直接造船厂。 |

地图地形与地标按布局固定编排；矿石仍使用现有铺矿规则，油井会按空地检测小幅避让。预留桥面、维修屋和资源附近空间，避免随机障碍直接堵住。新海战地图的基地保持距岸固定距离，AI 可在三档尺寸内选到船厂位置；群岛登陆优先生产第一艘运输船。新地图的敌方开局矿场改放基地下侧，避免小尺寸地图东侧入海。

兼容 2400／3200／4000 三档、RA2 与扩展规则、预建基地和基地车开局。布局 ID 参与现有地图选择记忆、国家配色记忆和战斗存档；旧布局 ID 与序号不变，不迁移或覆盖玩家存档。
