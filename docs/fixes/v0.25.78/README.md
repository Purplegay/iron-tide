# v0.25.78 · 挂件三轴旋转与快捷键

涂装工坊「调整挂件」现在支持 X 侧倾、Y 偏航、Z 俯仰。旋转模式显示红／绿／蓝三色圆环；拖圆环调整对应轴，组合旋转后仍按显示的挂点轴转动。边缘朝向的圆环采用沿屏幕切线拖动，避免射线与旋转平面平行时跳变。三视图实时同步；仍可直接输入角度。

| 操作 | 快捷键 |
| --- | --- |
| 移动挂点 | W |
| 三轴旋转 | E |
| 整体缩放 | R |
| 分轴拉伸 | T |
| 选旋转轴 | X／Y／Z，自动切入旋转模式 |
| 旋转选中轴 | ←／→：每次 5°；Shift 为 1°，Ctrl 为 15° |
| 拖圆环精调／吸附 | Shift 降低灵敏度；Ctrl 吸附 15° |
| 原有操作 | 非旋转模式 Shift 拖中心缩放／拖轴拉伸，Alt 拖俯仰；右键环绕、中键平移、滚轮缩放镜头 |

输入框获得焦点时不抢走编辑快捷键。旋转围绕挂点，不改车身大小和位置；骨骼动画继续带动挂件。旧档未设置的新轴默认 0°，保留原俯仰方向和尺寸。取消恢复旧状态；保存位置、旋转、尺寸合计一次 100 军需券，未修改免费。位置单独保存不会清除旋转。复位恢复全部角度、位置和尺寸。

验证：独立 Windows 桌面、从不切换桌面，三轴拖动／快捷键／角度输入／存读档／取消／旧档兼容／骨骼同步 33 项通过；原缩放拉伸、费用失败回滚等 36 项回归通过。合计 69 项。原回归刻意制造写盘失败的一次 warning 属于预期。截图见 [rotation-editor.png](rotation-editor.png)。未打包、未推送。
