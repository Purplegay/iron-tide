# v0.25.24.4 · 框选残血部队

选中面板单独绘制低血告警，保留原来的红色脉冲。超过 12 个单位时，静止单位的选中标记与装饰动画分三个物理帧错开刷新。移动、开火、转向和受击仍可立即触发重绘。

在隔离桌面用同一批 96 名动员兵交替框选满血与 16% 血量的队形，每档两轮，每轮记录持续选中时的 60 帧。低血告警原先每轮产生 62～63 次面板主题变更，改后为 0 次。启用单位物理更新、固定战场和镜头后，单独对照错帧绘制前后，两轮残血中位帧耗时由 22.1～22.8 毫秒降至 14.8～14.9 毫秒。该场景未模拟交战中的整场 AI 负载。

回归场景为 `res://tests/wounded_roster_regression.tscn`，覆盖框选数量、告警随血量恢复、近期受击与移动重绘，以及从大编队切回单选。
