# v0.25.46.1 · 余烬重钢移动特效性能

用户指的是普通犀牛坦克橘黄色「余烬重钢」，不是英雄机甲皮肤。本机 `user://battles/slot1.itsave` 有 161 单位、25 建筑，其中 46 辆犀牛，45 辆普通犀牛在局外档装备余烬重钢。

## 修复

- 沙土环绕原来每辆车每次重绘提交 24 条抗锯齿线和 24 个圆，每辆都重复生成几何。
- 改为半径／相位共享的前后两片网格，每次只提交两次绘制；保留 24 颗沙粒、椭圆轨迹、车体前后遮挡、停车淡出和受炮弹攻击的金属护壁。
- 每周期 96 个视觉相位（约 28 Hz），不改变单位移动、攻击或游戏结算速度。缓存最多 8 种半径，各 192 片网格，避免长期增长；圆点有 16 边与透明软边。
- 仅在护壁闪光实际变化时更新材质参数，不再每个物理帧重复提交零值。
- 不修改玩家战斗存档、局外进度、皮肤装配或数值规则。

## 验证与边界

全部测试使用无窗口进程或不可见 Win32 独立桌面，没有切换桌面、启动可见游戏窗口或终止玩家进程。

`tests/tank_finish_regression.tscn`：1449 项通过，覆盖三种半径和所有相位的几何索引、前后粒子总数、共享缓存、起步／停车／瞬移和受击衰减。独立桌面检查了优化前后的放大图，见 [沙土对照](dust-comparison.png)。

同一存档和同一局外配置，Intel Core Ultra 5 250K Plus + RTX 5060 Ti，Godot 4.7.2 Compatibility，关闭 VSync、固定模拟步长；每阶段采集 180 帧，保留 AI 和战斗。两个原实现样本和最终代码样本：

| 场景 | 原实现中位帧耗时 | 最终实现中位帧耗时 | 最终 P95 |
|---|---:|---:|---:|
| 读档视角 | 27.63／28.33 ms | 21.74 ms | 33.70 ms |
| 框选 46 辆犀牛 | 28.39／28.43 ms | 26.36 ms | 37.27 ms |
| 46 辆犀牛移动 | 41.21／42.59 ms | 30.45 ms | 43.01 ms |

移动阶段中位帧耗时减少约 26%～29%。完整摘要见 [profile-summary.json](profile-summary.json)，原始帧样本保留 [before_1.json](before_1.json) 与 [after_final.json](after_final.json)。其他中间轮次移动中位数为 22～30 ms，但曾出现 125 ms 的孤立尖峰；本次不据此宣称持续稳定 60 FPS 或所有尖峰均已解决。

这是真实存档的图形回放，不是 3700X 实机结果。仍有单位行动／碰撞、自动索敌及其他表现开销；不能归因为 Intel/AMD 品牌差异，也不能仅凭皮肤优化证明其他瓶颈消失。

## 复现

保留当次采样脚本 [saved-battle-profile.gd](saved-battle-profile.gd)。放入隔离测试工程 `tests/rhino_profile.gd`，通过场景运行；设置 `IRON_PROFILE_SAVE` 指向存档只读副本、`IRON_TIDE_REPORT_DIR` 输出目录、`IRON_PROFILE_CASE` 标识轮次。需独立 APPDATA，并将对应 `iron_tide_meta.json` 复制到隔离的 `CodexIronTideValidation` 用户目录，否则皮肤可能没有装配。`ember_off` 仅用于关闭效果的诊断对照。

存档哈希已核对，测试前后原文件一致。用户存档与局外文件未纳入仓库。

更新工程后需完全退出旧游戏再启动；旧试玩包不会自动更新。本轮未打包、未推送。
