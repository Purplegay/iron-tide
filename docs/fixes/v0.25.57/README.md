# v0.25.57 · 战场被动／天赋详情与快捷键

## 玩家入口

- 选中单位后，点击技能栏「被动／天赋」。即使未装配被动卡，也可查看天赋；建筑也有详情入口，部署收割者展示原单位天赋。
- 显示本局已启用专属天赋与等级、原生机制强化数值、实际装配被动说明、英雄累计天赋、磁爆蓄电状态、临时效果及剩余时间。条件效果标注触发条件，不把已启用等同于当前正在触发；暂未单独列出所有机制内部计时器。
- 读取本局冻结数据；局外改等级不会改写已经开始的战斗。经典模式不显示扩展养成天赋。死亡或对象释放后显示离场，英雄残骸／乘员／冻结状态说明限制。
- 多选时展示技能栏代表单位；详情每 0.25 秒刷新，战斗继续进行。Esc 关闭，打开期间拦截战场鼠标与快捷键。
- 主菜单设置、战斗设置中点击「战斗快捷键」。可改 Q/W/E 槽、攻击／停止／警戒／部署等指令、存档／暂停／倍速与视角键，共 27 项单键。
- 点击指令再按新键，冲突时拒绝保存；Esc 取消当前录入，支持恢复默认。按键与按钮角标同步，改后旧键不再触发旧指令。
- Ctrl／Alt／数字编队、方向滚屏、Ctrl+G、Ctrl+F、F11、Esc 和鼠标组合保持原规则。Shift 仍可配合已有追加指令。配置保存在 `user://battle_hotkeys.cfg`，写入失败保持旧设置，损坏／重复配置回退默认。
