战场远征面板显示信物指令，按钮提示写明选兵及操作条件。维拉以三段光束击中同一目标触发战记；林岚由返回集合点后留下的残影实际开火触发。

## 通信原文

### 林岚 · 遮阳板乘客名单

**《还有四个空位》**

林岚递来一块旧遮阳板。上回写在背面的名字都打了勾，最下面却多出四行，用橡皮擦过一遍，又描得整整齐齐。

“别等出事才填。”她把铅笔塞进弹簧夹，“你出发前就写。我走到哪一站，知道该等几个人。”

**《回车铃》**

车已经停稳，远处又响起主炮声。小满从副座上跳起来，数了一遍人头，又数一遍。林岚把他按回座位，指着那些姓名：“听见的是刚才的他们。现在这一车，归你点名。”

### 沃尔科夫 · 缺齿炮闩

**《第三声》**

米沙把旧炮闩压在调拨单上。钢上缺了一齿，长官肯定嫌它难看。沃尔科夫却说，车里最黑的时候，戴手套一摸就知道哪头朝前。

他在我桌面敲了两下。我等了一会儿，隔壁车库果然传来第三下。他把炮闩推给我：“这回听见了。给你。”

**《合奏》**

德国车长在电台里喊了一声准，天启的炮手们齐声回答。米沙拿铅笔在值班表上画了根五线谱，几个音符全挤在同一拍。老头挑了半天毛病，最后只说：少画了人家起头的那个。

### 苏砚 · 双曝光底片

**《漏光的暗袋》**

苏砚从显影盘里夹起两张叠在一起的人像。第一张是个浑身泥的工兵，第二张是他洗过脸以后，耳朵后面还漏了一块。研究所嫌重影，他把照片留了下来。

“别人看得见挨了几炮，我想看清第一炮到底帮了第二炮多少忙。”他把那只暗袋交给我。

**《两次快门之间》**

显影纸上第一道白痕刚好贴着第二道的边。苏砚把两支车组的名字都写进署名栏，把自己的名字挪到背面。我翻过来，看见一行小字：洗照片的，今晚留下擦桌子。

### 玛拉 · 灯塔的红绿玻璃

**《给归船留一面》**

玛拉拆下灯罩，把红玻璃递到我左手，绿玻璃递到右手。她父亲教她认方向从来不说左右，只问，回家的船从这里看，应该是什么颜色。

她退到营地门外，让我给她指一次路。看我没拿反，她才把两块玻璃装进小盒。

**《交班》**

两队飞机在灯列两端报了平安。年轻的飞行员问塔上是谁领航，玛拉把麦克风递给我。那头传来笑声：“我认得你的灯。绿色那盏，比红的晃得厉害一点。”

### 娜佳 · 慢五秒的钟摆

**《报时误差》**

修钟师说钟楼慢了五秒。娜佳不肯调：楼下那个卖报的孩子，每天就靠这五秒赶上第一班车。

她给新钟装了准点的摆，把旧摆包好送我。“什么时候差一口气，你就朝我借。那孩子现在自己开车了。”

**《末班车》**

两个车组在同一拍接了话。娜佳以为自己拨错频率，听了半天才发现，两个国家的小伙子都在用嘴学那声钟响。她按下通话键，也学了一声。

### 乔远 · 磨白的木折尺

**《折过去的半寸》**

乔远的尺上少了半寸刻度。小时候他拿它量门框，妹妹一年比一年高，最高的那道铅笔印被拇指磨没了。他从没舍得换。

交给我时他折起第一节：“量桥用后面几节。这一节，到家还得量人呢。”

**《尺的另一头》**

烟散开时，两条支路同时露出了路口。重装大兵和发射车司机各自举起尺的一头，隔着空地争是谁站歪了。乔远只忙着拍照：“吵，使劲吵。以前这里两边的人喊都听不见。”

### 维拉 · 变电所最后一把钥匙

**《钥匙认人》**

小徒弟从工作服里摸出一把钥匙，柄上还拴着病房的蓝布条。维拉问他舍不舍得。他说配钥匙的铺子上礼拜开张了，掏出一串新钥匙，挨个试给我们听。最后那把旧的落在我手里，还有他的体温。

维拉把我的手指合上：“上次你把拿钥匙的人救出来了。这次，换你合闸。”

**《合闸的人》**

三道亮光在同一处碰头，小徒弟低头在值班表上找了半天，说还缺一个签名。维拉把表推过来。我签得歪，他也没擦，只在下面写：今夜送电，全班到齐。

### 伊内丝 · 背面朝外的袖镜

**《镜子朝外》**

伊内丝的袖口缝着一面镜子，镜背朝外。她说小时候站在窗口给弟弟打信号，闪一下是车来了，闪两下是再睡一会儿。后来侦察队人人会读，弟弟倒总要装睡。

她替我扣好袖扣：“想让人知道你在哪儿，再翻过来。”

**《多闪一下》**

雨燕的两列车顺着镜光同时现身，电台里的口哨响成一片。清点完毕，伊内丝往空路口又闪了一下。我问那是什么意思。她收起镜子：“告诉在家等的人，可以再睡一会儿。”
