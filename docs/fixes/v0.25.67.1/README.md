# v0.25.67.1 · 受击残盾停止增长

## 根因与确认规则

旧 tick 只判断静止且盾量低于 50%，没有区分首次蓄盾和受击残盾，因此一秒后会补回消耗并刷新持续时间。用户明确选择：首次可蓄到 50%；一旦受击，有残盾就不再增长，清零后才能重新蓄盾。

现在 shield special 状态保存 damaged 标记。实际吸收正伤害后锁定增长并清空未满一秒的蓄盾进度；残盾继续倒计时，不因静止、移动后停止或读档补盾／刷新时限。破盾或自然到期清零解除本轮锁定，重新静止 3 秒得到 15%，未再次受击时仍按每秒 +5% 增至 50%。

保留护盾吸收顺序、伤害溢出、110% 主炮攻击力破盾爆炸及 2 格范围，自然到期不爆炸。天赋说明、战场详情标明“受击锁定，残盾不恢复”，演示增加残盾停留再破盾、重新蓄盾过程。

## 存档

新字段随既有 special 快照保存；未受击护盾读档继续首次蓄盾，受击护盾保持锁定。旧档没有受击标记、无法判断历史时，已有护盾保留当前量和剩余时间并按锁定处理，防止载入恢复残盾；清零后开始正常新一轮。无盾旧档正常静止蓄盾。不改存档格式版本或养成数据。
