# v0.26.6.7 · 超武落成语音与持续位置暴露

AI 将战略武器设施从就绪队列放到地图上时，玩家会收到一次 EVA 播报、带建筑名的战场消息和雷达标记。核弹井、铁幕、超时空传送仪和天气控制器使用各自的原版侦测语音。侦察机、美国空降和力场护盾设施使用通用信标语音，战场消息注明设施名称。发射时仍有独立警告。

已建成且仍存在的战略设施会持续向对手暴露自身位置。停电、充能、发射后重新装填及读档都保留这项情报。设施毁掉后，玩家保留已探索地形，其他侦察或临时视野按各自规则处理。读入已有对局会按当前建筑恢复位置，无需重新建造，也不会重播建成语音。

## 后台验证

纯 RA2 与扩展模式均从敌方建造队列实际落地七类设施，检查语音资源、雷达标记和立即可见性。发射、断电、存读档及时间推进后复查位置，并检查移除设施后视野回到已探索状态。语音通过后台播放器检查，未做扬声器听感验收。

超武警报 248 项、战略支援栏 110 项全部通过。迷雾与胜负规则套件 566 项中通过 562 项，剩余四项都断言平局后局外数据完全不变；在隔离副本中关闭此次视野与建成警报改动后，相同四项仍失败。
