# Iron Tide v0.3.9.2 修复说明

2026-10-27

- 校准盟军兵营、战车工厂、矿场及船坞的生产出口；车辆朝出口方向出厂，夜鹰对应顶舱，机场飞机直接进入本机场预留停机位。
- 按反馈增加受阻偏移：优先原出口，在出口前方及两侧160世界单位内由近到远寻找合法空位；检查单位间距、建筑阻挡、水陆和地图边界。附近全部堵住才等待，不重复扣费；机场停机位仍按本机场容量处理。
- 无集结点的新造单位短距离驶离出口；已有集结命令优先，地图生成不继承工厂命令。保留开局两辆矿车、矿场自动采矿和机场返航逻辑。
- 出兵专项及关联回归见 VERIFICATION；外观及连续出兵手感待实机确认，未提交、推送或打包。
