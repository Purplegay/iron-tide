# v0.27.17.0 · AI 出征与生产偏好

单电脑和多家独立 AI 共用以下规则，不影响玩家部队的命令或自动采矿。

- 总现役达到 32 个触发主力出征，矿车、工程师等支援不参战，至少保留 6 个战斗守军；例如 29 战斗＋3 支援，23 个出征、6 个守家。
- 后续战斗单位轮流增援、留守；守军不足 6 个时优先补齐，补齐不消耗交替次序。每家 64 上限、排队名额校验、原有满编减半后的造兵加速规则保留。
- 角色与增援次序随存档保存；旧档首次决策按现有兵力建立分工，不删除超过上限的旧单位。陆军到达目标闲置后再发起进攻，凶残 AI 不再把出征部队按闲置回营或基地报警整批召回。
- 海空战斗单位也分配角色，留守者只选择基地附近或自身射程内威胁；原有海空任务、运输与侦察流程保留，32 是主力集体出征阈值，并不禁止前期专门任务。
- 海豹、疯狂伊文采购系数 0.35 → 0.0875，相对当前再减 75%；尤复天启、光棱系数 1.5 → 1.95，提高 30%。这是采购权重，不是承诺最终单位比例；科技、反制和经济仍参与选择。
- 通用作战采购不再包含工程师、间谍、矿车和基地车等非战斗产品。新工程师占油任务必须存在当前可见目标，不能只依据迷雾里的旧记录或受威胁的中央油井反复购买；其他明确的支援流程保留。
- 地面 AI 收到实际攻击后，优先停下攻击射程内、可见、可攻击的敌人；不为反击新建路径。目标离开射程或反击记忆过期后恢复原目标和路线；飞机保留专用航行攻击规则。已有连发先完成，不打断弹仓。
- 战役目标从部队当前位置评估距离，提高附近可见建筑的优先级，局部索敌也增加建筑权重；不透视隐藏目标、不覆盖就近反击。

## 验证

Godot --headless、隔离用户目录，无桌面窗口，975 项通过：出征专项 59，多家经营 248，海空与生产 466，战术 58，满编补员 24，决策预算 16，凶残三 104。

专项覆盖真实攻击移动下令、31／32 阈值、6 人守军、十兵五五分配、读档续接、64 封顶、反击保留原路、玩家命令不受影响、海空留守过滤与凶残闲置回营冲突。修改了旧战术测试中的八兵出击断言，使其符合新的 32 阈值。各测试结果与源码 SHA256 见 [regressions.json](regressions.json)。

本轮属于 AI 行为调整，没有重新测量大型存档 P95，不能把这些通过项视为性能达标。无头验证不等于实际对局的视觉与体验验收。不导出试玩包。
