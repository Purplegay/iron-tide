# Iron Tide v0.3.5.1 修复说明

2026-10-27

- 修复 RA3 幻影与普通坦克混编移动时，积累的履带轨迹拖慢整幅画面的问题。最多1600个逐条绘制命令改为按两张原贴图批量实例绘制，新轨迹最多30Hz更新。
- 保留1600条上限、18秒寿命、末5秒淡出、方向、迷雾过滤和读档清理；屏幕外轨迹不提交绘制。未改骨骼动画、模型精度、移速或寻路。
- 同机三辆混编、1600条轨迹压力场景：移动帧耗时中位数17.604ms→3.990ms，P95 21.248ms→6.638ms；12辆混编中位数22.000ms→6.724ms。测试场景结果不代表所有战况的固定帧率，实际手感待使用者确认。
