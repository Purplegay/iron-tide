# v0.26.1.1 苏联战车工厂工期

尤复规则中，GAWEAP 和 NAWEAP 均为 Cost=2000，使用默认建造时间倍率。按 BuildSpeed=.7 换算，两者基础工作量都是 84 规则秒。项目此前只把盟军工厂映射到战车工厂的节奏，实际为 21 秒。苏联工厂落入通用的两倍生产速度，实际需要 42 秒。

现在两座工厂共用同一条工期规则。正常供电、单建造厂、1 倍速且资金充足时，生产卡片显示 21 秒，建筑队列按进度支付 2000 资金并进入就绪状态。已有订单沿用存档中的已付金额和完成进度，下次推进时按新速度计算剩余部分。

无窗口专项 `war_factory_timing_regression` 共 24 项通过。RA2 与扩展模式各以美国、苏俄开局验证，均在 10.5 秒扣款 1000，20.9 秒仍在建造，21 秒支付全部 2000 并就绪。
