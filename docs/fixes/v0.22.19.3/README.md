# v0.22.19.3 · 修复无窗口回归卡住，复验战机返航补弹和 C4 进出建筑

无窗口 Godot 不发出画面绘制结束信号。飞机弹药、机场指令和 C4 专项此前等待该信号直至超时。本版将像素截图与行为断言分开。使用图形渲染器时仍执行原有像素断言。此版本修复测试入口，复测没有发现需要修改的对局逻辑。

## 本次实测

Godot 4.7.2 在独立玩家目录内无窗口运行，覆盖纯 RA2 和扩展模式。

| 专项 | 通过 | 观察点 |
| --- | ---: | --- |
| aircraft_ammo | 94 | 已选和悬停时显示的弹数、齐射扣弹、补弹进度、低电暂停、满弹待机 |
| airfield_order | 50 | 入侵者和黑鹰通过右键选择机场、保留预订位置、满位拒绝、多人抢最后一个停机位 |
| logistics | 180 | 实际齐射、自动飞回并着陆、恢复供电补弹、原目标存活时满弹停留十秒，以及既有载具与航母后勤 |
| c4_entry | 136 | 海豹和谭雅右键从四侧接近战车工厂，进入地基安放后撤出。另测电厂引信、工程师拆弹、停止命令、进出建筑时存读档、爆破与击杀归属 |
| commando_attack | 120 | 实际目标对应的武器、普通与混编攻击指令、C4 建筑攻击与移动命令 |

共 580 项通过，脚本与引擎报错均为零。弹药点像素变化和建筑红闪强度留待图形渲染环境验收。
