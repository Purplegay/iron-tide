# v0.25.51.1 · 原生天赋动作演示

单位改造中的原生天赋原先共用纯文字的「数值预览」入口。现在统一进入「演示」，上方播放未强化状态，下方播放所选 0～3 级，提供暂停、继续和重播。等级选择同时更新动作、机制数值和说明。

## 覆盖内容

- 美国大兵、重装大兵：部署及受击后的生命对照。
- 盟军／苏联警犬：扑击、命中、再次扑击间隔，以及正面防护与后方受击区别。
- 超时空军团兵：传送残影、恢复等待及恢复后开火。
- 武装直升机：部署炮形态与强化后可覆盖的额外射程。
- 辐射工兵：部署辐射与伤害对照，保留相同半径。
- 疯狂伊文／超时空伊文：接近目标、放置炸弹、引信与爆炸。
- 鲍里斯：标记建筑及空袭到达。
- 盟军／苏联基地车：展开过渡、进度与展开期间防护。
- 光棱坦克：主光束及分裂光束。
- RA3 幻影、未来、天启、收割者、磁暴坦克：分别演示覆盖范围、横扫后冷却、牵引速度、跳跃落地范围和磁暴模式范围。

## 实现边界

新增 `native_talent_demo.gd` 与 `native_talent_stage.gd`，共 18 个兵种入口。模型复用单位展示组件；演示数值读取当前 `skill_training.gd` 的公式，扑击／跳跃等待使用对应玩法常量。较长引信、展开和冷却使用明确标注的演示倍速。

这是使用真实单位模型的只读机制动画，目标、光束、范围等采用说明性绘制，并非完整战斗模拟或原作特效复刻。不会购买／改变等级、修改战斗上下文、运行 AI 或加入全局单位组。已有专属天赋和英雄演示入口保留。
