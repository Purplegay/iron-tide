# v0.25.52 · 演示慢放与进度条

动态演示新增 0.25×、0.5×、0.75×、1× 播放速度，可拖动进度条和当前／总时长。拖动期间冻结动作，松开恢复拖动前的播放状态；暂停时可以逐段拖动查看，拖到末端停留最后一帧而不是立即回到开头。重播／切换等级从头开始，保留当前速度，并同步对应周期长度。

接入原生天赋、技能卡、英雄天赋和复用单位模型的专属天赋（如掩护倒车、分区射击、辐射扩域）。碉堡原有静态射程图没有时间轴，不显示无意义的播放控件。速度只改变演示时钟，不影响战斗速度或养成数据；长冷却原有的演示压缩倍速仍单独标注。

共用组件 `scripts/ui/demo_playback.gd` 负责控制和同步；各演示继续读取自己的周期及等级规则。模型展示组件仅在专属天赋演示中应用慢放／暂停，不改变涂装工坊旋转和轮胎演示。
