# Iron Tide v0.5.0.9 修复说明

2026-10-28

- 未来坦克 Q 超出范围时先寻路接近，进入起义原生 250 距离（本地图 375）后才展开并开始冷却；无法接近、S 停止或新移动命令不会空放／消耗冷却。技能范围预览同步使用真实施放距离。
- 横扫拆分为沿线 25 伤害和末端 50 伤害；末端按原定义延迟 0.1 秒，非步兵倍率 30%。删除错误的“每 0.1 秒把两者一起结算”，原生 DamageInterval=0 按固定 30 步连续采样，低帧率补齐事件，独立于尤复 15 帧速度。
- 命中使用单位碰撞圆／建筑占地轮廓；延迟尾帧在光束结束后继续结算，保存读取恢复事件游标，保留既定跨代血量换算。七组 577 项通过。
- 下载并对照 Bibber 的 Upheaval 1.16 源码，区分其 RA3 移植写法与官方起义模块。完整来源、差异和 CPU 证据边界见 [Q 逻辑对照](../../RA3_RIOT_AUDIT.md)；操作及横扫观感待实机确认。
