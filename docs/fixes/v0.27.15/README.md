# v0.27.15 · 按实际航道调整 AI 造船

以船厂出口所在的可航行连通水域占地图的比例决定投入。原图使用导入的地图格数，自制地图使用战场网格。低桥、陆地和阻塞航道的建筑会影响连通范围。地形重算后重新评估，电脑盟友和敌人都遵循同一规则。

| 船厂所处水域 | 平时的采购规则 |
| --- | --- |
| 小于 5% | 陆军采购后，每 4 次符合条件的机会允许订 1 艘，常备 2 艘 |
| 5% 至不足 15% | 陆军采购后，每 2 次符合条件的机会允许订 1 艘，常备 4 艘 |
| 至少 15% | 沿用开放海域的连续生产和预算规则 |

同一电脑的现役舰船、该水域所有船厂已排队的订单合并计数。旧档里已超编的舰船继续服役，已有订单继续生产。同一水域可见敌舰多于己方时，可按正常预算优先补到敌舰数量。隔水的敌舰不会触发增援。海峡和群岛登陆的首艘运输船仍可优先采购。玩家船厂由玩家直接控制。

Circuit Board 的原图有 12960 个地图格，低桥分割后，最大的水域为 415 格，约占 3.2%。测试在该图的真实船厂验证了陆军优先和小水域订单；另在有独立大海和小河的同一地图验证了多船厂共享配额、跨水域敌情、航道扩展后重新评估。海岸 260 项、多方 AI 236 项、自制地图 281 项、登陆 54 项，合计 831 项无窗口检查通过。
