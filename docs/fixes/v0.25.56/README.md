# v0.25.56 · 分类普通卡与场景图标

按照用户确认的五张普通卡分工，添加 `allowed_categories`。获取仍是 gacha，同名共享，抽取费用、概率、品质、升级和已拥有等级均未改变。普通分类卡不冒充兵种专属卡，专属筛选仍按真实专属卡／天赋。

分类见 [技能卡开发规范](../../SKILL_CARD_DESIGN.md)。兼容规则用于 UI 和有效装配归一化，旧不兼容装配失效但卡片／培养不删除。已有战斗快照数值未执行破坏性迁移；新冻结对局包含防御建筑装配，旧对局缺少该建筑记录时不会读取新改的局外装配。

当前 20 张可抽卡全部配置语义图标。大图形表示应用场景，右下表示效果，多类型右上表示另一适用类别；文字列出适用对象。兼容原专属高亮、培养和战斗技能栏。没有导入 AI 位图，沿用现有 SVG 图标体系。

防御建筑改造页支持 W 和被动。扩展模式中，聚焦射击按卡等级生效 6 秒、冷却 20 秒，复合装甲板按等级作为防御除数；驻军射击临时应用建筑火力倍率后恢复原始值，不永久污染乘员数值。旧磁暴脉冲保留，适配器继续用原 special 字典保存。供电、建造、暂停和死亡限制仍有效。Auto W 对聚焦使用可攻击且即将开火的条件。碉堡装 W 后仍能点击驻军头像撤出。经典模式不启用卡牌。
