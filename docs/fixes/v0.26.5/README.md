# v0.26.5 对局养成与 AI 难度

对局中的档位属性、全体后勤、兵种火力和装甲、英雄火力和生命训练，每项增加的数值调整为原来的 1/4。基础属性仍按 100% 起算。各项按原来的方式组合。玩家已购等级、价格、等级上限继续沿用，挂机产出和仓储使用原来的数值。

全体与兵种火力现在每级 +0.75%。兵种装甲系数每级 +0.625%。四名英雄的火力训练每级 +0.5%，满级 +75%；生命训练每级 +0.75%，满级 +125%。技能卡、专属天赋及军衔按各自的规则生效。

凶残1 的 AI 后勤／兵种改造等级由 5／3 换算为 20／12，凶残2 由 10／8 换算为 40／32。AI 用自己的等级读取相同的新每级收益，允许超出玩家商店当前可购买的等级。其实际属性、收入和生产速度与此前相同。开局时可查看难度选项提示，局内顶栏直接显示 AI 难度，悬停凶残1、凶残2 可看两项等级。

已开始的对局沿用冻结的后勤和兵种数值，旧战斗内新晋升英雄也按旧规则计算。读取局外养成后新开的对局采用新规则。

本轮 596 项无窗口检查通过，覆盖六档难度标识、凶残1 和凶残2 的实际攻防与经济、玩家及英雄属性、旧战斗养成、英雄装配与最终伤害限制。
