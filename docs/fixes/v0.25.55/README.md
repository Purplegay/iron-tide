# v0.25.55 · Auto W 全开／全关

局内保留技能栏的单独兵种开关，并在右侧指令甲板的维修／出售操作下方增加「Auto W 全开／全关」。研究局外 Auto W 科技后，在新扩展对局显示；未研究和经典模式不能使用。

- 无须选中单位即可全开／全关，统一设置所有己方已支持 Auto 的 W，包含还没有生产的兵种和后续新单位。
- 全开／全关重置之前的单独选择；随后仍可以单独打开或关闭某个兵种，多选统一调整的原行为保留。
- 使用已有技能触发条件，不影响手动 W、Q/E；不会让未支持自动的技能强行自动释放。
- 全局默认与兵种覆盖共用原偏好文件和战斗快照；旧存档没有全局键时仍按此前默认开启处理。读档保留当时设置，新局读取最近偏好。
- 保存失败不改变当局状态，清除旧覆盖与写入全局默认在同一次原子保存中完成。未修改真实玩家存档。
