# v0.22.0.1　苏联导弹逐架装填与巨型乌贼缠船

规则数据来自本机 Steam 尤复的 expandmd01.mix 内 rulesmd.ini。时间按每秒 15 个规则帧折算。生成弹离架与寄生解除的顺序另对照本地行为参考 AirSpawnTrait、WeaponTargeting、ParasiteableTrait。具体飞行曲线、脱离位置和摇船动画仍由 Godot 连续坐标实现。

| 对照项目 | 对局表现 |
| --- | --- |
| V3 单架 | 抬架 60 帧，离架后再生 400 帧。完整周期约 30.67 秒；在架上被击毁时从拦截时刻起再生。 |
| 无畏双架 | 每架静置 20 帧、抬架 60 帧、再生 80 帧。一架被拦截不会重置另一架，只有一枚就绪时只射一枚。 |
| 拦截 | 两类弹体均为 50 生命。离架播放起飞声；成功拦截后不命中预定落点，不计入单位击杀或军衔经验，不播单位损失。 |
| 缠绕 | 可攻击已探测的舰船和潜艇。登陆艇在水中可抓，上岸后不能抓。机械舰艇用 SquidGrab 固定并摇晃；海豚和敌方乌贼使用 SquidPunch。普通乌贼在目标已达红血时处决，精英在黄血时即可处决。 |
| 脱离 | 声波或外部有效维修驱离乌贼，超时空传走宿主时乌贼留在原处附近。强制驱离后浮出水面，10 秒内无法再次缠绕；自愈不会驱离。手动脱离或正常绞沉后寻找邻近水位。 |
| 宿主沉没 | 外力击沉宿主会压死附着的乌贼。原规则 SQD.SuppressionThreshold=250；近期超过阈值的外来单次伤害也能压制绞沉后的逃生，铁幕保护单独判断。 |

专项覆盖普通与扩展遭遇战、齐射中断、补弹临界点、抬架存读档、声波与维修，以及缠绕关系恢复。图像和音效尚未与尤复实机逐帧、逐音对照。

无窗口回归通过 1252 项。苏联综合 464 项、高级单位 86 项、火箭架与弹道 54 项、声波 486 项、海军 110 项、船厂维修与脱离 52 项。船厂专项同时检查付款前后、泊位阻挡和超时空传送起点的乌贼位置。
