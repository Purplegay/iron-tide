# v0.27.15.3 · 遭遇战地图出生点恢复

在 v0.27.15.2 的 Windows 试玩包复现：Circuit Board 初次打开显示四个地图编号，修改初始资金后按钮数量降到零。预览与地图共用同一份出生点坐标，刷新预览时原地清空数组，也清掉了后续进入该地图要用的缓存。重启进程会临时重建这份缓存。

现在重建预览时先分配独立数组。测试从遭遇战界面更改资金、切到另一张尤复地图和自制地图、切回、用鼠标交换出生点、退出再进入，并启动对局检查玩家起始坐标。多方遭遇战专项 248 项通过。此修复包含在 v0.27.16 导出快照中。

发包验收：解压 v0.27.16 Windows x64 压缩包后，实际 IronTide.exe 修改资金前后均保留 4 个按钮；连续切图、鼠标交换、重进大厅与实际开局坐标检查通过。
