# v0.22.18.2 · 盟苏遭遇战规则修复

## 对局变化

- 常规范围攻击读取尤复弹头的 CellSpread 和 AffectsAllies。驱逐舰、V3、无畏和基洛夫的爆炸可波及友军。地面爆炸不会击中上空单位，乘员不会在车内再单独承受同一发溅射。
- 间谍进入盟军空指部或苏联雷达会清除受害方已经探索、当前无人观察的地形。当前视野和雷达支援的充能保留。渗透核弹井等战略武器建筑仍能清空相应充能。
- 矿石精炼器、超时空传送仪、天气控制器、工业工厂、铁幕和核弹井按所属方各限一座。从加入建造队列起就占用名额，已就绪的第一座可正常放置，失去建筑后可重建。旧档里多付的钱有去处：玩家可以收回重复的就绪订单，AI 会为已经拥有的建筑自动退款一次。
- 同一方的多个实验室共用一次力场护盾，多个苏联雷达共用一次侦察机，美国伞兵继续共享。玩家和敌方分别计时。释放后所有同类设施同步归零，断电、被占领、主设施被摧毁以及读档时均按所属方和支援类型选择设施。

## 无窗口回归

Godot 4.7.2，隔离玩家目录。18 个专项最终通过 7,346 项断言。其中新增盟苏对照专项 240 项，覆盖纯 RA2 和扩展模式。雷达测试先让新生成的间谍更新视野，再从普通右键入口检查目标资格。

另复跑原审计的三个独立探针。距爆心 9 世界像素的同型犀牛，友方和敌方各损失驱逐舰 31、V3 122、无畏 220、基洛夫 83 HP。三国六个雷达场景均保留原有 11 秒充能并重罩远处地形，三个共享支援双设施场景均拒绝立即再释放。

对应回归见 [盟苏规则专项](../../../iron_tide/tests/yr_faction_parity_regression.gd)。对照来源和历史复现见[盟苏审计](../../YR_ALLIED_SOVIET_PARITY_AUDIT.md)。下一批仍有占领异阵营工厂后的生产目录、窃取科技后的兵营资格、部分武器开火音效。
