# v0.25.1.5 · 短局胜利无需拆除剩余防御工事

短局此前将仍存活的炮塔、围墙和碉堡计为基地。现在双方失去最后一座基地建筑和最后一辆基地车后即判出局，防御工事（defense 标签）与民用建筑不计入。建筑按用途分类，天气控制器、核弹井等战略建筑仍可维持短局。歼灭规则继续统计幸存防御建筑。大厅的胜负选项和对局简介同步说明短局条件。

Godot 无窗口测试覆盖纯 RA2 和扩展模式的玩家与 AI，验证九种防御工事、剩余盟苏基地车、普通生产与供电建筑、超武、胜负结算及歼灭规则。新增场景在修复前有 8 条失败，修复后基地恢复与特殊机制两个专项共 437 项通过。苏联开局专项目前仍有 3 条失败，涉及基地车展开、随后建造电厂、空军与海军页签；修改前快照复现相同三项。
