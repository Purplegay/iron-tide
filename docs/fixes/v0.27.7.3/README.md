# v0.27.7.3 · 修复重载战斗的慢动作

原先的过载保护把每个画面限制为一个 60 Hz 物理步。1 倍低帧率时，每帧只能推进 1/60 秒，部队行驶和武器计时都会落后。1 倍规则基准始终为每秒 15 个规则刻，战斗倍率为 1.0。

物理补算过载时，保持所选战速，按帧耗时逐档减少物理更新次数，每步按相应时间推进，单帧允许最多两个物理步。1 倍重载可降到 30、20、15 Hz，3 倍重载保持至少 30 Hz。恢复流畅后回升，离开战斗恢复引擎原配置。F8 快照增加当前物理更新频率。追击与视野继续分档调节。

同一份电路板存档，读入 316 个单位、95 座建筑。使用独立 Windows 桌面、OpenGL 实时渲染，累加物理回调收到的游戏秒数，与实际经过时间对照。观测窗口约 10 秒，含读档后的调节时间。

| 战速 | 修正前推进 | 修正后推进 |
|---|---:|---:|
| 1 倍 | 3.20 游戏秒 | 9.18～9.60 游戏秒 |
| 3 倍 | 7.40 游戏秒 | 14.20～16.40 游戏秒 |

1 倍的平均画面刷新由约 19 帧/秒降至约 10～14 帧/秒。这份存档仍有慢帧，3 倍仍达不到完整三倍速。数据来自本机，3700X 未实测。
