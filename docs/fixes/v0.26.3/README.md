# v0.26.3 围墙与步兵火力

尤复 rulesmd.ini 中，美国大兵 M60、卧倒机枪 Para、动员兵 M1Carbine 和海豹 MP5 均使用 InvisibleLow 弹道，其 SubjectToWalls=yes。这些武器的普通弹头缺少破墙标志。盟苏围墙是 concrete 类型。AP 则有 Wall=yes，NUKE 有 WallAbsoluteDestroyer=yes。

本版按当前武器和墙段占据的建造格检查射界，双方墙段都提供掩护。已建成且存活的墙段参与判断。目标在墙后时，受阻的普通枪弹无法开火。破墙弹头可直接攻击墙段，普通枪弹的直接和范围伤害都经过墙体受击判定。可破木障和绝对摧墙分别按弹头标志处理。墙段销毁后立即释放射界。覆盖地面单位、载员、驻军与常规武器防御建筑。这里适配的是开火射界和墙体受击，飞行中炮弹的三维撞墙轨迹另属弹道模拟。

RA2 和扩展模式的围墙射击专项 68 项、围墙连接与拆除专项 1422 项通过。验证使用隔离副本、无窗口 Godot，覆盖截至本版本的脚本和规则。围墙组售的测试场地补齐双方基地，避免测试在已经判定胜负后出售围墙。
