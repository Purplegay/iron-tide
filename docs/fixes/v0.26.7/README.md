# v0.26.7 · 矿车交矿增收

在「驻防基地 → 后勤 / 档位」用军需券升级。每级增加己方矿车交矿资金 0.5%，10 级 +5%，20 级 +10%。费用沿用「后勤网络」曲线，首级 400 军需券，每一级的标价按基础价乘以 1.38 的当前等级次方后向下取整。

新开的扩展对局按开局时的等级计算。普通矿、宝石和部分卸货都按实际交付价值结算。矿石精炼器另行乘算。例如普通矿原值 500，满级交矿到账 550，有一座工作的精炼器时到账 687.5。已有养成档从 0 级开始，旧对局存档按开局时的收益继续。

后台验证覆盖逐级购买与扣款、满级限制、盟苏矿车交矿、混合矿物、分次卸货、精炼器、纯 RA2 模式、开局锁定、旧对局缺字段和困难 AI 收益。经济链 268 项、养成平衡 21 项通过。
