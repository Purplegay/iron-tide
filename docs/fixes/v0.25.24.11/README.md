# v0.25.24.11 · 重装大兵背架贴合

英雄 E1/E2 装甲用当前帧头部位置与身体朝向绘制。GGI 采用自己的肩部挂点，但原背架在部署后插值到固定阵地位置，头部与肩膀动作时，上半部装备脱离身体。镜筒和折叠支臂的携行高度也使侧面轮廓容易压住头部。

本次上部背架持续跟随 GGI 原贴图逐帧肩部位置，部署时撑脚伸到地面；缩小包体、收拢镜筒和支臂，降低携行高度。远侧、人体、近侧绘制顺序及单向待机的逐帧朝向沿用既有处理。
