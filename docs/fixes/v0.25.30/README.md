# v0.25.30 · 军需券长期养成与天赋格限制

2026-11-05。按用户逐项确认：仅普通单位改造扩到 20 级，英雄等级上限不改；增加后期军需券消耗。技能卡、英雄与单位天赋升级继续使用战略核心。

## 天赋格

- 开格上限为 `min(2, 实际开放天赋数)`，在界面和购买入口同时检查。零天赋不能买第一格，一个天赋不能买第二格；收割者两项天赋仍可购买两格。
- 旧档已购格子不删除、不退款、不补扣；多出的格子显示“历史已购空格保留，待新天赋开放后可使用”。已有天赋和分配等级不变。

## 单位改造

定制火力、定制装甲、技能强化均为 20 级。每次费用为 `floor(500 × 1.35^当前等级)` 军需券，每条从零升满 576,096 券，单兵种三条合计 1,728,288 券。

原每级增益保持：攻击系数 +3%、护甲系数 +2.5%、技能系数 +6%。20 级分别为 ×1.60、×1.50、×2.20。护甲仍通过原公式结算，该项满级实际减伤约 33.3%，同步纠正原说明“每级直接减伤 2.4%”的不准确表述。

旧 12／12／10 等级不重置，原有效果保留，新价格只用于之后购买。购买现在先持久化，再发送升级事件；写盘失败恢复等级和完整费用。

## 英雄数值训练

只更换货币和价格，不改成长效果：火力上限 150 级、+300%；生命上限 167 级、+500%。下一等级费用为 `1000 + 100L + 4L²` 军需券，L 是本项已升等级。

| 项目 | 最后一升级 | 从零升满总费用 |
|---|---:|---:|
| 火力 | 104,704 券 | 5,722,600 券 |
| 生命 | 127,824 券 | 7,707,384 券 |

火力与生命独立计价；UI 价格、余额不足判定与实际扣费均使用军需券。英雄护卫／生存天赋仍使用战略核心。旧档联合训练数值和后来分拆的火力／生命字典均保留，不追补历史费用；现有对局继续使用开局冻结的养成快照，新购买对新对局生效。沿用既有 JSON 存档，不添加或迁移字段。

## 后续军需券消耗设计（未实装）

一次性升级总会满级，这轮提高总消耗只能延长积累周期，不能永久消除溢出。建议下一步先选一种周期项目，不直接继续提高战斗数值上限：

1. **英雄训练委托**：每周用军需券领取少量训练任务，完成出场／助攻目标后获得好感经验；按周限制份数，英雄满好感时不允许买无收益委托。它加快现有养成，不增加第二套英雄等级。
2. **兵种外观精修委托**：用军需券和兵种使用记录换专属装饰材料，材料用于已有外观的灯色／铭牌等可选细节，不免费解锁本体皮肤。周期补充主题形成可持续消耗；不产出军需券或无限兑换战略核心，避免循环套利。

这两项需要另行确定价格和奖励，当前没有扣费入口。
