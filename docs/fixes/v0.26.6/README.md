# v0.26.6 遭遇战难度「凶残3」

从遭遇战大厅选择凶残3，局内顶栏显示实际难度。盟苏科技树与兵种目录沿用原阵营。AI 实际读取后勤 50 级、定制火力与装甲 37 级。

| 规则 | 生效条件与数值 |
| --- | --- |
| 玩家造成的最终命中伤害 | 扩展模式，对 AI 的命中按原有基础伤害参照，150% 以内足额，超过后按同一压缩曲线逐渐趋近 225%。 |
| AI 坦克装甲 | 普通伤害结算与防御效果完成后，最终承伤再乘 0.9。灰熊、犀牛、光棱、坦克杀手、幻影、机器人、磁能、天启及相应扩展坦克适用。 |
| AI 防御塔与驻军 | 最终装填冷却再乘 0.8。部署、瞄准与蓄能阶段沿用各武器规则。 |
| AI 建筑护盾 | 每栋初始、新建或新占领的 AI 建筑获得实际最大生命 50% 的护盾。伤害先扣盾，余量再扣血；盾不自行补充。读取战斗记录时恢复剩余量。 |
| AI 收益 | 在凶残2 的收入倍率上再乘 2，矿车交矿为基础值的 8 倍，常规收入 4 倍，每 10 秒补助 2000。开局资金按后勤 50 级的开局资金规则计算，退款与间谍转移按实额。 |

盟苏基地在合法地块围住建造场，避让地形、矿点、已有建筑和生产通道；基地车开局在首次展开后布防。之后在建造范围内为部署步兵的两翼购买墙段，使用真实防御队列。面前的射线和后方退路留空。如果掩护对象已离开且无其他合适阵位，退回已就绪墙段的费用。

机动部队编组时坦克在前、支援兵种另选可达后排。遇袭后附近可达的部队回援，空袭优先调防空兵种；矿车、驻军、维修和专职任务保留岗位。行军指令长期无进展时尝试侧移绕行，再前往原目的地；远离集结点的空闲部队可重新归队。

无窗口验证共 335 项，其中凶残3 专项 96 项，凶残2、养成平衡和最终伤害回归 239 项。分别以美国和苏俄 AI 进入两种规则模式，检查真实建筑订单扣款与放置、护盾溢出及读档、受袭回援、分组站位和停滞行军的绕行指令。测试覆盖指定场景，尚未统计长期胜率。
