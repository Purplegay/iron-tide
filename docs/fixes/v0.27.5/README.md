# v0.27.5 · 战斗性能快照

战斗中按 **F8** 保存一次。建议在同一局流畅时和卡顿时各按一次，将两个 JSON 一起发给开发者。可在「设置 → 战斗快捷键 → 保存性能快照」改键。如果旧配置已经把 F8 给了其他指令，会保留原设置并给快照选择一个空闲键。战斗顶部「存档」按钮的提示显示实际按键。

文件位于 `user://performance_snapshots/`。默认 Windows 工程版路径为 `%APPDATA%\Godot\app_userdata\Iron Tide RTS\performance_snapshots`。每份文件独立命名，游戏内提示实际保存路径。

快照记录游戏版本、对局标识、地图、倍速、进程号、存活单位与建筑的数量和分布、选中单位数、场景节点、特效、弹体、资源、绘制调用及寻路计数。最近最多 300 个渲染循环之间的实际墙钟间隔按时间顺序保留，附中位数、P95、P99 和最大值。内存字段以字节计；Windows 工作集与私有字节由后台查询，文件内记录这次查询相对按键的延迟。受限系统仍会输出其余字段。

经典与扩展模式下通过 140 项战斗检查，覆盖快捷键冲突迁移、连续保存、JSON 内容和 Windows 进程内存读数。
