# Iron Tide v0.5.7.5 修复说明

2026-10-29

- 三种 RA3 单位按官方起义 XML、继承模块和实际运行入口集中检查，记录来源、消费路径、回归覆盖和剩余差距，见[三单位检查](../../RA3_THREE_UNIT_AUDIT.md)。
- 补齐未来坦克的原生基础回血：启动延迟1秒，此后每0.5秒2点；英雄回血独立叠加，存档继续原计时。炮艇既有基础回血保持，配置从两单位自己的 AutoHealBehavior 导出。
- 修正三个RA3单位的经验栏仍套用尤复两档军衔文案：精英正确显示“距英雄”，最高级显示“英雄”；RA2最高军衔仍为精英。
- 新增真实 Unit 生命周期与持续开火回归，覆盖三单位、炮艇双模式、军衔、15/60/120Hz、弹匣和存档；更新幻影车体检查以排除新增阴影专用网格，保留车体/履带/炮口/像素断言。
- 炮口军衔特效按原版共用定义保持；没有为了升星观感提高伤害、扩大范围或更换颜色。
