# v0.27.8.1 · 英雄独立换装

英雄养成页可单独更换英雄皮肤。读档后按保存的英雄外观重建材质和特效，普通兵种继续使用单位改造中的涂装。未装备英雄专属皮肤时使用英雄原版。试穿只影响预览，装备按钮位于模型旁，并标出当前装备。

修复前为普通兵种装备涂装、同场晋升四名英雄后存读档，四名英雄的材质检查均失败。修复后英雄装配 115 项、坦克英雄 79 项和普通单位换装 146 项无窗口检查通过。验证包含两个步兵英雄、两个坦克英雄、同场普通单位，以及对局外换装后再读旧战斗。

养成综合测试在修改前后均有 13 项相同失败，涉及技能卡适配和档位收益。专项退出时仍有 Godot 资源释放提示。皮肤和粒子的最终画面待实机确认。
