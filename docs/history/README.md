# Iron Tide RTS（铁潮）

红警3 / 星际争霸2 / 命令与征服 风格的 RTS 原型，用 **Godot 4.3+** 制作。
核心特色：**兵种克制** + **局外养成（挂机老家）** + **可视化数值编译器** + **GM 后台**。

## 快速开始

1. 安装 Godot 4.3 或更高版本（标准版即可）。
2. 打开 Godot → `Import` → 选择本目录的 `project.godot`。
3. 按 `F5` 运行。

> 项目使用 GL Compatibility 渲染后端，老显卡/集显也能跑。

## 玩法架构

### 1. 局外养成（老家 / 驻防）
- **档位（Tier）**：T0→T4，每个档位有不同的挂机收益、离线累积上限和全局属性加成。
- **挂机收益**：按真实时间累积军需券与战略核心，像 SLG 老家收菜一样。上限受「仓储扩容」升级影响，离线最多结算 12 小时。
- **升级项**：火力校准 / 复合装甲 / 强化结构 / 引擎调校 / 模块化预制 / 后勤网络 / 仓储扩容 / 快速部署，永久生效并作用于所有战斗。
- **逐单位改造**：每个单位三条永久轨道（定制火力 / 定制装甲 / 技能强化），成本按等级递增。
- **单位技能**：每个单位可装配 4 个主动技能 + 1 个被动技能（数据驱动，战斗中 Q/W/R/D 释放）。技能库分两类：**通用技能**（开局人人可用，共 7 个）+ **抽取技能**（需消耗军需券抽取解锁，共 11 个，分普通/稀有/史诗）。未解锁的技能不能装配、即使残留存档也不生效。

### 2. 局内战斗
- 资源：资金（资金由指挥中心基础补给 + 采集车往返运输）
- 生产：指挥中心 → 兵营 → 战争工厂 → 空军基地
- 克制：伤害 = 单发伤害 × 克制倍率(攻击类型×护甲类型) × 局外攻击加成
- 护甲类型：无甲 / 轻甲 / 中甲 / 重甲 / 建筑 / 空中
- 视角：等距投影由 `iso.gd` 统一管理，相机 = `Zoom(z, z*K) · Rot(-eff_angle())`。
  地平面元素裸画世界坐标；立体元素在 `_draw` 顶部调 `Iso.begin(self)`，地面方向用 `Iso.dir()`、高度用 `(0, -h)`。
  **`begin()` 与 `dir()` 是严格互逆的一对，符号必须相反（一改就得两个一起改）**，否则实体会被横向压扁剪切。
  7 档预设（默认红警2 标准 2:1）；`[` `]` 调压扁、`'` 切「菱形/正视」、`\` 切镜像。

### 3. GM 后台（`admin/`）
- **数据编译器**：可视化编辑克制矩阵、单位数值、波次组成，一键导出 JSON。
- **经济调参**：实时调整档位收益、升级价格、挂机倍率。
- **GM 控制台**：加钱、秒杀、无伤、刷兵、跳波、清场、直接发放货币与解锁全部单位、解锁全部技能。

## 扩展点（已预留）

- `data/cards.json`：抽卡单位池，目前逻辑留空。
- `data/skills.json`：技能库。新增技能只要加一条（`unlock` 决定是通用 `base` 还是抽取 `gacha`，`rarity` 决定抽取权重），无需改代码。技能抽取规则在 `unlock.draw`（货币 / 单价 / 稀有度权重）。
- 每个玩家拥有「基础单位」+「抽卡单位」两套生产列表，抽卡列表当前为空。
- 虫群（swarm）作为外来势力，后续可替换成第三阵营玩家势力。

## 说明

本项目为原型/框架，美术全部使用程序化图形（色块 + 线条），重点在系统与数值层。
