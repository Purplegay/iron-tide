# Iron Tide — 变更说明

本版 = **B 阶段（流场寻路 + 编队）** + **红警2 式等距伪3D** + **RA3 式建设模式**
+ **点击单位 UI（指令栏 / 姿态 / 选中反馈）**，并修复了三个会导致游玩中断的缺陷。

---

## 本轮（2026-09-30）：红警2 角度校正 + 点击单位 UI

### 1) 等距投影改成与红警2 逐像素一致

RA2 的地图投影是 `screen = ( (x-y)*30, (x+y)*15 )`，即地块 60×30、菱形宽高比 **2:1**。
本工程同样用 `dir(v) = rot(v, 45°)` 后纵向 ×K，代入 x 轴得 `(1,0) -> (0.707, 0.707K)`；
要得到 RA2 的 1:2 斜率，必须 **K = 0.5**。旧值 `0.62` 让菱形比例变成 1.61:1（偏高），
这就是"看着不像 RA2"的直接原因。

→ `Iso.K` 默认改为 **0.5**；新增 `Iso.PRESETS` 四档（2:1 / 1.8:1 / 1.6:1 / 1.4:1）
可现场对比；新增 `Iso.MIRROR` 镜像翻转。顶栏「视角」按钮循环切换，
`-` / `=` 微调 K，`\` 切换镜像。

### 2) 镜头默认改成红警2 式近景

单位数据半径只有 7–14（坦克约 27 世界单位），旧默认 `view_zoom = 0.62` 是远景，
单位在屏幕上只有十几像素，整张图显得空旷，也不像 RA2 的紧凑取景。
→ 默认 `view_zoom = 2.0`（约 20 地块宽，接近 RA2 取景），滚轮缩放范围放宽到 `0.45 – 3.2`，
初始镜头位置下移到 `map_size * 0.80` 对准基地。

### 3) 地面网格增强

`ground.gd`：交错地块亮度差拉大、网格线不透明度 `0.025 -> 0.05`，
让 2:1 菱形网格在近景下能看出来。

### 4) 点击单位 UI（红警2 风格）

- **世界内反馈**：选中 = 绿色地面菱形描边 + **屏幕对齐四角括号**（呼吸动画）+ 血条；
  警戒 = 脚下小方块，巡逻 = 脚下圆点。鼠标悬停在单位/建筑上会淡绿高亮其轮廓，
  悬停敌人时光标变十字。
- **点击反馈**：下达移动/攻击/巡逻指令时，目标点冒一个 0.75s 的扩散菱形圈
  （移动=绿、集火=红、巡逻=黄）。
- **底部选中面板重做**（RA2 侧栏观感）：单位头像网格（程序化绘制、按型号聚合、
  右下角数量角标、底部血条、右上角是否带武器）+ 型号 / 血条 / 姿态 / 护甲 / 射程 / 速度 /
  武器与克制表 / 局外加成 + **指令按钮组**（移动/攻击/停止/警戒/巡逻/全选同型）+ **阵型行**。
- **指令模式**：点「移动 / 攻击 / 巡逻」（或按 `M` / `A` / `P`）进入指令模式，
  顶部出现提示条、世界内出现跟随鼠标的准心，左键点目标执行，`Esc` / 右键取消。
- **姿态系统**：新增 `警戒`（原地固守、不追击，`H`）与 `巡逻`（两点往返，`P`）。
- **双击选同型**：双击一个单位 -> 选中场上全部同型号（RA2 习惯）。
- 新增 `scripts/ui/unit_icon.gd`（单位头像控件，纯程序化绘制，无需美术资源）。

### 5) 顺手修掉一个真 bug

`Battle.select_unit / clear_selection` **不触发选中事件**，只有鼠标框选路径会触发，
导致非鼠标路径（GM 造兵后选中、指令内选同型、已选中单位阵亡）时 HUD 面板不刷新。
→ HUD 改为按「选中签名」每帧对比（`_selection_signature()`），任何来源的选中变化
都会在一帧内重建面板；血量/姿态/货舱只做数值刷新、不重建控件（避免点击瞬间按钮被重建）。

## 修复（上一轮）

1. **造兵崩溃（关键）**
   `Invalid type in function '_queue' in base 'CanvasLayer (BattleHUD)'.
   Cannot convert argument 1 from Dictionary to String.`
   原因：`Building.buildable` 被赋成了**单位定义字典数组**
   （`GameData.units_from_building()` 返回 `Array[Dictionary]`），
   而 HUD 与 `Building.enqueue()` 都按**单位 id 字符串**使用它。
   修复：`building.gd` 中把 `buildable` 规整为 id 字符串数组。

2. **无武器单位导致生产面板崩溃**
   `hud.gd` 把 `ud.get("weapon", {})` 传给 `CombatMath.describe_weapon(weapon: Dictionary)`；
   当 `units.json` 中该单位 `"weapon": null`（如采矿车）时，显式为 null 会绕过默认值 `{}`，
   而 Godot 的 `Dictionary` 形参**不接受 null** → 报错。
   修复：`combat.gd` 的 `raw_damage / full_damage / describe_weapon / dps`
   形参改为可空（内部本就有 null 分支，此前不可达）。

3. **框选/建造预览不可见**
   `Ground` 会绘制整块不透明底色，且作为子节点绘制在 `Battle` 自身绘制**之上**，
   导致 `Battle._draw()` 的框选框、建造半径环、占地预览全部被遮住。
   修复：`ground.z_index = -10`。

## 视角：红警2 式 2:1 等距

- `battle.gd`：`camera.rotation = Iso.cam_angle()`（45°）+ 非均匀 `zoom = Iso.cam_zoom(z)`。
- `iso.gd` 为**旋转感知**投影：
  - `Iso.dir(v)`：世界地平面向量 → 屏幕（旋转 45° 再纵向 ×K）。
  - `Iso.ell(center, rx, ry)`：地平面椭圆 → 屏幕多边形（自动 45° 菱形）。
  - `Iso.extrude(...)`：竖直圆柱（底/顶为菱形椭圆），返回顶面中心。
  - `Iso.box(...)`：等距长方体（只画朝前的两面 + 顶面）。
  - `Iso.begin(ci)`：`draw_set_transform(ZERO, -ANGLE, Vector2(1, 1/K))`，
    抵消相机旋转+压扁，使**实体**仍 1:1 直立绘制。
- 地平面元素（地面、阴影、占地预览、建造半径环）**不做补偿**，直接按世界坐标画，
  由相机自动投影成菱形 —— 因此 `Ground` 的网格自动变成 RA2 的菱形网格。
- **节点自身 `scale` 恒为 (1,1)**：`Unit extends CharacterBody2D` 带 `CircleShape2D`，
  设 `scale.y` 会把碰撞圆拉成椭圆（曾使寻路到达率 29→6）。

## 可调参数

- `Iso.K`：纵向压扁系数（**默认 0.5 = 红警2 标准 2:1**；越大越"高俯视"）。
- `Iso.ANGLE`：相机旋转角（默认 45°）。改 `90°` 可退回"正俯视压扁"。
- `Iso.MIRROR`：镜像翻转 45°（只影响观感）。
- `battle.gd`：`view_zoom = 2.0`（默认近景）、`BUILD_GRID = 40`（建造吸附网格）、
  `BUILD_RADIUS = 620`（建造半径）。

## 操作

左键框选/点选（双击选中同型）、右键移动或集火、滚轮缩放、方向键滚屏、
`B` 建造菜单、`Space` 暂停、`Tab` 倍速、`M` 移动、`A` 攻击、`S` 停止、`H` 警戒、
`P` 巡逻、`F` 循环阵型、`1/2/3` 直选阵型、`G` GM 控制台、`-`/`=` 微调压扁、
`\` 镜像、`Esc` 取消指令/返回大厅。
