# 变更说明：平视视角 + 红警式建造进度条

本轮（在 RA3 UI 版之上）做了两件事，外加一个顺手修的 bug。

## 1. 视角更「平视」（iso.gd）

- 新增更平视的预设，`PRESETS` 现为：
  | 索引 | 名称 | K（=sin 俯角，越小越平视） |
  |---|---|---|
  | 0 | 红警2 标准 2:1 | 0.50 |
  | 1 | 略平视 2.25:1 | 0.4444（**新默认**） |
  | 2 | 平视 2.5:1 | 0.40 |
  | 3 | 平视 2.8:1 | 0.3571 |
  | 4 | 略俯视 1.8:1 | 0.5556 |
  | 5 | 斜视 1.6:1 | 0.625 |
  | 6 | 高俯视 1.4:1 | 0.7143 |
- `K` 初值由 `0.5` 改为 `0.4444`，`preset_index` 由 `0` 改为 `1`：默认视角比红警2 稍平视。
- 游戏内仍可用「视角」按钮循环、`-` / `=` 微调 K、`\` 镜像。

## 2. 红警式建造 / 生产进度条（hud.gd）

- 新增 `_make_build_bar(frac, caption, fill_col)`：RA3 皮肤进度条（轨道 + 填充 + 说明文字）。
- 选中面板：建筑 `under_construction` 时显示「建造中」+ 施工进度条 + 百分比。
- 生产面板：
  - 建筑在建：追加「施工进度 N%」进度条；
  - 正在生产：追加「生产中 <项名> · N%」进度条（替换原先只写百分比的文本）。
- `_process`：选中的建筑「在建或队列非空」时，把生产面板刷新间隔从 0.45s 提到 0.08s，保证进度条平滑。

## 3. 修复：全选部队把建筑当单位（battle.gd）

`select_all_combat()` 原先遍历 `allies` 组（含建筑），导致 HUD 读取建筑不存在的字段而报
`Invalid access to property 'unit_id' / 'stance_label' on Building`。
改为遍历 `combatants` 组并排除采集车（`u.is_harvester`）。

## 校验

- `--headless --editor --quit` 导入：无 Parse / SCRIPT ERROR。
- 冒烟：`SMOKE_SUMMARY ok=98 fail=0`，且不再出现上述建筑误选报错。
- 实拍：`iso_ui.png`（新默认视角）、`iso_build.png`（建造进度条）、`iso_sheet.png`（四档平视对照）。
