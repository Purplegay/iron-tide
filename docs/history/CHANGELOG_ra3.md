# CHANGELOG — 单位细致化 / 指令完整化 / UI 向红警3对齐

本轮三件事：**加深单位建模与"贴图"细节**、**补全操控指令**、**把 HUD 从红警2 侧栏改为红警3 观感**。

## 1. 单位细致化（`scripts/units/unit.gd` 整体重写绘制层）

全部程序化绘制，无美术资源；新增**逐型号专用建模函数**与**明暗分层 + 面板缝线 + 阵营涂装**：

| 型号 | 建模内容 |
|---|---|
| 载具/坦克/火炮 | 两条**带滚动纹路的履带**、车体箱（4 面分层明暗 + 面板缝）、首上装甲斜高光、后部引擎格栅、侧裙板高光、**独立朝向炮塔**（后坐位移 + 舱盖 + 天线 + 同轴机枪）、炮管（火炮带炮口制退器）、车灯、阵营涂装条 |
| 步兵 | 双腿步态（行走摆动）、躯干圆柱 + 战术背心色块、背包、头盔（高光 + 盔沿弧）、双手握枪、瞄准镜、行进上下颠簸 |
| 空军 | 尖锥机身 + 高光脊线、座舱玻璃、尾梁尾翼、双短翼、翼下挂载导弹、**三叶主旋翼旋转**、双引擎喷口脉动辉光、地面分离阴影、悬停浮动 |
| 机甲 | 双关节腿 + 脚掌、躯干、双肩甲、胸口反应堆（脉动）、头部传感器红灯、线缆、臂炮（后坐 + 炮口火光） |
| 兽群/生物 | 三对交替摆动的腿、分节甲壳 + 甲缝弧线、背刺、头部与下颚、发光眼、尾巴 |
| 采集车 | 履带、底盘、**后部料斗（按 cargo 实时填充矿石）**、前部驾驶舱玻璃、前钻头、警示条纹 |
| 通用表现 | **开火炮口火光**（按剩余时间衰减）、**后坐复位**、**低血冒烟**、阵营配色、选中（地面菱形 + 屏幕对齐四角括号呼吸动画 + 姿态标记） |

- 新增动画时钟 `_anim` / `_track_phase` / `_muzzle` / `_recoil`，仅对"选中 / 悬停 / 行进 / 开火 / 低血"单位逐帧重绘，避免百单位掉帧。
- 新增通用绘制辅助：`_sdir()`（世界方向→屏幕方向，含 K 压扁）、`_oriented_box()`（按世界朝向的立方形箱体，返回顶面中心）、`_draw_track()`、`_draw_box_seams()`、`_draw_muzzle_flash()`、`_draw_smoke()`。

> 约束保持：节点自身 `scale` 恒为 (1,1)（`CharacterBody2D` + `CircleShape2D`，缩放会拉扁碰撞圆）；所有"立起来"的元素在 `_draw` 顶部 `Iso.begin(self)` 内绘制，保持 1:1 直立。

## 2. 操控指令完整化

- **修复真 bug**：`_try_fire_ready()` 自始至终**从未被调用**——单位从不实际开火（之前只有建筑会开火）。现于 `_physics_process` 内调用，射程内自动开火，战斗闭环才真正成立。
- **路径点队列（Shift 队列指令）**：`Unit.order_queue` + `queue_waypoint()`；Shift+左/右键追加路径点，抵达后自动前往下一点，世界内绘制连线与小菱形标记。
- **攻击移动**：`arm_command("attack_move")` / `Ctrl+右键`，边走边打。
- **采集指令**：右键矿点（或"采集"指令）把选中的采集车派往该矿点，`Unit.order_harvest()`。
- **集结点（Rally Point）**：选中建筑后右键设定集结点，之后出厂的部队自动前往；世界内绘制旗帜；`Battle._set_rally() / rally_for()`，`spawn_unit()` 应用。
- **开火姿态**：`free 自由开火 / return 仅反击 / none 停火`，`Unit.cycle_fire_stance() / fire_stance_label()`，被击后仅反击计时 `_return_timer`。
- **全选部队**：`Battle.select_all_combat()`。
- **镜头对准选中**：`Battle.center_on_selection()`。
- **悬停高亮**、**双击选同型**、**警戒 / 巡逻**沿用并有姿态地面标记。
- 指令模式提示条与准心配色扩展：移动绿 / 攻击红 / 巡逻黄 / **攻击移动橙** / **采集黄**；指令落下时世界内对应色涟漪。

## 3. UI 向红警3对齐（`scripts/ui/hud.gd` + `ui_kit.gd` + `unit_icon.gd`）

- **布局**：从"红警2 式的左下面板 + 底部生产条"改为**红警3 式右侧竖栏**：一条贯穿的侧栏底板（`ra_rail`）内自上而下为 **选中面板（头像 + 信息 + 指令网格 + 阵型）→ 生产面板 → 战术地图**；顶部为整宽数据条（资金 / 部署阶段 / 击杀 + 视角 / 暂停 / 倍速 / GM / 返回）。建造菜单作为侧栏左侧浮层。
- **皮肤**：新增 RA3 皮肤工具 `UiKit.ra_style / ra_panel / ra_button / ra_label / ra_progress` 与 RA3 调色（深蓝玻璃 `RA_PANEL` / 青色描边 `RA_EDGE`、`RA_CYAN` / 金色 `RA_GOLD`）。面板带顶部青色高光边、圆角 3–4px。
- **单位头像格（`unit_icon.gd`）**：改为 RA3 式 cameo 格——竖直渐变底 + 细网格 + 顶沿青色高光 + 四角青色括号，按型号聚合 + 数量角标 + 血条 + 有无武器点。
- **生产标签页**：生产面板顶部新增 `全部 / 步兵 / 载具 / 空军 / 支援` 分类标签（`_add_prod_tabs()` + `_unit_cat()` + `_cat_match()`）。
- **指令网格**：11 个指令按钮（移动 M / 攻击 A / 停止 S / 警戒 H / 巡逻 P / 攻击移动 X / 采集 Y / 开火姿态 T / 全选部队 E / 镜头 C / 全选同型）+ 阵型行（线列 1 / 楔形 2 / 纵队 3），全部改用 RA3 瓷砖按钮并注册到 `cmd_buttons`。

> 兼容：`UiKit` 原有 `COL_*` 与 `make_*` 全部保留，`admin/` 后台与其它界面不受影响。
