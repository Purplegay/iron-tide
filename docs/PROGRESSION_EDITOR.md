# 游戏内天赋／技能调参（v0.30.24）

进入战斗按 **Ctrl+G**，点击 GM 面板顶部的 **天赋／技能数值编辑器**。也可从主菜单后台进入 **天赋技能调参** 页签。

## 使用

1. 搜索名称、单位 ID、技能 ID 或参数名。分类包含技能、天赋、英雄养成、机制参数。原有 145 项之外，新增 51 组、396 个固定机制参数。
2. 在所属技能页直接编辑各等级数值及下方的 **固定机制** 字段。例如搜索 **金鳞战垒**，修改 **护盾持续秒数**，默认 10 秒。英雄五级养成在“英雄养成”分类，亦可按“停机护罩”等具体能力名搜索。
3. 点击 **应用本项**，将当前页的技能和所列固定机制一起应用；任一字段校验失败则均不应用。切换项目保留未应用草稿，关闭编辑器丢弃草稿。
4. 点击 **保存已应用修改到本机**，重启后继续使用；未应用草稿不保存。
5. **恢复本项原值** 会恢复当前页及所列固定机制的出厂值，再保存可让恢复结果跨启动保留。重载不会把上次修改误当成新的默认值。

字段标明秒、格、比例或倍率，悬停显示参数路径。比例 0.2 表示 20%；普通技能顶层 radius 为像素，扩展技能 values/radius 通常为格，1 格为 55 像素，以字段说明为准。次数必须为整数，间隔、除数等有相应下限；微小修改也会保存。

描述区的 **快捷调整** 参数名带蓝色下划线。点击后自动滚动到对应参数的起始等级（通常 Lv.0），聚焦输入框并选中数值，直接输入即可修改草稿。固定机制定位到本项对应字段；英雄能力保留自身实际解锁等级。描述较长时可在描述区内滚动查看全部入口。跳转不应用、不保存、不重置数值，修改后仍需点击 **应用本项**。

保存位置为 Godot 用户数据目录下的 `progression_tuning.json`，界面显示完整路径。二次保存保留 `.bak`，临时文件写入成功后替换原文件。不会写回工程 `res://data/`，也不修改玩家解锁、养成等级或货币。保存失败保留上次文件，已应用的内存修改仍有效。

## 接入范围与生效时机

新增配置权威为 `iron_tide/data/progression_parameters.json`；战斗通过 `scripts/rules/progression_parameters.gd` 读取，编辑器与战斗使用同一份数值。

- 谭雅、鲍里斯、游隼、雷铸的两条专属养成：伤害、护盾、生命阈值、持续时间、触发次数、范围、冷却、补弹、维修、供电等。
- 原有英雄护卫、训练、护盾成长、复苏与保命机制，以及英雄技能卡中的召唤数量、范围、间隔和持续时间。
- 扩展单位天赋与 W／被动技能中的固定触发参数；原生天赋各级强度倍率也改为读取配置，公式上限和转换系数单独列出。

应用影响本次运行所有阵营的相应配置。在场装备技能保留原对象、剩余 CD 和已有状态，不返还施放次数。动态查询参数的效果在后续计算中读取新值；生成时快照的护盾、攻击和计时器遵守各机制的快照规则。出生时计算的属性需要新建单位验证。三点破门炸药保存生成时的引信时长，寿命随引信设置延长，避免长引信炸药提前消失。

机制类型、目标类型规则、三角连接等结构、等级解锁逻辑、原版兵种基础数据、渲染与动画常量不属于该数值编辑器。调整共享机制组会影响其列出的所有关联技能。

## 说明与演示

金鳞战垒的护盾时长文字及演示时长、爆炸范围读取当前值。护航水幕的减伤、范围、数量、CD、余波储量上限和护盾时长仍可逐级编辑，演示只有三艘候选友舰。

其它尚未模板化的固定说明保留原机制叙述，在上方显示 **GM 当前调整（优先于原说明数值）**。部分脚本演示仍是固定场景，并非任意调参组合的通用仿真；不能用旧演示的次数或排布判断配置是否生效。英雄养成说明也显示当前覆盖值。
