## 矿车与矿场

新建矿场展开完成后，免费赠送 1 辆超时空矿车并自动采矿，不需要研究科技。出口受阻时等待，读档不会重复赠送；开局预置矿场保持原有矿车配置。

选中已建成的己方矿场，在左侧面板点击“制造矿车”。每座矿场同时制造一辆，
沿用该模式现有价格与生产时间，随进度扣费；缺钱暂停，取消返还已付费用。
出口堵住时保留成品，腾出空间后出车并自动采矿。战车工厂也可生产矿车；矿场入口作为独立科技，当前调试默认解锁。
这是用户指定、两个模式共用的定制规则，不作为原版 RA2 一致性结论。

矿车行驶时车头朝前，抵达矿场固定卸矿口外侧后转向、短距离倒车入库。
手动移动或重新指定矿点会解除旧的倒车状态与路径；矿场不可用时保留货物等待。
修改脚本后须关闭旧游戏，再通过原启动入口重开。用户已确认矿车正常前进、仅在矿场门口倒车；

## 海空运输与生产经济
